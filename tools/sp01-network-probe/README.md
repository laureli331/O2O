# SP01 网络样本汇总器

当前只有本地纯函数 `summarizeSamples`，不发网络请求、不部署云函数、不产生测速数据。它保留失败次数和失败率；成功请求的 P50/P95 使用最近秩；相邻成功请求耗时差的均值仅是应用层波动描述，**不是网络层抖动或丢包测量**。全部失败时耗时为 `null`，不会以零伪装。

用户同意先设计目标 cloud1 的临时只读探针，再于 SP08 用正式接口复测。正式取样前仍需确定只读端点、上/下行测法、正常和弱网参数、设备与环境、样本输入以及清理边界。当前没有云端部署或真实样本，因此 R04 和 SP01 均保持待完成。该汇总器可由后续采样器调用，也可独立替换；复用 Node 原生数组与统计计算，不引入测速服务或第三方依赖。
