- 工具不显示临时 URL、不显示文件内容、不输出请求日志。账号 A 核验时只比较一段合成证明文本。错误只有命中 CloudBase 明确权限码才记为“权限拒绝”；文件不存在、网络错误和未知错误都保持“无法判定”。

## 使用顺序

1. 在微信开发者工具中以此目录单独导入，不要打开或覆盖 QuickStart 项目。
2. `cloudfunctions/sp01IdentityProbe`已临时部署；只从本工程小程序端调用，禁止从控制台函数测试面板或HTTP入口调用身份函数。
3. 账号 A 生成共享码并创建合成文件，把页面生成的 JSON 测试包交给账号 B。
4. 账号 B 必须在同一目标 AppID 的小程序里粘贴测试包并运行探针。若身份摘要相同，工具会在任何文件请求前停止；只有摘要不同才测试文件访问。
5. 如果 B 的同路径写入成功，探针会立即尝试删除它写入的确切 fileID；这时不要再运行 A 的文件核验/删除，直接在控制台只读检查 `sp01_permission_probe/` 为空。如果 B 的写入被明确拒绝，则由 A 粘贴原测试包，核验文件后确认删除确切 fileID，再检查目录为空。
6. 如返回“无法判定”、覆盖写后清理未确认、或环境/文件状态不符合预期，停止重复测试。先记录脱敏错误码，检查当前对象后再决定恢复。

创建者流程若显示“文件清理未获确认”或“上传结果未确认”，不要分享测试包，也不要重复操作；只核对页面显示的本轮测试路径。若设备临时文件清理失败但云端删除已确认，本轮同样停止并重新开始，不得分享旧测试包。
