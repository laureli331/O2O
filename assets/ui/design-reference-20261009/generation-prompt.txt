Use case: ui-mockup.
Create ONE extremely polished, high-fidelity Chinese WeChat mini-program UI prototype overview image for 湘邻湘友, a local township life service app. Present 8 full-height screens in a disciplined 4-column by 2-row grid on a warm ivory exhibition canvas. High resolution, aim 3200x2400 or similar portrait-friendly wide canvas, sharp Chinese text. Each screen equally sized, straight-on flat front view, screen content takes priority; minimal slim framing, no perspective or photoreal devices. Above each screen a small Chinese number and page title. Top board title “湘邻湘友” and subtitle “生活服务 · 高保真设计参考”. Footer subtle “占位图片 · 示例数据 · 非运行页面”. The screens should feel thoughtfully designed, sophisticated, light, spacious and practical, not an empty wireframe.

VISUAL SYSTEM: Only three UI source colors: sage green #618872, near-white ivory #FCFBF7, dark green ink #263A31, plus opacity blends derived from them. Warm light content surfaces, dark readable Chinese sans-serif, small rounded corners (card 8/control 6 logical pixels). Page title26, subsection18,body16,metadata13 on each logical mobile artboard. Large tasteful whitespace, consistent alignments, close related fields and larger gaps between task groups. Gently glowing diagonal sage gradients on primary action buttons, translucent ivory glass panes with visible softly blurred sage backdrop in category panels and fixed operation trays; text stays perfectly crisp. Light soft shadows, no harsh outlines. Home has faint tasteful leaf silhouettes in header as a UI ornament. Distinct information hierarchy and restrained surface layering inspired by clean boarding-pass confirmation, frosted silver finance UI, and efficient fitness dashboard, all translated to THIS green-ivory style. Do not copy their blue, orange, serif fonts or huge pill cards.

ALL PHOTOS AND IMAGE FIELDS MUST BE PLACEHOLDERS: Use simple ivory/sage rectangular placeholder panels with a minimalist landscape-image outline icon and clear Chinese label “图片占位”. No real or generated product photographs, trees scenery, washing machines, bicycles or humans. Avatars are generic outlined user silhouettes without actual faces. Decorative leaf silhouettes are not photographs. Placeholder boxes should be elegant rather than checkerboard, show purposeful photo area structure. All values and names are explicitly demonstrative.
