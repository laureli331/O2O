# Cloud function workspace

This workspace is reserved for the SP08 implementation work. It intentionally contains no function code, CloudBase SDK dependency, environment identifier, secrets, deployment script, or production configuration. Select and validate the runtime, SDK calls, data contracts, and server-side enforcement against the actual CloudBase environment in SP08 before adding executable functions.

The `miniprogram/` QuickStart directory remains separate and is not a workspace or product implementation source.
