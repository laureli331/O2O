# Banner自愿取消与提前终止退款确认

日期：2026-10-17（Asia/Shanghai）。首组三项退款商业政策及第二组三项处理原则已分别确认，Banner仍为第二版，299/249/199元仍为候选30天报价；没有实际订单或退款。原题和逐题完整答复保存于[结构化记录](merchant-banner-refund-confirmed-20261017.json)。

## 1. 原题与实际答复

1. **Banner已核实付款，但对应购买期尚未实际开始投放，商家主动取消时采用什么商业政策？包括提前买好的未来购买期；平台违约及依法应退款等情况另行处理。**

   用户完整答复：A（推荐）：允许取消申请指明的购买期，退该期全部实付，不扣手续费，不连带取消其他已购期。降低首次试投顾虑。

2. **Banner已经按约开始投放，且不存在交付故障或违规争议，商家因自身原因希望提前终止，采用什么商业退款政策？平台未按约交付的退款／补偿另行确认。**

   用户完整答复：A（推荐）：允许提前终止。退款＝本购买期实付×终止生效时剩余秒数÷该购买期总秒数，最终四舍五入到分；不收手续费、不重算已投时段单价。

3. **对允许自愿取消或提前终止的Banner购买期，从何时停止投放、确定退款计算时刻？本题不决定退款处理时限、到账时间或原位置何时重新售卖。**

   用户完整答复：A（推荐）：提交前展示终止影响和退款金额并二次确认；用户确认立即终止，且完整有效申请提交成功时生效，以该时刻计算退款，审核期间不继续消耗该期时长。


本次按三个实际A答复记录，不虚构用户说过一句“全A”。

## 2. 尚未实际开始投放

先核实申请指明的购买期实际付款。对应期尚未实际开始投放时，包括提前买好的未来期，允许取消并退该期全部实付，不扣手续费，不连带取消其他已购期。不从付款日或预约排期开始日虚算已投时长；付款成功和实际可展示后，仍按已确认的实际投放开始时刻起算。付款金额或状态未知须核实，不能填0冒充已核实，也不能把仍未实际开始当作已投放。

## 3. 已按约开始投放

仅适用于正常按约交付、无交付故障或违规争议且商家因自身原因自愿提前终止的对应购买期。平台未按约交付、故障、违规争议及依法应退款等情形另行处理，不以本自愿退款公式限制另有依据的请求。

设P为该购买期已核实实付，T为该购买期总秒数，S为终止生效时剩余秒数，0≤S≤T：

**退款R＝P×S÷T，最终结果一次四舍五入到分。**

P使用该期实际付款，不直接使用候选报价；不收手续费，不把已投时段改按更高单价重算。现有30连续天对应2,592,000秒，不按自然月或整天向上取整计费，不把首页实际停留秒数当购买期总秒数。算式保持精确比例到最终金额，再舍入到分；不先把日单价或小时单价舍入后相乘。

本公式计算结果在0与该期实付之间。若剩余0秒，本自愿政策的时间退款为0；极少剩余时间产生不足半分的应退金额，最终可舍入为0.00元。这些算例不认定平台故障、违约或依法应退金额为0。重复申请、历史退款与并发防重处理仍待细化，未批准重复退付。

## 4. 终止与计算时点

提交前展示终止影响和退款金额，并二次确认。用户确认立即终止，且完整有效申请提交成功时，对申请指明的购买期生效；以这个时刻确定剩余时长和退款金额，停止该期投放，审核期间不继续消耗该期时长。仅查看预览、申请不完整或提交失败均未满足生效条件，不能据此终止。

不以人工审核通过或退款到账时刻替代已生效终止的计算时刻；不因审核等待而少退一段时间。普通素材修改待审时保留原合规版本的规则，仅适用于仍有效且未终止的购买期，不能据此继续投放已生效取消的该期广告。不连带取消其他购买期，不把本条生效规则扩为已经确认退款成功或立即重新售卖位置；起步无自行撤回、可人工申诉的规则按第8节确认。

## 8. 第二组逐题A、A、A：处理时限、失败或未知及自行撤回

1. **Banner退款的处理时限采用哪种目标？两案均为收到申请后24连续小时内首次回应，资料不全时告知必要补充项；下述为审核及发起符合条件退款的目标，不保证到账。异常须在原期限内说明原因、进度并继续处理。**

   用户完整答复：A（推荐）：完整有效申请成功提交后72连续小时内完成审核，并对符合条件的申请发起退款。与已确认的会员、AI增购运营口径一致，本题明确批准用于Banner。

2. **对已生效的Banner退订，退款失败或结果未知时，是否采用以下处理原则？本题不决定人工申诉后的恢复或补偿方式，也不决定位置何时重新售卖。**

   用户完整答复：A（推荐）：保持退订生效，不自动恢复投放或继续消耗该期时长；继续核实办理退款，结果未知先查证，避免盲目重复退款，未核实的退款不标为完成。

3. **Banner退订生效后，起步是否提供用户自行撤回的入口？此前已确认提交前展示终止影响和退款金额并二次确认；人工申诉后的具体补救仍可单独讨论。**

   用户完整答复：A（推荐）：起步不提供自行撤回入口；误操作可提出人工申诉，补救规则另行确认。减少退款与排期恢复的冲突。


**两个处理起点**：收到申请后24连续小时内首次回应，必要资料不全时告知补充项；自完整有效申请成功提交起72连续小时内完成审核，对符合条件者发起退款。首次回应不从补齐材料或人工开始工作时重算；72小时也不等到24小时首次回应目标结束后才开始。连续小时不因夜间、周末自动暂停。

**异常与到账**：72小时是审核及发起符合条件退款的处理目标，不代表72小时内到账。实际通道和到账时效仍待核实。异常须在原期限内说明原因、进度并继续处理，不能只发一条延期消息就停止跟进；未核实退款不标完成。

**失败或未知**：保持该退订生效，不自动恢复投放或继续消耗该期时长；继续核实办理，结果未知先查证，避免盲目重复退款。不把失败或未知等同到账成功，也不因未知重算已确认的终止时点和比例退款金额。具体回执、重试、防重及并发实现仍待后续细化。

**撤回与人工申诉**：起步不提供退订生效后的自行撤回入口；原有提交前影响/金额披露与二次确认继续执行，误操作可提出人工申诉。恢复排期、重新投放、补偿金额等人工补救未定，不承诺一定恢复原位置或原排期。本组不决定位置释放或重新售卖的时刻。

**核对示例**：仅作为计时验证，不是真实申请记录。假设第0小时收到申请、第10小时完整有效提交，则首次回应目标仍为第24小时，审核及发起符合条件退款的目标为第82小时；不是第34小时首次回应，也不是从首次回应目标结束后另加72小时。材料原本已完整且第0小时成功提交时，两个目标分别为第24小时和第72小时。以上均不承诺对应时刻到账。

**出处与范围**：第二组完整答复另存refundExecutionDecision，首组responses、sourceCommit、公式、舍入和算例保持不变；本组没有一句可替代逐题原文的“全A”实际答复。会员/AI增购退款、交易账单、Banner候选价/容量/保留及第二版归属不变；实际销售、退款或自动执行均未开启。
