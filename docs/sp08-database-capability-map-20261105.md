## 官方文档能力

腾讯云当前[事务文档](https://docs.cloudbase.net/database/transaction)写明：文档数据库事务仅在服务端运行且仅 `node-sdk` 支持；事务操作列出 `get`、`add`、`delete`、`update`、`set`。快照在第一次读取后生成，写入会锁定相关文档，遇到写锁冲突可能终止事务。事务最长 10 秒；事务内只支持 `doc` 方法，不支持 `where`；事务期间应避免 DDL，不能把外部云函数/API 调用放入可重试事务。文档没有给出固定读写操作数上限，实际数量受单次操作耗时及 10 秒总时限约束。

腾讯云[索引文档](https://docs.cloudbase.net/database/data-index)列出单字段、组合、地理位置和唯一索引。唯一索引约束索引值不能重复；未提供该字段时按 `null` 处理，因此唯一索引不允许多条缺字段/空值记录。索引字段大小上限为 1024 字节。

这些是平台文档所述能力和限制，不证明当前环境已经创建任何产品索引、实际事务隔离对所有并发调度的结果，或任何特定业务约束已满足。

## 对后续设计的约束

1. 受权限保护的业务写入必须经服务端 Node SDK 路径执行；本记录没有决定认证、授权适配器或角色策略。
2. 正确性关键的事务读集合不能依赖事务内 `where` 查询。必须先为具体业务对象设计可寻址文档/冲突锚点和事务读写集；“先查没有，再写入”本身不构成并发原子证据。
3. 唯一索引是官方提供的候选机制，不代表已选择为每个业务键建索引。具体键、字段缺省策略、现有数据迁移和重复请求/并发插入证据都待各业务对象映射后确认。
4. 可重试事务中不执行外部请求。与事务相关的可靠后续工作需按后端合同设计单独的持久意图/恢复流程。
5. 服务端身份、服务器时间、金额、版本、幂等与未知结果恢复仍由具体服务端用例执行；共享 TS 合同和临时探针不能代替它们。
