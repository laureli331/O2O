## 本批调整

采用独立ui-consistency.css及明确的页面标记，不改其它共享样式文件。统一卡片12px圆角、按钮／输入框8px圆角、弹窗16px圆角和底部抽屉20px顶部圆角；手机16px页边距与卡内边距、12px卡间距；后台24px页边距、20px卡内边距、16px卡间距。主按钮最小46px，触控区至少44×44。

正文、标题、辅助信息按角色统一；金额和宣传主标题保留独立层级。头像、胶囊、首图尺寸、手机预览外框、底栏SVG和业务脚本保持。新规则同时处理.phone和.device容器，作用域不进入外部演示控件。三个HTML加载同一带摘要版本的样式，未对33个有效页面批量开启。
