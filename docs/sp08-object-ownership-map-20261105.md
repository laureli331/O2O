## 必须遵守的逻辑快照

1. **公开需求投影**：F02–F04 仅输出 PRD 明确公开字段。访问控制必须在服务端裁剪；不得返回完整对象后仅靠前端遮挡。F04 附件范围待确认。
2. **候选视图**：发布者能看本需求候选；每个候选只看本人申请。未选候选仍保持联系打码，相关接单资料仅用于申请上下文。
3. **选定交易约定**：选择或闲置确认关联当前合法轮次、双方、被接受的条件/时间/费用版本和授权事实。精确物理字段/读写集在对应业务用例中确定。
4. **地址与联系授权**：地址选用形成任务快照；地址簿编辑/删除不倒改历史任务。新对象不继承旧授权；联系变更、撤回、结束按 PRD 撤销/打码规则执行。
5. **费用和凭据**：待确认方案不覆盖当前值；费用、实际支出、佣金及实缴/抵付/多收退款分别表达。凭据只向当前有权当事人及必要运营开放。
6. **评价与商家内容**：只有当前审核通过版本公开，原稿和待审内容私有；评价自然人标识不公开，旧合法公开版在新版本审核通过前保留。
7. **私人工具、AI 与分析**：草稿/收藏/地址仅本人；AI 候选仅用户本人；分析只向授权管理账号给出有来源的汇总。

## 未决项与影响范围

- **F04 附件可见性**：PRD 未明确是公开还是仅当事人。阻断附件读取/上传功能开放，不阻断其它字段映射。
- **F22 唯一规则所有者**：后端合同分配了商家主体资料，但没有明确主帖草稿、审核版本、替换和下架事实的唯一 Module。阻断 F22 物理建模/实现；须在 SP08 明确、SP24 前落实。
- **F11 页面读者**：时段/忙碌的具体读取页面尚未逐页合同化；物理 DTO 字段需 SP14 对照页面确认。
- **E03 数据保留/删除**：期限与依据未定。真实个人信息、证件及新增生产分析保持关闭，直至 E03 形成有依据并获确认的期限/删除规则。
- **物理与交易证据**：真实集合/索引/规则/API、各 TX01–TX12 读写集、冲突/回滚/并发/恢复证据仍未完成。SP01 合成事务探针不替代业务级验证。
