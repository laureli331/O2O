# 接单多类别资料与批量时段确认

日期：2026-10-22。

用户指出 V10 缺少“其它”，且时段入口看起来只能管理一种类别，并要求先参考成熟平台再结合项目适配。用户明确选择：“各类独立，支持多选批量设置（推荐）”。

## 当前规则

- 接单资料覆盖维修、跑腿、其它，每类分别编辑、保存和在申请资料中展示；同一账号可同时维护三类资料。固定入口仍位于 V05“我的收藏”下方，服务页仍为订单中心，不恢复人员目录。
- 概览直接列出三类时段与忙碌摘要，分别进入编辑；“批量设置”进入同一个编辑页，可勾选一个或多个适用类别。
- 编辑内容以进入时的类别为基础。保存前明确显示将替换哪些类别的时段，用户确认后才应用；取消保留输入，未选类别不变。空时段也属于明确覆盖，确认文案说明替换原有时段。
- 保存后各类别持有独立的时段副本。之后单独修改维修，不会继续同步跑腿或其它；不引入隐藏的“共用时段”关联。
- 忙碌状态在勾选类别下分别显示和编辑，不将某类忙碌自动复制给其它类。只应用所选类别在本页明确显示的状态。
- 同日重叠时段合并、结束须晚于开始、时段选填的既有规则不变。类别间允许时段重叠；这些仅作沟通参考，不增加自动预订、自动拒单、取消订单或接单并发限制。
- 资料字段上限、资格核验、联系方式权限、执照原图隔离、认证返回及本地演示边界保持既有规则。

本记录覆盖[上一轮恢复确认](provider-profile-confirmed-20261021.md)中仅维修/跑腿的范围和仅显示当前类别时段的布局；上一轮原话及旧决定保留供追溯。

## 调研与适配

查阅 Cal.com 官方[多种可用时段](https://cal.com/blog/streamline-your-appointment-scheduling-with-multiple-availability-options)和[FAQ 中的时段分配说明](https://cal.com/faq)：其支持默认时段及不同事件类型使用各自时段。本项目借鉴“多类别独立设置”的思路，按用户选择提供明确批量复制，而不是引入日历同步、持续共用计划或预约自动冲突规则。依据公开文档，不把文档当作已体验最新版应用的证据。
