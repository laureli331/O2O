# 查看接单资料后回到原候选

2026-10-25。沿用已确认的返回连续性原则，修复V03候选卡与V10只读资料之间的往返。

## 问题与处理

- 实际复现：选中候选B、填写申请并打开其资料，返回后草选消失，原表单恢复初始值。
- 从V03打开资料前，在该浏览历史条目记录本次返回所需的候选、业务、演示状态、申请会话、尚未提交的表单、需求上下文及内外阅读位置。
- V10只读申请人资料从同源V03进入时，顶部返回沿浏览历史回到原页；直接打开V10仍使用原业务的V03兜底入口。
- 浏览器保留原页面时恢复原按钮焦点与位置；没有保留原页面时，仅在浏览历史返回中恢复这次快照、表单和位置。使用后清除一次性快照，普通刷新仍重置演示。不新增长期存储或后台保存，也不把未提交文字写入有效申请。
- 保留上一轮结果未知时先查询的保护，不允许借查看资料绕过。V10资格、编辑、类别时段和联系方式权限规则不变。

## 参考与适配

[W3C焦点顺序说明](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html)强调可理解、可操作的焦点次序；[MDN页面返回事件](https://developer.mozilla.org/en-US/docs/Web/API/Window/pageshow_event)说明前进/返回以及缓存恢复均会触发pageshow。项目适配为回到原候选资料按钮及阅读位置，分别覆盖缓存恢复和重新加载，不新增页面、弹窗或确认步骤。
