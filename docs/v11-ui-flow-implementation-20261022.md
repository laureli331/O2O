# V11 审阅稿实施与验证

用户新指令：“根据这个文档，进行优化”。来源为[V11审阅稿](v11-ui-flow-naming-review-20261022.md)，覆盖原稿仅写稿、不实施的范围限制；仍只授权合成交互预览。

## 本次补充确认

D4 原题：是否采用方案C，经营名称从已审核商家档案只读带入；本次广告经营或服务区域可修改，提交后审核，且不修改商家档案？用户答复：“采用方案 C（推荐）”。当前合成档案使用“青禾生活馆 / 演示社区”，只读名称在模型和页面两端约束；区域保存在广告素材或修改稿中，不写入档案。D5未指定真实规格，不新增图片大小、比例或文案长度承诺。D3没有真实后台事实，继续将审核与排期作为明确标注的合成组合结果，未声称拥有两个后台阶段。

## 已实施

- 命名：经营推广 → 首页轮播广告 → 广告管理；关联入口为“订单与退款 / 投放数据”。创建、修改、准备下期各有任务标题；草稿、审核未通过、待付款、付款/退款结果核实中等状态统一。
- 当前期与下一期同页两卡，素材、状态、位置、排期、付款和退款独立；下期任务始终说明当前期继续投放、不自动续费、不保证原位置。兼容此前临时演示的previous结构，恢复为当前期与下一期，不静默丢掉当前期。
- 保存草稿更新最近保存快照；无变化直接返回，有后续变化才确认放弃。修改草稿刷新可恢复，不当作生效版本。打开模态清除提示计时和Toast，模态期间不再弹Toast；关闭恢复触发焦点，键盘焦点留在模态。
- 退回原因同时出现在状态卡、进度与首图素材区；修改退回保留当前生效版本，恢复后重新预览/提交，审核通过才替换，不重算周期。
- 等待审核用时钟、退回用警示；完成/当前/未来步骤明确区分，当前步骤使用aria-current。待开始优先订单与排期，不将无数据报告作为主路径。
- 三位置使用fieldset/legend/radio真实互斥单选，首位（默认显示）/第二位/第三位价格仍为299/249/199候选元每30天。
- 长表单错误摘要位于内容顶部并获焦点；摘要与字段错误同文，可点到字段，aria-invalid与描述关联完整，输入不清空。只读档案名不参与可编辑校验错误。
- 预览标注待提交修改、下期待提交、当前生效、待投放或已终止版本；圆点对读屏隐藏，另有“第N位，共3位”。开始/结束时间分行，带年份并注明北京时间。
- 保留44px操作区、整行按压和键盘焦点，减少动态效果时关闭缩放。外层三页导航明确为预览评审导航，不接入正式小程序。
