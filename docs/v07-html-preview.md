## 如何体验

顶部索引可进入全部19页；“业务”“本人角色”“状态演示”分别切换四业务、另一方操作及异常状态。切换业务或状态重置合成交易；角色切换保留本次交易和待回复请求。所有日期均为固定合成时间，使用页面内演示时钟，不代表真实订单时点。

- 费用：维修 → I → 填项目和金额 → 发起 → 切另一方 → J确认 → H查看有效累计。
- 闲置：选择“闲置待确认” → 买家D提出时间 → 卖家E提交 → 买家F确认 → G查看生效交易。
- 延期/取消/异议解除：一方提出，切换另一方回复；发起方不能代表对方确认。
- 异议：N提出 → P演示扫描被阻断 → O双方解除。平台故障保护与交付异议相互独立。
- 结束后：选择“已结束 · 费用待处理”，在I/J补费用后Q展示首次申报窗口；R双方同意后才显示本次恢复电话。

## 原型边界

所有人物、电话、微信、地址、金额、图片选择与历史均为合成演示。图片只校验本地类型、数量和大小，不上传或保存。页面内存状态刷新后重置；没有真实交易、内容审核、鉴权、消息、支付、凭据存储或计佣任务。

页面覆盖用于前端审阅；完整关联内容与费用的原子变更、既有阶段费用更正、特殊补费改价24小时超时、故障重放去重、真实提醒与举报/评价/计佣更正等后端合同没有据此完成生产实现。Q页明确显示特殊窗口规则，关联内容/费用仍以PRD合同为准；不以静态页面证明真实交易验收。
