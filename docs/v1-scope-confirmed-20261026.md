# 首版开发范围与商家商业规则待确认清单

日期：2026-10-26。状态：功能版本归属按用户本轮答复确认，商业细则尚待逐项确认；不表示规则全部冻结、真实功能已实现或可以收款上线。

## 本轮实际决定

1. 商家入驻：“首版一并做入驻收费，先补齐规则”。99元／连续30天入驻收费纳入首版，不作为仅有HTML的第二版预留。
2. 广告：“V11—V13广告放到首版”。广告管理、广告订单退款、投放数据纳入首版；按已有广告规则交付可选99元标准制作及后台处理，而非仅移动入口或版本标签。

这两项覆盖此前“Banner第二版”“首版不售卖Banner”的版本归属；九档广告价、入驻价、定制价、退款边界与真实能力门禁没有因此改变。原文和旧版本记录保留历史。

## 本轮入驻细则实际确认

- 用户先答“入驻费不退”，经范围澄清后答“按这个范围处理”：已成功开通后，商家因自身原因提前退出或未使用，不按剩余时间退入驻费；重复付款、付款后未能开通、平台未按约交付等另核对，不以“不退”一概覆盖。异常按下述24／72小时目标处理。不将该政策说成可排除依法应处理的责任。
- 用户选择“保留旧主页和帖子，暂停新增”：到期未续费仍公开原合规内容，暂停新增帖子、活动和新领券；保留历史、续费、已领券核销和投诉处理，已付广告仍按独立订单执行。旧内容修改和新广告购买资格见下方补充确认。
- 用户答“3天内”，随后明确“通知成功起连续72小时”：审核通过且通知成功后起算72连续小时；到期未支付不能沿旧审核直接开通。真实付款结果未知先查，不能把回调迟到等同未付。

补充实际确认：到期旧内容可下架，可提交营业地址／联系电话／停业等必要更正并经审核更新，暂停营销性修改；经营档案审核仍有效且资料合规时，可单独购买广告和99元定制，不强制先续入驻，新增帖子／活动仍需续费。入驻异常收到申请24小时内首次回应；完整有效材料提交成功后72小时内核对并为符合退款条件者发起退款，到账不保证、未知先查，不与广告两笔费用互相抵作退款。

入驻首发权益进一步确认：经营资料、主页、帖子管理、活动与免费优惠券；不附赠商家AI文案／图片额度，广告和99元Banner定制独立购买，不把旧商家AI套餐自动并入本期收费。每个主体首版限一个经营档案，持照按经核实的经营主体、无照按已核验自然人去重，同一人不同持照主体可各自申请1档；不提供自助合并／迁移。

活动券采用免费满减券，商家填写消费门槛、优惠额、总量、有效期；微信登录用户每个微信账号每个活动限领1张，由该商家核销1次，不额外要求接单资格、不新增店员账号体系、不售券和不代收交易款。领券／核销不自动生成居民交易、佣金或评分资格。固定起止时间；门槛和优惠额为正数且优惠额不超过门槛，总量正整数，领取与核销都在有效期内，过期失效，不做领取后N天有效。发布后门槛／优惠额／有效期锁定，商家可停新领取，但已领券仍按原规则至原到期日有效；停领或入驻到期不作废，错误／争议由平台核对。

2026-10-26新增设计前确认：审核通过通知成功生成到商家站内消息并记录该时刻后起算连续72小时，不等待已读或微信订阅消息送达。活动满减券内容安全检测与平台人工审核都通过才公开；未通过保留填写并按原因修改重提，不新增未确认的审核时限。

## 仍延后／不启用

- 内容加热仍先观察真实发帖数据，第二版酌情评估；本次Banner提前不等于加热、置顶、推荐算法一并提前。
- 图片进入AI、有出处的规则问答、AI运营助手、微信流量主广告仍后续版本；SaaS继续长期储备，不纳入这两个版本。
- 居民AI次数包直购优先推进能力核实；20次／1.90元、到账180天的规则保留，退款执行等未补齐前不真实售卖。
- 平台自营服务余额保留设计，首版是否启用仍待资质、用途和本金退回执行确认；本轮没有把它随广告自动启用。
- 不恢复人员目录、V17产品入口、自由聊天、居民交易款代收、自动扣佣、刷脸、公共自由话题。V06兼容跳转和V17合法历史归档不作为新模块开发。

## 新增范围带来的原型缺口

V11—V13及广告后台已有预览，但商家完整入驻申请／审核／付款／开通／续费／到期／异常处理，活动免费券发布／领取／核销尚没有对应完整交互原型。需要先补ASCII和必要页面，再编写正式产品代码。不能因为前一轮23组V页已回归，就把这批新商业范围视为全部设计完成。

商家到期后的必要更正和独立买广告权限，也需纳入新原型、权限表与端到端测试。既有合成测试不证明这些新增流程已完成。
