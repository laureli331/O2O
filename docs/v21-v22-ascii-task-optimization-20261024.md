## 理由与结果

C/D提供与当前任务相关的短句，由用户明确点选后插入，可编辑和撤销，重复不叠加，不覆盖原输入或选中文字；不自动认定降价或欠款事实。保留1—500字及附件规则，必要事实由用户补充。提交失败保留输入，未知结果查询原请求，成功回到同一对象进度；原材料与处理经过不因界面精简而删除。

## 不变的边界

- 看板仍按Asia/Shanghai默认最近7个完整自然日，结束日不晚于昨日；同批漏斗与日事件分开，无历史快照不补造；0/未知/未采集/无样本分开，失败保留旧成功值并标过期。
- AI沿R/S/U/B/E原公式及去重，修改不等于错误，采用不等于发布，速度不等于整体任务耗时。评测、用量和费用可追溯；无报告写未评测，无依据不造金额。DG01前仍只合成演示、管理账号后端可读。
- 账单实际出账成功才启动72小时；争议只暂停对应部分，无争议原期限继续；补通知未成功不启动新截止，旧理由/旧材料重复不再次暂停。
- 锁定比例和封顶不变；真实降价和平台减佣核验独立；原账单保留、下月更正，未知不填0。
- 分次缴款不重置剩余期限，重复回调只记一次；未知先查，不重复付款或退款；多收退回、核准抵扣、卡包余额、客户线下款分别处理。
- 欠费结清只解除该原因，其他限制保留；退款仅可核对成功才标已退回。注销不强制放弃、不清零、不假退款、不新定处理时限。
