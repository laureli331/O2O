# 接单资料编辑不中断

2026-10-25。沿用已确认的资料编辑、三类独立/批量时段和未保存保护，完善V10局部增删后的定位。

## 实际问题与处理

- 已复现添加展示图片后重绘整个编辑区，焦点落空、阅读位置回到顶部。现局部操作重绘后恢复编辑区与页面外阅读位置，聚焦对应操作；目标超出可读区域时只作必要滚动，内容缩短按可滚动范围收敛。
- 添加展示图片后回到选图入口，移除后定位相邻图片，空列表回到添加入口。执照选入/移除后回到执照选图入口；展示图片、执照选图均支持Tab聚焦、Enter/空格激活及可见焦点。
- 新增服务时段后聚焦新行星期；移除后定位相邻行，移除全部后回到添加入口。原时段、说明、区域、微信号、类别勾选及各类忙碌草稿由原读取逻辑保留，不自动保存。
- 多选适用类别复用同一定位方式，保留当前类别控件焦点及内外阅读位置。仍按原规则一次核对批量应用，取消后继续编辑、明确保存后才应用；不新增类别、限制或忙碌联动。
- 切换或重绘编辑内容时清掉上一轮保存提示，避免旧提示误指当前尚未保存的新修改。
- 原保存校验、实际修改离开提醒、资格衔接及申请人只读权限不变；执照原图仍不公开，图片仅本页预览、不上传。

## 参考与适配

[W3C焦点顺序说明](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html)强调操作可理解、焦点顺序合理。本项目将该原则用于反复增删图片/时段的现有表单：不让重绘把使用者送回页首，删除后给出就近的下一操作，不改变视觉风格或增加确认步骤。
