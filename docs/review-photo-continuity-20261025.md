# 评价图片操作不重建评分与文字

2026-10-25。沿用已确认的V18评价表单、最多三图和未提交保护，完善图片局部交互。

## 实际问题与修复

- 已复现添加图片后，整个评价表单重建，原文字输入框消失、焦点落空；取消选图也会走完整重绘。
- 将图片展示与局部错误抽为独立区域，添加/移除/选图错误只更新该区域，保留原评分控件及文字输入框的实际节点。原文字、评分、输入状态与阅读位置不因选图重建。
- 取消选图或选择为空时直接保留原页面。添加未满三张时回到原生选图控件；满三张添加入口按原规则隐藏，焦点转到最后一张的移除按钮。移除后定位相邻图片，清空后回到添加入口，必要时只作少量滚动保证操作可见。
- 保留原生文件控件与键盘选图方式，补充添加区域的可见焦点。仍最多3张、JPEG/PNG、单张5MB，错误在图片区域提示，拒绝的文件不改变已有图片。
- 未解决的评分错误不因添加图片而消失，继续按原评分操作逐项解除；原图片本地预览、URL释放、元信息提交、审核、失败重试和未提交离开保护不变。原图仍不上传或跨页保存，回应仍只支持文字。
- V19及共享模型、共享样式未修改，本轮可见焦点样式仅用于V18；不新增页面、确认或保存流程。

## 参考与适配

[W3C焦点顺序说明](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html)强调合理的操作次序，避免控件更新打断理解；[MDN文件控件说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/file)说明原生文件选择及文件列表。本项目继续使用原生选图控件，局部更新图片区，避免重复实现文件选择器或重建无关输入。
