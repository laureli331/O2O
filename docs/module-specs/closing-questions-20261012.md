# 维修和其它费用收尾与履约申请：第七轮8题

日期：2026-10-12。状态：8题全部待答。A推荐；同时适用于维修和其它，均是待确认提案。完成后费用只读、取消后可协商已发生费用、服务结束后关闭凭据访问、双方确认和历史保留仍有效。不修改跑腿或个人收入。

## 1. 确认完成时还有待确认费用怎么办？（CQ01）

A：先处理费用方案（确认、不同意或撤回），再允许确认完成。B：允许直接确认完成，同时关闭待确认费用方案并保留历史；未确认费用不自动认可。两种都保留原有效约定，完成后费用只读，不要求先证明已付款。

## 2. 确认取消时还有待确认费用怎么办？（CQ02）

A：关闭该待确认方案并保留历史；已发生费用可在取消后重新协商提交。B：只涉及已发生费用的方案继续待确认，含未发生费用的方案关闭留历史，可重新协商。两种都不阻止取消、不自动确认费用、不表示结清，也不恢复凭据或联系访问。

## 3. 实际支出项目允许明确填0元吗？（CQ03）

A：允许，但必须是已确定实际为0，不能填0代替未知金额。B：实际支出项目必须大于0；没有支出则不添加该项。本题不改服务费允许明确0元规则。

## 4. 多个收费阶段怎么组织费用？（CQ04）

A：各阶段独立约定；修改只替换该阶段版本，服务累计取各阶段当前有效版本之和。B：每次方案完整列出这次服务所有已约定费用，后续阶段更新整份约定；服务累计取最新有效版本，旧版本不再相加。两种均不重复计算旧版本、待确认项不计入已约定费用、未知后续费用暂不加入，每条需求仍最多1份待确认方案。

## 5. 整次服务累计费用也设上限吗？（CQ05）

A：整次服务当前已约定费用累计也不超过99,999.99元。B：只限制每项及每份方案，不另设跨阶段服务累计上限。两种均不按历史版本重复累加，本题不改变已确认的每项及每份方案上限。

## 6. 同类完成/取消申请最多几份待确认？（CQ06）

A：同一次服务最多1份完成申请、1份取消申请，两种可以并存。B：最多1份完成申请；取消申请双方各可有1份待确认。两种均只能产生一个有效结束结果，结束后其它待确认结束申请关闭并保留历史。

## 7. 发起方能撤回或修改完成/取消申请吗？（CQ07）

A：在申请待确认且服务未结束时可撤回；修改须先撤回再重新提交。B：同样可以撤回，也允许直接修改为新版本，修改后须对方确认新版本。两种均保留历史，不单方结束服务；已确认结果不能撤回，修改不能绕过说明和附件规则。

## 8. 明确不同意完成/取消后，申请怎么处理？（CQ08）

A：本次申请结束并留历史，服务继续；协商后可重新提交。B：保留为已不同意的未结束申请，继续协商；后续对方明确同意后仍可结束服务。两种均需理由，不同意本身不结束服务、不新增评分资格；本题不改变接单申请不设单独拒绝的规则。
