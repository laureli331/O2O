# 维修和其它预约细则：第九轮8题

日期：2026-10-12。状态：8题全部选择A。用户实际回复：“全A”。同时适用于维修和其它。预约选填、双方都可提出、另一方确认、同次服务最多1份待确认、新时间未确认不替换原预约的规则继续有效。原PRD采用Asia/Shanghai时间，本轮不另造时区。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（TQ01） | 预约时间填写到什么程度？ | 一个开始时间，精确到分钟 | 开始与结束时间，均精确到分钟，结束须晚于开始 |
| 2（TQ02） | 提出预约时能填写过去的时间吗？ | 只能提出未来时间，开始须晚于服务端当前时间 | 可补录已线下约定的过去时间，明确标为历史预约，不自动视为已服务 |
| 3（TQ03） | 未来预约到点仍未获确认怎么办？ | 自动关闭这份待确认预约，保留历史；不影响原有效预约或服务状态 | 保持待确认并提示时间已过；须修改后重提，不能直接确认为未来预约 |
| 4（TQ04） | 修改待确认预约或改期怎么办？ | 发起方可撤回，修改须先撤回再提交 | 发起方可撤回，也可更新为新版本，须对方确认新版本 |
| 5（TQ05） | 不同意预约或改期是否必须填理由？ | 理由选填，最多300字 | 理由必填1—300字 |
| 6（TQ06） | 清除双方已确认的预约怎么办？ | 一方提出，另一方确认后清除 | 任一方可清除并通知对方 |
| 7（TQ07） | 服务结束时，未确认的预约/内容变更怎么办？ | 完成或取消后关闭待确认变更、保留历史，不视为同意 | 完成前须先处理这些变更；取消时直接关闭留历史 |
| 8（TQ08） | 已确认预约时间过后，仍未提交完成怎么办？ | 只标明预约时间已过，不自动完成或取消 | 标明已过并生成一次站内提醒，不自动完成或取消 |

第1—3题中“到点/时间过后”：单一时间点按该开始时间，时段按结束时间；第3题仅讨论提出时为未来时间的待确认预约，不涉及第2题B的历史补录。若第2题选B，历史补录的确认与展示细则需继续明确，不假装本轮已完整定义。

第4题两种都保留历史，不允许覆盖原有效预约或已确认结果。第5题两种均结束本次待确认预约，保留历史，原有效预约不变，不取消服务；理由沿用去首尾空白和用户可见字数原则。

第6题仅清除预约，不取消服务；两种均保留历史。清除请求与待确认改期的数量占用、冲突及无回应处理仍需明确，不能自动扩展为单方终止服务权。

第7题不改变完成前先处理待确认费用、取消不受未决费用阻止的既有规则；本题仅涉及内容/区域变更与预约变更。第8题不新设逾时收费、违约处罚或自动结束；渠道和其它提醒频率仍另议。

保留原题及两种选项，仅A获批准。规则与验收见[预约细则](appointment-rules.md)。
