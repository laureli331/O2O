# 结束期限边界：第二轮8题

日期：2026-10-14。状态：8题全部待答，A为推荐提案。依据：[第一轮实际选择7B、其余A](deadline-completion-rules.md)。只继续细化一套首发规则，不恢复暂停的SO表或改变已确认的主收入口径。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（DA01） | 预计结束时间由谁先填写？ | 接单员/卖家先填，客户确认交易时一并确认 | 客户先填，对方明确接受后用于交易确认 |
| 2（DA02） | 确认交易时，预计结束时间已经过去怎么办？ | 不允许确认，提示双方重新约定未来时间 | 允许，但最终自动完成期限必须仍在未来，明确展示剩余时间 |
| 3（DA03） | 同一交易的延期请求怎样限制？ | 最多1份待确认，修改先撤回重提，历史保留 | 可有多份待确认，按最后成功确认的版本生效 |
| 4（DA04） | 有效异议恰好在自动完成截止时收到怎么办？ | 仍有效并暂停；超过截止时间后才可自动完成 | 到截止时间即可自动完成，后续收到的异议走更正 |
| 5（DA05） | 普通取消申请未获回应，是否暂停自动完成？ | 不单独暂停，真正的取消/履约争议按已确认异常规则处理 | 只要取消申请待确认，就暂停自动完成 |
| 6（DA06） | 自动完成后费用才确定，什么时候补计佣？ | 从正式费用生效后再留72小时申报窗口，无有效阻断才形成记录；不重开流程 | 双方确认正式费用后，满足计佣条件即可补形成记录，不另留72小时 |
| 7（DA07） | 自动完成时，未确认的延期/取消申请怎么收尾？ | 关闭并保留历史，不视为双方同意；待处理费用继续保留 | 保留待确认，双方继续处理，已结束状态如何更正另定 |
| 8（DA08） | 自动完成后的联系方式怎样处理？ | 重新打码并关闭对方私密地址权限；保留费用/异议入口，必要联系恢复另议 | 费用仍待处理时保留必要联系权限，费用处理结束再打码 |

第1题只确定谁先提出时间，另一方仍需明确认可同一版本，不授予单方改期权，不增加接单员二次接单。A在跑腿报价、维修/其它申请、闲置卖家交易确认中的具体录入/展示入口另行补齐，不能把费用选填改成强制报价。B的接受证据与既有申请/选人动作如何合并需继续明确；选人前改时间导致申请失效的既有方向仍需核对。

第2题以确认成功前的服务端当前时间判断，不能使用用户设备倒填；日期精度、相等边界、晚到确认与提示后续补齐。B仍按预计结束加72小时计算，不悄悄从确认时刻再给72小时；过去结束时间与尚未来到的最终期限必须同屏明确。两项均未指定最远允许日期或默认小时数。

第3题只针对最终期限的延期请求，区别于原预约开始时间的变更。A不擅自将期限申请与待确认费用/取消合并成同一个数量限制；允许谁撤回、拒绝理由、有效期限的延长/提前及请求闭合通知后续明确。B不能用多个已关闭或待确认版本重复延长期限。

第4题以服务端有效接收事实为准；申诉晚到仍可核验，不是截止后永远禁止提出异议。异议/完成/取消同时发生的其它并发细节后续补齐，不用用户本地时间伪造提前申报。

第5题区分普通取消申请与已成立的有效争议。A不是忽略明确提出的未交付/未成交，也不把取消未回应当同意；真正已确认取消的不再自动完成。有效争议识别、理由与状态后续补齐。B可能被单方请求长期阻断，不能据此宣称防规避闭环完成。

第6题针对已自动完成但首次正式金额未知/待确认、因此尚未形成主计佣记录的情形，不覆盖已有有效计佣记录的后续加价/降价更正。使用双方正式费用及核验后的计佣依据，仍不默认0，不按预估/标价替代；异议、再次改价及部分金额计时衔接随后补齐。A的72小时为费用后来生效的申报窗口，不重复叠加到已结束流程，也不改变实际出账后72小时缴佣。无论A/B，按主记录首次成功形成月份归账，不倒填自动完成月份，不重复收费。

第7题仅在正常自动完成实际成功时处理请求，已成立有效异议仍按暂停规则；不自动同意延期/取消，不删除历史、不因关闭请求免除实际义务。A的费用待处理例外保留，不把未确认金额结清；B后续处理不得未经明确规则回退已成功结果或重复形成记录。

第8题对象仅限该笔交易双方，不能公开联系方式。A保留本人必要历史/费用处理/异议，恢复联系的用途、对象与核验流程另定；不能只遮盖页面仍下发完整信息。B的必要对象、时间、范围与结束判断必须另行收口，不批准无限期共享私密信息。两选项不自动开放原费用凭据或新增运营查看权限。
