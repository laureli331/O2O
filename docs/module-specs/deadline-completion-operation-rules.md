## 未理解题的具体说明

原DO02是在问未选定交易之前客户改了预计结束时间后，原报价的接单员在哪里确认接受新时间。例子仅用于说明：客户原来希望下午5点办完，接单员已报价；之后客户改成下午3点。报价金额保留，但不能认为接单员当然能在下午3点办完。

共同规则已经批准：客户修改时间 → 原报价金额保留 → 接单员明确接受新时间 → 客户才能选定这份报价。原DO02只选择确认入口：A在原报价卡片直接点击接受新时间；B客户先发独立时间确认请求、接单员回复后再选原报价。推荐A的直接入口只是提案，用户尚未选择。

这不讨论选定后双方正式延期；已选定的交易按双方延期及既有费用条件处理，不增加接单员二次接单。本轮可继续记录已回答的排序、超时、解除和再次发布方向，但不执行或固化DO02的任一入口。

## 新范围与其它时钟

初次最大30天从交易确认时起算；延期最大七天，起算点是原有效预计结束还是延期确认成功时点，用户本次未明确，需要下一轮选择。30天/七天按连续小时还是自然日也待确认，不默认使用720/168小时或自然日午夜。初次等于确认当前时点允许、已过去不允许，以及延期新时间必须晚于原有效预计结束的已有边界保留。

预计结束后72小时、正式延期新预计结束后72小时、有效交付异议解除后较晚时点再72小时、首次补费的72小时与出账后缴佣72小时分别沿原确认规则处理。新30天/七天只调整预计结束的可选上限，不替换这些已确认的窗口；范围算法确定前不宣称最长总完成时间已算好。

补费普通改价超时关闭不等于同意对方修改，原有效金额与版本仍在。原窗口已结束且条件齐备可补形成主记录，不以恢复时再给72小时无限平移；实际成功形成月份才是归账月份。首笔未知费用、真实异议、未核验减基和已存在主记录的更正不套用本次普通超时规则。

交付异议由一方提出解除相当于认可本次解除，对方必须明确确认同一版本；运营仍只记录服务异议，不代为解除或裁决交付。有效异议提交时何种资料足以暂停、解除申请数量/撤回/拒绝仍需收口，不把未定项当事实已核验。
