# 闲置取消、改价与完成衔接规则

确认日期：2026-10-14。依据：[第二十轮原题](idle-change-questions-20261014.md)，实际回复“全A”，八题全部A。与[闲置交易规则](idle-transaction-rules.md)、[收费与确认动作](commission-confirmation-rules.md)共同使用。第十九轮拒绝交易的5B继续保留，本轮是独立批准，不推导为同一请求。

## 已确认

| 来源 | 规则 | 边界 |
| --- | --- | --- |
| IC01 / A | 已生效交易任一方申请取消，另一方确认后取消 | 不是卖家单方取消；说明/证据、撤回修改、并发及取消后钱款处理仍待补齐 |
| IC02 / A | 取消无回应保持待确认，不自动取消，原交易继续 | 不满24小时自动关闭，不自动解除交易中限制；提醒及异议细则另议 |
| IC03 / A | 不同意取消理由必填1—300字，该请求结束留历史，交易继续 | 空理由不能作为有效不同意；不是取消交易，不影响旧举报/申诉职责，文本计数和空白处理待定 |
| IC04 / A | 已确认交易金额变更任一方提出，另一方确认后生效 | 真实降价双方确认留历史，降低计佣基数另需运营核验；不覆盖初始价，不证明退款到账 |
| IC05 / A | 同笔交易最多1份待确认改价 | 修改/撤回/不同意/无回应和同时提交冲突仍待明确，不允许多份待确认方案 |
| IC06 / A | 待确认改价须先处理，再确认交付完成 | 可确认、拒绝或撤回，不强制同意；待运营核验的计佣调整与普通改价不同，其完成衔接仍待确认 |
| IC07 / A | 买家确认交付完成后自动标已售、退出在售并恢复联系方式打码 | 不删历史，不把已售当付款；既有联系人权限终止细节、其它私密字段访问及旧单方已售操作衔接另议 |
| IC08 / A | 新流程双方确认交付完成直接开启评分资格，无重复实际经历确认 | 仅新流程完成，不由联系获准、单方已售、待确认完成或取消产生；既有合法资格/评分保留，历史迁移/统计字段待定 |

双方确认取消与不同意取消是不同状态；取消不代表现金结清或退款成功。真实价格确认与计佣基数核验是不同流程，保持原价和版本历史，不允许一方编辑直接减少计佣。5%与20元佣金封顶锁定规则继续有效，获准调整按原锁定规则重算差额，原已出账账单保留。

新闲置评分资格由卖家完成申请加买家交付确认产生，仍沿用原双向三维体系、图文审核/申诉和资格门槛；不改跑腿明确确认资格规则，也不改变维修/其它已确认触发。评分资格不表示图文立即公开、已付款或支付资格通过。

## 验收依据

1. 任一方可提出取消，对方确认前交易仍有效，无回应超过24小时也不自动取消/关闭。
2. 不同意取消理由为0字或301字不能有效提交，明确1—300字可提交；有效不同意结束取消请求、留历史，交易继续。
3. 任一方提出改价、另一方确认才能使新约定生效，最多1份待确认；真实降价未核验批准不自动减少计佣基数。
4. 存在待确认改价时不能确认交付完成，不能以完成自动丢弃该方案；确认/拒绝/撤回处理后才可继续，不能强制认可新价。
5. 卖家仅提交完成申请时仍交易中，买家明确确认交付后才完成；该成功动作自动已售、退出在售并恢复联系方式打码，历史保留，不标支付成功。
6. 新流程双方交付确认后双方获得原双向三维评分资格，不再另走实际经历确认；单方已售、联系获准或取消均不能产生该新资格。
7. 历史合法资格和评分不因本增量删除，图文仍按原审核规则，不扩展用户评分角色或公开权限。
8. 本轮没有确认取消后自动恢复在售、自动退款、运营代确认完成或计佣核验审批等同服务调解。

当前仅验证文档与资源一致性，没有实现或验证真实取消、改价、权限、评分、计佣或支付。完成/取消并发、改价撤回/不同意/无回应、结束权限、重开、金额及证据字段仍未齐备，整体仍非完整上线依据。
