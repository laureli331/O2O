# 时间接受入口与完成收尾：第三轮8题

日期：2026-10-14。状态：实际回复“5B, 全A”，对应1A、2A、3A、4A、5B、6A、7A、8A，结果见[第三轮已确认规则](deadline-completion-entry-rules.md)。以下保留原问题和未选选项，未选选项不用于开发。依据：[第二轮实际1B、其余A](deadline-completion-boundaries-rules.md)。客户先填写、对方明确接受的方向已确认，本轮不重复改变该方向，只收口入口与剩余边界。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（DC01） | 维修/其它怎样接受客户填写的预计结束时间？ | 发布需求时填写，接单员申请时明确接受；发布者选人时再次校验仍在未来 | 选人前向候选发时间确认请求，候选接受后再选人 |
| 2（DC02） | 跑腿怎样接受客户填写的预计结束时间？ | 发布需求时填写，接单员报价时明确接受；客户选报价时再次校验 | 客户选报价前提出时间，候选先确认，再选定 |
| 3（DC03） | 闲置买家填写的时间怎样被卖家接受？ | 买家联系申请时填写，卖家发起交易确认时明确接受并带入，买家确认同一版本 | 联系获准后买家单独提出时间确认，卖家接受后再发交易确认 |
| 4（DC04） | 双方正式确认延期后，自动完成期限怎样计算？ | 新预计结束时间加完整72小时，保留时间变更历史 | 新预计结束时间加原申报窗口剩余小时数 |
| 5（DC05） | 闲置自动完成后怎样公开展示？ | 标“交易自动完成”并退出在售列表；“已售”仍需明确交付确认 | 直接标“已售”，同时展示自动完成来源 |
| 6（DC06） | 自动完成后，费用凭据还能查看吗？ | 与明确完成一致：双方关闭查看权限，保留费用文字历史 | 费用待处理期间保留原双方凭据查看，处理结束再关闭 |
| 7（DC07） | 补计佣的72小时窗口内，正式费用又改了怎么办？ | 金额变更须双方确认，不重置窗口，保留原截止；有效异议仍有处理出口 | 金额变更生效后重新给72小时，仅改备注不重置 |
| 8（DC08） | 有效交付异议解除后，自动完成期限怎样恢复？ | 从解除成功时间与当前约定预计结束时间中较晚者重新72小时 | 沿原窗口剩余时间；原期限已过则满足条件后自动完成 |

第1/2题A将预计结束时间作为对应发布入口所需时间，报价/申请须对当前版本明确接受，不把空金额强制为0、不用默认勾选同意。选人/选报价仍按此前既定确认，不新增接单员二次接单；提交后时间版本变化与旧申请/报价失效需继续细化。B引入选定前的独立时间接受动作，其可见对象与明确接受记录后续设计，不自动解码联系方式或新增聊天。

第3题客户为买家、对方为卖家，时间先由买家提出，不将卖家发起交易请求误当时间由卖家先设定。A的联系人选择仍仅针对该帖已获准买家；时间的读取版本和交易发起前过期处理后续补齐。时间接受、联系获准本身不解码，仍需有效交易确认及已同意规则，金额仍须明确。B也不允许联系阶段先泄露完整地址或电话。

第4题不单方延期，不以多个请求重复累计延长。A重新计算的是最终完成期限，不重复加两轮72小时，不恢复已完成/已取消流程。延期期望时间的未来校验、能否提前、与待确认费用/异议冲突、截止瞬间更新仍需明确。B须定义准确剩余时长及暂停口径，不擅自当作已批准算法。

第5题都不将系统到期作为付款、真实交易额、交付已核实或主收入证据。A保留原明确完成后已售方向；自动完成来源在公开详情如何显示、允许谁恢复在售以及重开后新交易权限另定。B的“已售”是产品展示来源，不自动将它放入真实交付已核实统计。

第6题只讨论原费用凭据的双方查看权限，不新增上传、重新授权给新交易当事人或运营查看。A不删除费用文字历史或阻止处理费用；文件保存/删除时限另定。B须进一步界定待处理费用及终止权限时点，不默认无限期保存、公开或重新查看此前已关闭凭据。必要电话恢复仍是独立待定项。

第7题只针对DA06尚未形成主计佣记录的补费窗口，不改已存在主记录的更正流程。A针对正式金额版本生效的变更保留原截止，变更待确认时不自动同意或偷用旧金额处理未决争议；若截止后才形成最终有效费用，准确补录/异议边界仍需收口。B只有真实金额变更后生效才重置，备注等不重置，不允许未经批准真实降价直接减佣。两项均不重开自动完成流程或重置主记录的首次归账月份。

第8题仅讨论有效交付争议暂停的流程计时恢复，不授予一方自行解除或运营服务调解/交付裁决权。A衔接此前SB05计佣恢复公式的方向，但仅明确本题自动完成时钟；补费窗口与部分金额异议时钟另行核对。B到期后也需无有效阻断，不能把未解决异议当自动解除。解除主体、双方确认/核验依据和原评分资格处理仍需补齐。
