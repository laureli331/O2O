# 佣金金额与账单缴纳规则

最新当前标准：跑腿15%不封顶，维修15%上限30元、闲置5%上限20元、其它10%上限20元；各业务锁定动作见[第十八轮规则](commission-confirmation-rules.md)。以下第十五轮及后续历史索引按当时状态保留。

后续第十七轮：[封顶计算规则](commission-cap-rules.md)已明确获准调整按原规则重算差额、跑腿不封顶及封顶单位/锁定方向；金额尚未确认，建议30/20/20元不可当生效配置。

后续确认索引：第十六轮已确认其它10%，维修/闲置/其它封顶（金额未定），并明确调价、截止与欠费处理，最新见[费率落地规则](commission-operation-rules.md)。以下保留第十五轮当时的记录。计算样例仅检验比例与舍入，未应用后续封顶，不可当实际最终佣金。

确认日期：2026-10-13。依据：[第十五轮原题及实际回复](commission-billing-questions-20261013.md)。第1题部分数值确认、第6题自定义，其余A；与[第十四轮规则](monthly-commission-detail-rules.md)共同使用。历史决定保留，新增本轮记录，不将建议补成确认。

## 本轮已确认

| 来源 | 规则 | 边界 |
| --- | --- | --- |
| CB01 / 自定义 | 跑腿15%、维修15%、闲置5%；其它未确定 | 结构化记录为1500、1500、500基点，其它为null；null不是0%，也不是沿用维修15%。允许的配置范围、精度及发布生效流程仍待确认 |
| CB02 / A | 每笔合格交易按已锁定比例计算佣金，再按业务汇总 | 不先合计金额再舍入，不用月底新比例替换旧比例；服务费与闲置成交价方向不变，阶段与成交字段映射仍待补齐 |
| CB03 / A | 每笔计算四舍五入到小数点后2位 | 用精确金额计算，不能依赖浮点误差；本规则不确定后续差额应采用原佣金重算差还是直接对金额差计佣 |
| CB04 / A | 获准差额抵扣超过本月应缴，剩余继续结转抵扣，不自动退现金 | 不表示放弃退款权利；跨业务抵扣、账户注销、争议余额及余额先后顺序未定，无居民钱包 |
| CB05 / A | 探索小程序内支付平台佣金，资格通过后启用 | 只确认方向，收款主体、实际产品/接口及资格尚未核实；无自动扣款，不代收客户交易款，不以凭据或支付请求作为收款成功 |
| CB06 / 自定义 | 出账成功后72小时内应缴清 | 从实际出账成功时刻起连续72小时，不是7天、15天或三个自然日；成功定义、截止瞬间、宽限、支付在途与提醒细则未定 |
| CB07 / A | 逾期提醒，并限制新的接单/闲置交易，保留旧服务处理和申诉入口 | 限制具体动作、跨业务影响、争议账单和恢复条件仍待确认；不取消旧单，不阻断履约、必要取消协商、费用异议、举报/申诉，无自动罚金 |
| CB08 / A | 上月账单计划次月1日00:10生成，时区Asia/Shanghai | 月份仍按完成/成交成功月份；失败不能标成功，也不能启动72小时期限；失败重试、晚到数据和月末截止边界未定 |

已确认三项费率不代表真实计佣或收款可以启动。其它费率、实际支付资格、业务确认动作及金额映射未齐，整体仍不能据此实施收费。“其它10%”以及闲置佣金封顶等评估均未获用户确认。第十四轮结构化记录保留当时的数值未定状态，本轮独立记录后续确认。

以下是设计验收样例，非真实交易、利润或到账证明。扣佣后金额尚未扣除服务者成本；个人页仍沿用HD02，不改为扣佣后收入。

| 业务 / 样例基数 | 锁定比例 | 该笔佣金 | 扣佣后金额 |
| --- | --- | --- | --- |
| 跑腿12.00元 | 15% | 1.80元 | 10.20元 |
| 维修服务费100.00元 | 15% | 15.00元 | 85.00元 |
| 闲置成交价1000.00元 | 5% | 50.00元 | 950.00元 |
| 跑腿0.10元（舍入边界样例） | 15% | 0.02元 | 0.08元 |

- 两笔各0.10元、各15%：每笔0.02元，汇总0.04元；不能先合计0.20元再得0.03元。此金额仅检验舍入，不新增最低可交易金额规则。
- 原比例15%已锁定、之后新交易改10%：旧交易仍用15%，不回溯改费率。
- 本月应缴20元、获准抵扣30元：本月应缴为0、剩余10元待后续抵扣；不标现金退款成功。跨业务是否可抵扣仍待确认。
- 假设账单2026-11-01 00:10:00（Asia/Shanghai）真实出账成功，72小时参考时刻为2026-11-04 00:10:00；若实际晚到01:00成功，应从01:00计算。截止瞬间的判定留待下一轮。
- 定时任务失败、账单未生成：无已出账状态，无缴款倒计时，不能以未缴理由限制用户。
- 已存在服务及合法异议/申诉入口在欠费时仍可处理，不拿佣金欠费强制结束服务。
- 其它比例仍null，不能参与真实计佣或显示“默认15%”；是否阻止新的交易确认另待用户明确。
