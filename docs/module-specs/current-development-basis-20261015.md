| 首页/分类 | 跑腿、维修、闲置、其它。其它首期不强制细分、不接许可服务；免费目录仍只维修/跑腿。见[第二轮CQ21/22/31](business-closeout-round-2-rules-20261015.md)。[选定图交接](../ui-development-handoff/README.md)是视觉依据，示例图用占位 |
| 商家Banner | 原优选区域替换商家Banner，商业规则另议，旧价格/套餐/数量/分类不继承。见[方向](merchant-banner-direction-20261015.md) |
| 申请与选人 | 维修/其它先申请后选1人；申请及同时接单不设产品上限；同人同需求1有效申请，选前可改/撤，申请不强制报价，预估不算正式价。见[申请](application-rules.md)、[展示历史](application-detail-rules.md)、[排序重开](application-reopen-rules.md) |
| 选择与联系 | 发布者成功选定直接生效，不二次接单；只合法双方解码，其他申请者仍打码。结束后打码且关闭对方私密地址；处理费用可双方同意临时恢复电话24小时，不恢复地址/旧凭据。见[选人](application-rules.md)、[CQ26—28](business-closeout-round-2-rules-20261015.md) |
| 起止时间 | 需求发布填开始日期/时间和服务到期；“有效期”只指服务到期，不另造找人截止；闲置沿已批准的买家提时间、卖家/买家交易确认入口接受。选人时开始已过，先重约未来时间、对方接受。见[NE01/02、CQ25](business-closeout-round-2-rules-20261015.md) |
| 到期与延长 | 无有效异议则到期自动结束，不额外72小时；无接单员“已办完”或客户“确认完成/收到”。初次从交易确认起最多720小时，每次从原有效到期最多延168小时，双方同意，未同意不改期限。见[NE03/05](business-closeout-round-2-rules-20261015.md)、[期限](deadline-completion-clarification-rules.md) |
| 异议与取消 | 有效交付异议暂停；到期前解除等原到期，到期后解除不额外72小时。双方确认取消才取消；普通未决取消不单独阻断到期。取消不代表结清、不恢复旧申请/授权。见[当前到期](business-closeout-round-2-rules-20261015.md)、[异议取消](business-closeout-round-1-rules-20261015.md)、[原取消边界](exception-rating-rules.md) |
| 费用 | 维修/其它分阶段、收费前双方确认；服务费/实际支出分开，未知不填0，明确免费可0。阶段仅当前有效版本累计；单项/方案/整次99,999.99元上限保留。结束后可双方补录同次已发生遗漏费用，不重开流程。见[基础](fee-rules.md)、[字段](fee-detail-rules.md)、[边界](fee-boundary-rules.md)、[累计](closing-rules.md)、[后续CQ20](business-closeout-round-1-rules-20261015.md) |
| 改价/佣金 | 真实改价双方确认、保留初始价；减少计佣基数另须运营核验。跑腿15%不封顶；维修15%整次30元；闲置5%每笔20元；其它10%整次20元。按各业务确认动作锁定，不倒改旧标准、不重复阶段封顶。见[调价](commission-operation-rules.md)、[最终标准与锁定](commission-confirmation-rules.md)、[封顶](commission-cap-rules.md)、[核验材料](business-closeout-final-partial-rules-20261015.md) |
| 月账单 | 客户线下付对方，平台只月结自身佣金、主动缴纳，不自动扣款或代收客户款。计划次月1日00:10、实际出账成功后72小时；每笔到分后汇总；获准差额下月留痕抵扣，可跨同账号业务、先抵较早到期。见[账单](commission-billing-rules.md)、[后续CQ15—19](business-closeout-round-1-rules-20261015.md) |
| 欠费/账单异议 | 争议部分暂停，无争议原期限不变；核验后应缴确定且补充通知成功生成，争议余额再给72小时。同理由旧材料重复提交不再次暂停，新材料经受理可暂停。欠费阻四类新接单/卖出，不阻浏览、免费发需求、旧处理与申诉。见[首轮CQ15—19](business-closeout-round-1-rules-20261015.md)、[CQ39](business-closeout-final-partial-rules-20261015.md) |
| 个人页金额 | 仅本人跑腿正常到期、有效服务费已确认且无有效交付异议；按服务费累计，排除垫付/货款/本人支出、不扣佣金，注明系统统计和非到账，未知不填0。见[NE04](business-closeout-round-2-rules-20261015.md) |
| 评价 | 既有双向三维与业务/角色分开、自愿评价保留；自动到期不生成评分。有有效交付异议暂停未提交评分、解除后新7天；不自动删已有合法评分，取消不新增资格。见[评价基础](../prd.md)、[自动到期评价](deadline-completion-rules.md)、[后续CQ13](business-closeout-round-1-rules-20261015.md) |
| 通知 | 跑腿仅自动结束通知双方一次；维修/闲置/其它到期前24小时双方一次、结束后一次。此例外只覆盖到期通知，费用/选人/异议消息仍在。同待回复请求≥24小时主动提醒；站内为主、微信有条件授权。见[CQ32—34](business-closeout-round-2-rules-20261015.md) |
| 运营/看板 | 本人和伙伴共用本人一个管理账号，无成员分级/双人复核；账号鉴权与日志保留，不识别实际操作者。四类分开统计自动完成/取消/异议及佣金应缴/实缴，不证明客户款到账。见[最新账号与CQ37](business-closeout-confirmed-20261015.md)、[看板](business-closeout-final-partial-rules-20261015.md) |
| AI | 不扩大原有整理业务到维修/其它；跑腿明确起止时间可提候选，用户确认，不明留空、不自动发布。见[原合同](../prd.md)、[CQ35](business-closeout-round-2-rules-20261015.md) |

## 覆盖关系与未定边界

1. 普通到期不加72小时；首次补费申报、出账缴佣、争议核验后补缴这三个72小时仍保留。
2. 自动完成不是实际交付或客户付款确认，平台佣金实缴也不是客户线下实付额。
3. 历史长摘要中的手动完成、两独立账号、旧72小时收尾不能当当前需求；不存在运行系统或存量订单迁移。HD05标签仅为旧视觉，当前真实时间字段按NE01。
4. 费率/封顶确认不等于主体或支付资格已通过；30天是实际启用后的检查点，不是仅收费30天。
5. [本次五题](shared-understanding-confirmed-20261015.md)已明确全A：取消后重开按重开时间排序；关闭理由仅发布者/受影响申请者看；首版无独立返修流程但保留原救济；注销抵扣转人工核对、不直接清零；阶段可同名但按编号/建立顺序独立累计。原45题及实际回复不改，Banner仍延后。
