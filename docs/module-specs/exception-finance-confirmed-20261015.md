## 3. EA01：客户拖欠与平台佣金异议

- 已交付且约定费用有效但客户拖欠，允许佣金承担方使用现有账单异议入口，选择相关交易、争议佣金金额和原因。只处理本人有权账单，沿用附件和重复异议规则；提交不证明欠款或减免成立。
- 有效账单异议只暂停争议部分催缴及该部分欠费限制；无争议部分原期限和其他限制原因不变。核验结束、应缴余额确定且补充缴款通知生成成功后，再给应缴争议余额72小时。
- 客户未付款不自动免佣，不改为按实收计佣，不新增客户线下实付总额采集。运营只核验平台自身收费处理，不追讨、裁判或代收客户款。
- 付款纠纷申请不自动成为交付异议，不重开已结束交易、不自动暂停评分或回滚佣金；如另有合格交付异议，按其原规则独立处理。

## 4. EA02：可核实的平台故障保护

- 记录故障标识、日志/证据来源、受影响功能及交易范围、故障状态、恢复验收结果与成功时点。只有影响登录或异议提交、可核实的本平台故障适用；无关模块故障、客户端单方自报、用户断网或微信通知未送达不触发全站保护。
- 故障未恢复验收通过时，受影响交易暂停自动结束及相应主计佣记录形成。无关交易与无争议账单不据此暂停；本条不新增全部缴款倒计时的自动顺延。
- 恢复验收通过后，保护截止＝原有效服务到期与恢复验收成功时点＋24小时中较晚者。保护截止瞬间收到的有效异议仍及时；严格超过保护截止、故障已恢复且无其他有效阻断时，才可自动结束/依原费用规则计佣。
- 保护是自动收尾条件，不改双方服务开始/到期约定、双方同意的延期记录、费率/封顶快照，也不把普通交易统一增加24小时。保护内发生有效交付异议，仍须按原双方解除规则处理。
- 同一故障/恢复事件重放不刷新保护截止；再次发生可核实的受影响平台故障时重新暂停，恢复后取仍适用的较晚保护截止，不缩短已有保护。用户刷新页面不是新故障或新验收。
- 已确认取消不被故障保护复活，实际支付/退款事实不自动回滚；恢复验收需核对异常结束/计佣，必要更正保留历史并依原平台费用权限处理，不伪造回到过去的结束或归账时间。

## 5. EA03：分次缴款、多收退回与零应缴

- 可以分次缴纳；仅实际通道核实成功的款项计入付款事实。按最早到期的当前可缴应缴项分配，分配明细保留；受理暂缓的争议部分不自动占用无争议应缴款，其他账号不能获得抵付。
- 未缴余额仍按其原期限判断逾期，不因部分缴纳重新给72小时或自动全部解限。核实全部逾期应缴结清才解除欠费原因，其他违规限制不变。
- 同一支付交易的重复回调只记一次，不算重复实际付款。不同真实支付造成多缴/重复实收，保留各次支付事实及核对依据，超过当前应抵付的部分记为多收待退，不计作新增应缴、正常抵扣余额或平台收入。
- 核对后按实际通道能力退回多收部分；无法原路退回转人工核对处理。退款状态至少区分待核对、待退回、处理中、已退回、失败/结果未知；只有可核对的成功结果标已退回，申请/截图不算成功，不重复退款。
- 多收款退回与核准佣金更正产生的抵扣分别建记录、分别统计，不让退多收导致已经有效抵付的佣金再次欠缴，也不把原抵扣一概自动变成现金退款。
- 应缴为0显示“无需缴纳”、不创建0元支付、不伪记已实际缴款。存在暂缓争议时仍标争议处理中；本期0不解除其他历史逾期或违规限制。
