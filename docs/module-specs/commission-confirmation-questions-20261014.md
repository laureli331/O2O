第1题A是本轮对三个数值的明确批准，B需填写；不是把建议回写为第十七轮答案。第2—3题之前仍需完成承担佣金方规则展示及知悉；具体界面节点/证据后续补齐，不以发布者的操作代替接单员知悉。第2题B还需明确选定后、首次费用确认前完成取消/免费服务等情况下的版本来源。

第4题确认交易不是联系获准或已完成成交，不开放多个有效交易、取消、退款或支付新规则；其并发数量、候选买家与联系方式权限另议。第5题A沿用金额须明确，不将面议/空值当0；允许范围、最低值及字段约束待确认。B可能暂缺金额，不能据此产生虚构计佣数值，基数和确认补录流程另议。

第6题不恢复旧申请/联系方式授权，不自动复制旧费用生效或把已取消服务当已完成计佣；计佣交易与原需求标识分开规划，具体字段未指定。第7题真实约定降价已确认但降低计佣基数未获运营批准时，不能以真实新价自动减少预估佣金；不把预估当实际应缴或已到账。双方费用确认仍是独立动作。

第8题只确定评估时点，不自动到期免佣、涨降费率或解锁旧交易；启用须满足资格和业务规则，不把文档确认日期当正式启用日。评估指标/样本量/调整审批另议。
