# 维修和其它：费用表单与预约基础

确认日期：2026-10-12。依据：[第八轮表格8题](form-appointment-questions-20261012.md)，用户实际回复“全A”。以下为业务约束，不是已实现的字段或接口。与[收尾规则](closing-rules.md)、[费用边界](fee-boundary-rules.md)、[履约规则](fulfillment-rules.md)共同使用。

## 已确认规则

| 来源 | 决定 | 边界 |
| --- | --- | --- |
| DQ01 | 取消时，双方一致认为费用方案全部已发生才保留待确认 | 有分歧或未明确时关闭留历史，可重新协商；不阻止取消，不代表认可金额或结清 |
| DQ02 | 重开后，新服务双方中原本有权查看旧方案的人可复制 | 不仅限发布者；无旧方案访问权的人不能借此看旧历史，角色相同不自动有权 |
| DQ03 | 复制阶段、费用项目文字、金额、备注；垫付条件重新填写 | 不复制旧凭据、旧垫付条件或旧授权；新草稿须重新提交、由新双方确认 |
| DQ04 | 选择不垫付时，隐藏上限、清除当前表单值 | 不修改或删除历史有效约定；未提交并确认的新选择不撤销原有效垫付条件 |
| DQ05 | 不同意完成/取消的理由必填1—500字 | 不改变费用方案不同意理由选填、完成/取消/异议说明1—500字或评分文字规则 |
| DQ06 | 完成/取消/异议附件为JPEG/PNG，每张不超过5MB，沿用共同图片规则 | 选填0—9张，校验真实格式；费用凭据仍每支出项目最多3张/5MB，评分图片数量规则不变 |
| DQ07 | 发布者和接单员均可提出预约或改期，另一方确认 | 选人成功且服务未结束时适用，预约仍选填，未确认新时间不替换原有效预约 |
| DQ08 | 同一次服务，预约/改期合计最多1份待确认 | 不是每人各1份；双方同时提交仍需守住1份，冲突提示及撤回/修改规则待确认 |

## 与历史和授权的衔接

已发生范围的共同判断与费用金额确认分开记录：双方可以一致认为全部已发生，却仍未同意价格，此时取消后方案仍待费用确认；不能把范围判断当作金额已确认。没有一致判断或存在未发生费用时，取消仍可确认，待确认费用方案关闭留历史，之后仍可就已发生费用重新协商。

复制以新服务当事人身份和旧方案原有访问权同时校验，不能仅凭需求编号或新服务接单员身份读取旧服务私密费用。复制为草稿，费用是否已发生不自动继承为新服务事实；阶段如何关联及各表单字段映射仍需整理。当前新增复制入口不授予旧凭据访问，也不恢复已结束服务联系方式或完整地址。

不垫付的表单清值只影响当前编辑内容，历史版本保留；有效约定的变化仍需提交新费用方案并双方确认。再次选择愿意垫付，不能自动带回已清除上限，须按既有必填规则重新录入，上限0仍表示不能实际垫付。

## 验收依据

1. 双方一致判断全部已发生但价格未确认时，取消后方案仍待确认；判断有分歧、未明确或含未发生费用时关闭留历史，不阻止取消、不自动确认金额。
2. 新服务接单员无旧方案查看权时不能复制或读取旧费用；原本有权且属于新服务双方的人可以复制，不能仅限制为发布者。
3. 草稿复制包含费用文字、金额、备注和阶段，垫付条件须重新填写；不带旧凭据、旧授权或新服务已发生标记，不自动生效。
4. 不垫付隐藏并清除当前上限，再选择愿意垫付时应重新填；未确认新方案不能抹掉旧有效约定。
5. 不同意完成/取消的理由空白或超过500字时阻止提交；合法理由结束该次申请、不结束服务，继续沿用第七轮规则。
6. 0张附件不阻断合法说明，最多9张；非JPEG/PNG或超过5MB不可上传。费用凭据仍最多3张，不能因完成附件数量而放宽。
7. 任一服务方可提出预约或改期，但只有另一方确认后生效；选人前、服务结束后或非该服务双方不能使用该动作。
8. 任一方已有待确认预约/改期时，不能再产生第2份；未确认改期不覆盖旧有效时间，不因无回应自动改期。

当前仅验证文档与决定一致性，没有实现或验证实际文件上传、复制权限、字段清值或预约并发行为。
