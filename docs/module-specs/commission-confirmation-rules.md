# 封顶金额与交易确认动作规则

确认日期：2026-10-14。依据：[第十八轮原题](commission-confirmation-questions-20261014.md)，实际回复“全A”，八题全部A。与[封顶计算](commission-cap-rules.md)、[费率落地](commission-operation-rules.md)及账单规则共同使用；本轮首次批准具体上限，前轮未批准建议的历史保留。

## 当前收费标准

| 业务 | 比例 | 平台佣金上限 | 单位与锁定 |
| --- | --- | --- | --- |
| 跑腿 | 15% | 不封顶 | 发布者成功确认选择报价方案时锁定比例 |
| 维修 | 15% | 30.00元 | 同次服务全部阶段合计，只封顶一次；发布者成功选定接单员时锁定比例和封顶 |
| 闲置 | 5% | 20.00元 | 每笔交易封顶；卖家发起，买家成功确认后锁定比例和封顶 |
| 其它 | 10%（试运行） | 20.00元 | 同次服务全部阶段合计，只封顶一次；发布者成功选定接单员时锁定比例和封顶 |

三类封顶是佣金上限，不限制双方约定的服务费/成交价，也不是每月或账号的累计上限。标准修改只用于新确认交易；已锁定标准不按完成日或月底配置替换。客户款仍直接支付给对方，不因比例/封顶批准产生实际付款或收款资格。

## 本轮确认的动作

| 来源 | 已确认 | 尚需补齐 |
| --- | --- | --- |
| CT01 / A | 维修30元、闲置20元、其它20元正式批准 | 配置字段允许范围/精度、收费公示/生效流程、历史交易适用仍待定 |
| CT02 / A | 维修/其它在发布者成功选定接单员时锁定比例与封顶 | 承担佣金方须在此前知悉规则；具体界面/版本核对及并发未定 |
| CT03 / A | 跑腿在发布者成功确认选择报价方案时锁定比例 | 草选、提交报价或失败/未知结果不算锁定成功；报价时到选择时规则变化的告知仍待定 |
| CT04 / A | 闲置卖家发起交易确认，买家确认后生效 | 发起对象、数量、版本/无回应/撤回/不同意、交易中公开展示及完成/取消规则未定 |
| CT05 / A | 闲置面议需先填双方约定的明确金额，再确认交易 | 面议仍可发布，空值/面议不是0元；金额范围、最低值及真实成交金额映射未定 |
| CT06 / A | 维修/其它取消后重开并重新选人，新次服务独立锁定且独立封顶 | 不继承旧申请、联系方式权限或旧费用生效，不把取消服务当完成计佣；每次服务与原需求的标识映射未定 |
| CT07 / A | 费用变更确认后展示按当前已确认计佣依据算的预估变化，不重复知悉 | 费用方案仍须双方确认；真实降价的计佣减少仍须核验批准，不把预估当已缴/已到账 |
| CT08 / A | 方案正式启用后30天评估费率和封顶 | 正式启用尚未发生，不从文档确认日计时；准确起点/日界、样本/指标及后续调整审批未定，不自动到期免佣或涨降 |

锁定比例/封顶与确认双方具体金额是不同事实。维修/其它选人时仍不强制报价，金额未知仍待协商；不能把选人时发布预算、自愿预估或空值当正式服务费。缺失比例/封顶的新交易确认阻断规则继续用于未来配置缺失情形；本轮具体上限齐备不消除其它业务、支付和资格缺口。

闲置买家确认是事前双方确认交易，不是交付完成、客户付款成功、卖家标已售或评分资格。旧PRD的联系获准、单方标已售不足以认定真实成交/评分等边界保留，新增成交确认及评分衔接后续规划。

## 验收依据

1. 当前四类比例15%/15%/5%/10%，佣金封顶分别不封顶/30元/20元/20元，不将全部业务都封顶20元。
2. 维修全部阶段合格服务费250元按15%计算，封顶后30元；其它服务费250元按10%计算，封顶后20元；材料等实际支出分类仍分开，具体计佣字段映射待补齐。
3. 闲置800元基数按5%封顶20元；获准调整至600元仍20元，至300元变15元，差额-5元；不直接按减少500元×5%=25元减佣。
4. 维修/其它成功选人锁定标准，但不产生未确认服务费金额；跑腿提交报价、草选、失败/未知结果不锁定。
5. 闲置卖家发起但买家尚未确认时交易未生效；联系获准和单方已售不能替代本次确认；面议须先确定明确金额。
6. 新次服务独立锁定并独立封顶，不恢复旧授权，不把同需求所有历史服务累计共享一次封顶。
7. 费用变更显示预估，不新增重复知悉动作、不取消原费用双方确认或计佣减少核验；历史原账单仍保留。
8. 30天仅为正式启用后的评估安排，不标已启用、不安排自动扣费或自动改标准，不改变HD02个人收入口径。

当前仅验证文档、计算样例和资源一致性，没有实现或验证真实交易、支付、计佣、计时或权限；本文件不是完整上线依据。
