# 维修和其它：费用边界

确认日期：2026-10-12。依据：[第六轮8题](fee-boundary-questions-20261012.md)，实际选择1B、2B、3B、4A、5B、6B、7A、8B。本文件与[费用规则](fee-rules.md)、[费用录入规则](fee-detail-rules.md)共同作为业务依据，不定义实际接口或存储字段。

## 衔接和权限

完成后费用只读与取消后费用协商是两条不同规则；不能将只读限制扩大到已取消服务，也不能用取消后的许可绕过已完成服务只读。第七轮已确认完成前须处理未决费用；取消时仅已发生费用方案继续待确认，含未发生费用的关闭留历史。已发生判定仍待明确，不自动确认金额。详见[收尾规则](closing-rules.md)。

结束后关闭凭据访问，服务端同样必须执行；不能只隐藏图片组件而继续向双方下发可访问的图片地址。已有缓存或用户此前保存的副本不能被声称已远程删除。原文件保留与删除时限仍需另行确认。

取消后费用协商仍不恢复联系方式、完整地址或旧凭据权限。取消后补费用是否可新上传凭据尚未确认，不能擅自绕过结束后的访问限制。重开产生新服务，复制文字草稿不等于新双方认可；旧凭据不因复制自动向新接单员开放。

## 验收依据

1. 选择预设阶段或合法自定义名称均可使用；不因提供预设而自动生成必收检查费。
2. 已完成服务不能新增、修改或确认费用以改变约定；已取消服务仍按此前规则协商已发生费用，待确认方案收尾按第七轮执行，已发生判定另议。
3. 愿意垫付但上限空白不能提交；0可明确记录，但不产生可实际垫付额度；未确认的新上限不生效。
4. 超出当前上限可暂停该项垫付；只有新方案和新上限双方确认后才能依据新条件垫付，服务不自动取消。
5. 每个支出项目可无凭据；第4张、非JPEG/PNG或超过5MB均应阻止上传，不要求付款证明。
6. 完成/取消后原双方都无法再从服务端取得凭据图片，费用文字仍可查看；新接单员不取得旧凭据权限。
7. 单项不超上限但20项合计超99,999.99元时也不能提交；版本替换不能重复计费或自动视为付款。
8. 复制旧费用生成新草稿，只能重新提交并由新服务双方确认后生效；历史约定、授权及旧凭据访问不继承。

当前仅验证文档一致性，没有实现或验证真实金额计算、文件访问撤销、草稿复制或服务端操作。
