## 与已有规则的衔接

初始预计结束时间由客户提出，另一方明确接受同一版本，仍在各业务既定交易确认动作中生效。维修/其它的发布者选人后无需接单员再次接单；跑腿仍由发布者选报价；闲置仍卖家发起、买家确认交易。具体在哪个既有动作中接受时间见下一轮，不把“客户先填”当单方设定或事后随意修改授权。

预计结束加连续72小时仍是正常自动完成期限，两个时间展示。到截止时点不直接执行自动完成，要超过该时点并满足条件；有效未完成/未成交/取消争议仍暂停。普通延期、普通待确认取消均不能单独长期阻断；真正已确认取消与明确完成的有效结果保留，不重复结束或计佣。相同时间多个操作、异议有效性、已完成后的新异议更正继续补齐。

自动完成时费用未知/待确认，流程完成而费用转待处理，不关闭费用入口。后来首次正式费用生效后，给连续72小时申报窗口，无有效阻断才能形成计佣记录，不能按自动完成时间倒填记录月份。这个时钟服务于补计佣，不让交易再次变进行中；也不是出账后缴佣72小时。其截点、费用再次变更/待确认、部分金额异议、知悉与通知细节仍须单独确定，不把DA04自动完成的截止规则擅自套到所有财务计时。

同一交易仍只形成一份主计佣记录；维修/其它整次服务阶段合并只封顶一次，沿已锁定费率/封顶及核验后计佣依据。未知金额不是免费，未经批准降价不直接减佣。已形成记录后金额改变按既有更正/差额方向，不能再当首次正式费用重计一笔。

个人页仍执行AF07/B：主收入只统计明确交付确认的本人跑腿服务费，排除垫付款、非到账，自动完成部分详情单列。AF08/A的自动完成后无有效交付争议可自愿评价继续保留，不把评论资格当真实交付、主收入或客户付款证明。

自动完成后普通延期/取消请求关闭留历史；费用待处理仍可由原双方依法约定的有效权限处理，不因此自动取得完整联系方式、地址或费用凭据查看权。费用文字历史与费用确认入口可以保留，必要联系恢复和凭据权限须按后续选择，不能将“处理费用”无限扩展成所有私密附件可见。当前没有新增在线聊天、客服代发联系或运营查看权限。
