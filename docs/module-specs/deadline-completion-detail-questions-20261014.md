# 时间版本与异常处理：第四轮8题

日期：2026-10-14。状态：实际回复“1B, 2设三天长期服务再由双方延期, 3B, 全A”，对应1B、第2题自定义三天、3B、4A、5A、6A、7A、8A，见[第四轮已确认规则](deadline-completion-detail-rules.md)。第2题不是原A的30天，也不是原B的不限；三天的计时口径仍待下一轮确认。以下保留原题与未选选项，不用于覆盖实际回答。依据：[第三轮实际5B、其余A](deadline-completion-entry-rules.md)。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（DT01） | 预计结束时间恰好等于确认时的当前时间，允许吗？ | 不允许，必须严格晚于服务端当前时间 | 等于时允许，已经过去才阻止 |
| 2（DT02） | 初次/延期预计结束时间最远可选多久？ | 距确认时最多30天，长期服务再由双方延期 | 不设统一最长周期，只要求符合未来时间校验 |
| 3（DT03） | 跑腿发布后修改预计结束时间，旧报价怎么办？ | 旧报价失效并通知，接单员须重报并接受新时间 | 保留报价金额，选定前须重新明确接受新时间 |
| 4（DT04） | 闲置买家的时间过期，联系关系如何处理？ | 已获准联系保留；买家更新时间，旧待确认交易先撤回，卖家重新发起 | 联系失效，买家重新申请并获准后再发交易确认 |
| 5（DT05） | 待确认延期申请谁能撤回？ | 仅发起方撤回，对方可同意或不同意 | 交易双方都可撤回该请求，原有效时间不变 |
| 6（DT06） | 延期能否把预计结束时间提前？ | 只允许向后延长，提前完成走明确交付确认 | 可提前或推后，但须双方确认；相同时间不刷新窗口 |
| 7（DT07） | 已有有效费用后，补费窗口内的改价请求无人回应？ | 提交成功后24小时未确认就关闭调整，原有效费用保留；真正金额异议另处 | 一直待确认，继续阻断计佣，直到确认、拒绝或撤回 |
| 8（DT08） | 有效交付异议由谁解除？ | 双方明确同意解除后恢复；运营只记录，不代为裁决 | 新增运营按证据核验并解除的职责，双方仍可申诉 |

第1题以服务端确认事实判断，不按设备时间；第2题30天只是待确认的初版范围提案，不是已批准业务时长或真实业务统计。若选A，30天指连续30×24小时，从初次/延期确认时点计算，不是自然月；范围本身不代表固定结束时间，客户仍需填写、对方明确接受。最大范围对长任务、输入与选定时校验的衔接需后续明确。若选B，不擅自设置7天、30天或其他隐藏上限。

第3题只新增跑腿旧报价对结束时间变化的处理，维修/其它已有时间变更使旧申请失效的方向保留。A重报不继承旧版本的接受，也不改变已选交易费用；B须保留金额与接受版本、选定时校验当前认可，不新增选定后的接单员二次接单。无实际变化编辑、排序和并发另议。

第4题只适用于尚未生效交易的原已获准联系买家，不单方修改已生效期限。A不延长/扩张联系方式或地址授权；仅联系获准仍不解码。仍须卖家接受新时间、买家确认同一版本及明确金额；旧待确认交易撤回留历史，不静默编辑对方已认可版本。时间更新入口、过期请求及数量限制另定。B不删除原历史，不把失效当买家同意交易或取消已生效交易。

第5题不撤回已确认的延期结果，不改变当前有效时间，修改仍先撤回再重提；拒绝理由和文字计数后续补齐。第6题A的延期新时间必须晚于原有效预计结束，未来时间和最大范围按本轮选项核对；提前明确完成仍沿既有交付与费用条件，不以相同时间刷新窗口。B需要明确提前后的完整72小时、通知与范围，不能以单方提前侵害已约定时限。

第7题A只针对流程已自动完成、尚未形成主记录的补费窗口里已有有效正式金额后的普通调整请求；关闭未确认请求不等于同意调整，原有效金额和版本保留。它会细化此前费用变更无回应保持待确认的方向，不用于首次正式费用尚未知、有效未成交/未完成/金额争议。真实异议仍按暂停/核验，不用旧金额越过未解决争议。24小时从请求成功生效算，通知、拒绝、并发与截止后恢复形成记录的准确条件仍需明确，不直接倒填记录月份或重复封顶。

第8题只讨论有效交付异议导致流程暂停后的解除，不把双方对规则/预计时间的同意当解除同意。A不能用一方点击或沉默自动解除；真正金额异议的计佣核验与服务调解是不同职责。B增加原运营只记录服务异议之外的核验/解除职责，不能推导为运营确认真实交付或代客户付款；证据、申诉和执行界限需进一步确认。不论A/B，本轮没有实现异议核验或断言可以防止全部线下规避。
