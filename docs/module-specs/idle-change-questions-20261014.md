# 闲置取消、改价及完成衔接：第二十轮8题

日期：2026-10-14。状态：8题全部待答，A为推荐提案。依据：[闲置交易规则](idle-transaction-rules.md)及[收费与确认动作](commission-confirmation-rules.md)。上轮5B只用于拒绝待确认交易，不自动应用于取消理由；本轮补齐不同动作，不预设同意、已付款或退款到账。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（IC01） | 已确认的闲置交易，谁可以申请取消？ | 买卖双方任一方申请，另一方确认后取消 | 仅卖家申请，买家确认后取消 |
| 2（IC02） | 对方不回应取消申请时？ | 保持待确认，不自动取消，原交易继续 | 满24小时自动关闭取消请求，原交易继续 |
| 3（IC03） | 不同意取消，理由如何填写？ | 必填1—300字，请求结束并留历史，交易继续 | 选填最多300字，请求结束并留历史，交易继续 |
| 4（IC04） | 已确认交易的金额变更由谁提出？ | 任一方提出，另一方确认后生效 | 仅卖家提出，买家确认后生效 |
| 5（IC05） | 同笔交易允许几份待确认改价？ | 最多1份待确认方案 | 可多份方案，但仅选定1份生效 |
| 6（IC06） | 还有待确认改价时，能否确认交付完成？ | 须先处理待确认改价，再确认完成 | 完成时关闭未确认改价，按原有效金额结束 |
| 7（IC07） | 买家确认交付完成后，帖子如何处理？ | 自动标已售、退出在售并恢复联系方式打码 | 仅交易完成，由卖家另行标已售 |
| 8（IC08） | 新流程的双方交付完成确认，是否直接开启评分资格？ | 直接开启，不再重复确认实际经历 | 仍走独立实际经历确认流程 |

第1—3题只定义已生效交易的取消，不替代上轮撤回/不同意待确认交易；不回应、拒绝和取消是不同事实。取消申请的说明/证据、双方并发与撤回/编辑、完成同时待确认、取消后重新开放、已发生费用及退款另议；取消不证明双方现金结清。

第4—5题真实降价仍须双方确认留记录，降低计佣基数另须运营核验批准，不覆盖初始价；改价版本修改/撤回/拒绝/无回应、方案字段和阶段生效另议。第6题处理可以是明确确认、拒绝或撤回，并非强制同意；尚未批准的计佣核验请求与普通改价是不同流程，如何影响完成另议。

第7题沿原F03已售状态的退出在售/打码边界，不删除历史，也不把标已售当付款成功。既有联系人授权的结束范围及私密字段权限需明确，交易中仍按上轮规则。第8题若A，仅新流程双方确认交付的交易获得资格，不能由单方已售、联系获准、待确认完成或取消获得；旧合法评分/资格保留、旧历史迁移与统计字段待补齐，不自动扩大维修/其它或跑腿评分触发。

佣金支付资格、保存期限、金额范围、证据/隐私、并发与完整页面仍需后续规划。本轮不修改历史PRD或启用真实收费。
