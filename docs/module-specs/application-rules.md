# 维修和其它：申请与选人规则

更新：2026-10-11。实际回复：“全A, 4选B, 6皆不设同时接单上限,”。依据：[第二轮8题](application-questions-20261011.md)，同时用于维修和其它。保留此前最多1份有效申请、先申请再选1人、选定前可修改或撤回等规则。

## 本轮决定

| 来源 | 已确认规则 | 开发边界 |
| --- | --- | --- |
| AQ01 / A | 发布者确认选择后直接生效，无需接单员再次确认 | 必须成功选定当前有效申请；草选、请求失败或结果未知不算成功 |
| AQ02 / A | 选定成功后，其余申请全部结束并通知申请者 | 不保留候补，不自动递补；保留必要历史记录，不把结束当删除 |
| AQ03 / A | 主动撤回后，需求仍可申请时允许立即重申 | 仍最多1份有效申请；已选人或不可申请需求不能靠重申绕过限制 |
| AQ04 / B | 不设单独拒绝申请，只选人或等待 | 不生成“发布者拒绝申请”流程或拒绝后重申限制；内容审核及违规处理另有既有规则 |
| AQ05 / A | 申请说明选填，最多300字；预估服务费选填，未填显示“待协商” | 预估报价不等于正式费用约定，选人不自动批准报价或证明已付款 |
| AQ06 / 明确不限量 | 维修和其它均不设同时接单的产品数量上限 | 不影响每条需求选1人、同一人同一需求最多1份有效申请和资格要求 |
| AQ07 / A | 发布时可选填详细地址，私密保存，只向选中的接单员开放 | 发布者可管理自己的地址；选人前及其他申请者看不到完整地址；公开区域不是完整地址 |
| AQ08 / A | 选人前修改服务内容、区域或时间，原申请失效，通知申请者重新申请 | 失效申请不可直接选中；本题不批准选人后的单方变更，也不新增必填时间 |

服务端必须执行选定和信息授权，不能只靠页面隐藏地址或对完整电话号码打码。两类同时不限量来自AQ06独立确认，不是从申请人数不限推导。跑腿、闲置、免费目录及推广的原规则不因本轮而改变。

## 验收依据

1. 发布者选定1位当前有效申请者成功后，其申请成为选定对象，其余申请结束并收到通知；没有接单员二次确认步骤或自动递补。
2. 网络结果未知时应核对真实结果，不能提前解码双方联系方式或完整地址；重复选人不能产生多个同时选中的人。
3. 主动撤回且需求仍可申请时，可以立即重申；重复提交后仍只有1份当前有效申请。
4. 申请管理不出现单独拒绝按钮或对应业务状态，不能误采用未选的AQ04A。
5. 说明、预估服务费均可空；空报价显示“待协商”，不能显示0元或免费。填入报价及选人成功均不能替代双方费用确认。
6. 接单员已有维修/其它未结束服务，不因产品数量限制而被阻断新接单；仍须满足该需求的申请及资格规则。
7. 发布时不填详细地址也可继续；地址私密保存，只有发布者本人和成功选中的接单员可按该需求权限获取，其他人不能获取完整字段。
8. 选人前修改关键内容后，旧申请均不可再选，通知申请者重新申请；重复操作和并发选人/编辑不能让失效申请被选中。具体冲突处理提示待定。

当前为文档一致性验证和后续产品验收依据，没有实现或验证实际申请功能。原申请失效/结束不批准删除历史；具体保存期限仍需确认。
