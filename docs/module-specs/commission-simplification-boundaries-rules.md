## 记录与状态

同一交易不能因72小时计佣、真实交付补确认或费用阶段变更重复新增收费记录。原PRD的24小时完成提案不作为另一套首发计时流程。后续补确认可更新交付事实，计佣记录的首次形成时点/月份不因补确认重置；获准金额调整仍保留历史，未来发生已出账调整时差额按已确认规则处理。幂等/标识/事件先后、跨月调整细节及实际字段未实现。

真实完成仍需已确认的明确确认依据，不以暂定计佣自动结束真实履约。闲置IC07/08在明确真实交付后自动已售与评分的设计规则保留；只有暂定计佣时则使用本轮“已归档·交付未确认”和暂停售展示。归档不等实际已售，不能用它生成真实成交统计、HD02收入、评分资格或已付款。

用户线下办完后不回来确认，并不阻止有条件暂定计佣和归档：事前双方已明确同意规则/预计结束时间、正式金额有效、没有阻断条件且连续72小时窗口结束时，按既定方向形成暂定记录并归档，不以再次点击完成为前提。未知费用、未确认调整或有效未解决异议等仍不得当作正常无异常，具体截止和提醒细则待答。“交付未确认”用于表示事实未核实，不是永久留在待办列表；收入和评价仍按已有确认口径，不因本次疑问自动改动。

比例/封顶仍按已确认动作锁定：跑腿15%不封顶，维修15%上限30元，闲置5%上限20元，其它10%上限20元。首发计佣按记录首次成功形成月份归账，无需旧账迁移。计佣发生不等于出账成功，出账成功后72小时缴款期限是另一个时钟。

分阶段统一归集后，以最终预计结束时点统一进入72小时窗口，不是在该时点立即收费；无异常且前提齐备后才形成暂定记录。若已有符合条件的双方真实交付确认，则按SB02提前形成记录。各阶段当前有效服务费合计只使用一次封顶，材料等实际支出仍分开。

延期、异议、待确认改价及未知费用不得伪装无异常自动计佣。普通延期与异议核验解除是不同恢复原因，不把SB05公式自动套到所有撤回/拒绝延期或金额版本变化；新待确认请求结束处理与权限仍待下一轮。
