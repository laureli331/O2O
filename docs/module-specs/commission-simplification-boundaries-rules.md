## 记录与状态

同一交易不能因跑腿旧计时、默认72小时计佣、真实交付补确认或费用阶段变更重复新增收费记录。后续补确认可更新交付事实，计佣记录的首次形成时点/月份不因补确认重置；获准金额调整仍保留历史，已出账差额按原规则处理。幂等/标识/事件先后、跨月调整细节及实际字段未实现。

新规则适用单的真实完成仍需原明确确认依据，不以暂定计佣自动结束真实履约。原闲置IC07/08在明确真实交付后自动已售与评分的规则保留；只有暂定计佣时则使用本轮“已归档·交付未确认”和暂停售展示。归档不等实际已售，不能用它生成真实成交统计、HD02收入、评分资格或已付款。

比例/封顶仍按既有确认动作锁定：跑腿15%不封顶，维修15%上限30元，闲置5%上限20元，其它10%上限20元。归账月份改为新计佣记录首次成功形成月份的方向，仅适用于新规则的记录；旧账/旧结束事实不回溯。计佣发生不等于出账成功，出账成功后72小时缴款期限是另一个时钟。

分阶段统一归集后，以最终预计结束时点统一进入72小时窗口，不是在该时点立即收费；无异常且前提齐备后才形成暂定记录。若已有符合条件的双方真实交付确认，则按SB02提前形成记录。各阶段当前有效服务费合计只使用一次封顶，材料等实际支出仍分开。

延期、异议、待确认改价及未知费用不得伪装无异常自动计佣。普通延期与异议核验解除是不同恢复原因，不把SB05公式自动套到所有撤回/拒绝延期或金额版本变化；新待确认请求结束处理与权限仍待下一轮。
