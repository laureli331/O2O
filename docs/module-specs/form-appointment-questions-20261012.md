# 维修和其它费用表单与预约基础：第八轮8题

日期：2026-10-12。状态：8题全部待答。同时适用于维修和其它；A推荐，均为待确认提案。按用户要求以表格展示问题与选项，之后仍每轮8题。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（DQ01） | 取消时如何判定方案只含已发生费用？ | 双方一致认为全部已发生才保留待确认；有分歧或未明确时关闭留历史，可重新协商 | 按发起方逐项标记判断，只标已发生的方案保留待确认；对方可再不同意费用 |
| 2（DQ02） | 重开后谁可复制旧费用方案？ | 新服务双方中，本来就有权查看旧方案的人可复制 | 仅发布者可复制 |
| 3（DQ03） | 复制旧方案时包含哪些内容？ | 复制阶段及费用项目的文字、金额、备注；垫付条件重新填写 | 也复制是否垫付和上限为草稿值；仍须新双方重新确认 |
| 4（DQ04） | 选择不垫付时，上限如何处理？ | 隐藏上限并清除当前表单值，不改历史约定 | 灰显并保留草稿值，重新选择愿意垫付时可带回；不据此授权垫付 |
| 5（DQ05） | 不同意完成/取消的理由最多多少字？ | 必填1—500字 | 必填1—300字 |
| 6（DQ06） | 完成/取消/异议附件用什么规格？ | JPEG/PNG，每张不超过5MB，沿用共同图片规则 | JPEG/PNG，每张不超过10MB，仅这些附件放宽 |
| 7（DQ07） | 谁可以提出预约或改期？ | 发布者和接单员均可提出，另一方确认 | 仅发布者提出，接单员确认 |
| 8（DQ08） | 预约/改期同时最多几份待确认？ | 同一次服务合计最多1份 | 双方各最多1份，合计最多2份 |

第1题只判断已发生范围，不代表认可金额，不阻止取消、不自动结清，也不恢复结束后的凭据或联系访问。

第2—3题仅适用于已取消需求重开后的新服务；不能借复制给原本无权的人开放旧费用历史，不复制旧凭据，不继承旧约定或授权，新方案仍须重新提交确认。草稿值不是双方有效约定。

第5题用于完成/取消的不同意理由，不改变费用方案理由选填、完成/取消/异议说明1—500字或评分文字长度。第6题附件仍选填0—9张，不改变费用凭据最多3张/5MB、评分图片规格；B仅为待确认的新附件大小例外。

第7—8题在选人成功且服务未结束时适用；预约仍选填，改期仍须双方确认，未确认的新时间不替换原有效预约。具体时间字段、校验、拒绝、撤回、冲突与提醒另议。
