# 维修和其它费用边界：第六轮8题

日期：2026-10-12。状态：已确认1B、2B、3B、4A、5B、6B、7A、8B。用户实际回复逐行列出“1. B”至“8. B”，完整原回复保存在决策记录。同时适用于维修和其它。沿用第五轮已确认的确定金额、选人后发起、双方确认及历史保留原则；不修改跑腿或个人收入口径，不新增平台付款和自动结算。

## 1. 收费阶段如何命名？（FQ17）

A：每份费用方案填写阶段名称，1—30字，双方自行约定，如上门检查、维修处理。B：提供上门检查、服务处理、补充费用三个可选阶段，也可填写1—30字自定义名称。两种均不强制收检查费，示例不是固定收费项目。

## 2. 已确认完成后，还能协商费用吗？（FQ18）

A：允许就这次服务实际已发生的费用补充或修正，仍须双方确认，不据此重新开放联系权限或新增服务。B：完成后费用只读，补充或修正在完成确认前处理。此前已确认取消后的已发生费用可另行协商，本题不撤销该规则。

## 3. “愿意垫付”的上限怎么填？（FQ19）

A：选择愿意垫付时，上限必填且大于0；不垫付不填写上限。B：选择愿意垫付时，上限必填，可为0，但0表示当前不能实际垫付。不允许空上限被解释成不限额；金额格式沿用共同规则。

## 4. 支出超过垫付上限怎么办？（FQ20）

A：先协商新的费用方案和上限，双方确认后再按新上限垫付；未确认可暂停该项垫付。B：这次服务不再提高上限，超出部分由发布者自行支付，双方协调安排。两种都不强迫接单员超限垫付，暂停该项不自动取消整项服务。

## 5. 每个支出项目最多附多少张凭据？（FQ21）

A：选填，最多9张。B：选填，最多3张。均采用原共同图片格式JPEG/PNG、每张不超过5MB；本题仅指费用支出票据/照片，不改变完成/取消/异议附件数量或评分图片数量。

## 6. 服务结束后，费用凭据谁能看？（FQ22）

A：仍只供这次服务双方查看，结束后可回看；重开后新接单员无权查看旧服务凭据。B：只在服务进行中供双方查看，结束后保留费用文字历史，双方不能再查看凭据。两种均不公开展示，也不新增运营调解或查看凭据权限；保存期限另议。

## 7. 一份方案的合计也设置上限吗？（FQ23）

A：每项金额和方案合计均不能超过99,999.99元。B：每项输入仍不超过99,999.99元，合计可以超过。两种均按本份方案所列项目求和，服务费与实际支出分别汇总；不同版本不能重复相加，跨阶段累计细则另议。

## 8. 取消后重开，旧费用方案怎么办？（FQ24）

A：新一次服务重新填写并确认费用，旧方案只留在原服务历史中，不带入新服务。B：可复制旧方案作为新服务草稿，须重新提交并由新服务双方确认。两种均不自动继承旧费用或垫付授权，不向新接单员开放旧服务私密凭据。
