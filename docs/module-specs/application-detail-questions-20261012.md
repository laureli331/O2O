# 维修和其它申请展示与历史：第十一轮8题

日期：2026-10-12。状态：8题全部选择A，用户实际回复“全A”。原A/B选项保留作为依据，同时适用于维修和其它；本轮不修改已确认的选1人、不设申请人数/同时接单上限、选人前联系打码、不设单独拒绝申请规则。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（AD01） | 接单申请及预估报价给谁看？ | 发布者看全部，申请者只看自己的，其他人不可看 | 登录用户可看所有申请及预估报价，联系方式仍打码 |
| 2（AD02） | 发布者的候选列表显示哪些申请信息？ | 说明、预估服务费、申请时间；未填说明不占行，未报价显示待协商 | 说明和申请时间；预估服务费进入申请详情再看 |
| 3（AD03） | 候选接单员默认怎么排序？ | 按有效申请时间，先申请的在前 | 按有效申请时间，后申请的在前 |
| 4（AD04） | 未选人需求的申请开放期限？ | 不设自动到期，由发布者主动关闭 | 发布后7天自动关闭，可主动重新开放 |
| 5（AD05） | 有人申请但尚未选人，发布者想关闭需求？ | 可关闭，同时结束有效申请并通知，保留历史 | 仅没有有效申请时可关闭，已有申请须申请者先撤回 |
| 6（AD06） | 修改接单申请时，历史怎么保留？ | 保留各次提交版本，发布者与本人可查看 | 只展示最新内容，另保留修改时间和操作记录 |
| 7（AD07） | 接单员修改有效申请，是否通知发布者？ | 通知发布者，并在列表标记已修改 | 不另发通知，只在列表标记已修改 |
| 8（AD08） | 需求内容变更让旧申请失效后，能否立即重申？ | 仍开放时可立即重新申请，旧记录保留但不能直接选中 | 仍开放时等待24小时再重新申请，旧记录保留 |

第1—2题只讨论申请内容，不扩大身份、私密地址或联系方式权限；原有头像昵称与已获授权的评分展示另按既有规则及角色衔接处理。第3题不按报价或评分暗中重排；修改是否改变申请时间与重新申请排序位置需另行确认。

第4—5题只讨论未选人期间，主动关闭或自动到期均不等于物理删除；成功选人后不得借此单方取消服务。选人后双方确认取消再重开的规则保持有效，未选人关闭后的重新开放细则另议。

第6题保留版本或操作记录不代表无限期保存，历史可见范围仅限该需求发布者与对应申请者，不因此授予新服务当事人旧服务权限；保存期限仍待确认。第7题通知渠道、频率与失败重试另议，不能默认调用订阅消息。第8题讨论内容变更失效后的重申，不改变已确认主动撤回可立即重申的规则。
