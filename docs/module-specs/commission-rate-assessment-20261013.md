# 费率评估与下一步建议

日期：2026-10-13。用户已确认跑腿15%、维修15%、闲置5%，询问三项是否合适及其它比例建议。本文件回答建议，尚未获用户确认，不改已定费率或调价下限；无真实订单、获客成本、提供服务成本、服务者成本或留存数据，不能据此判断盈利或市场接受度。

## 经营判断（建议）

| 业务 | 已确认费率 | 判断及建议 |
| --- | --- | --- |
| 跑腿 | 15% | 可作为试运行起点。12元服务费扣1.80元，余10.20元，尚有时间、交通等成本；需用真实订单检验接单员是否愿意接受，不把15%宣称为已验证最优 |
| 维修 | 15% | 可试运行，重点明确只按服务费方向计佣，材料/配件等实际支出分开。100元服务费扣15元，余85元不是净利润；阶段基数映射仍未确定 |
| 闲置 | 5% | 相比服务业务，更需关注高价物品的一次性扣费。1000元成交扣50元；建议讨论单笔佣金封顶，提高费用可预期性。上限数值未定，不自动增加封顶或改5% |
| 其它 | 未定 | 建议10%作为待确认试运行方案，保留按业务归集以便以后细分。它是介于已定两类服务与闲置之间的经营提案，不是基于成本测算或行业标准，也不保证适合所有其它任务 |

试运行的周期、样本量、调整阈值尚未定义。不设自动涨降费率；将来变更只影响新确认交易，并需履行收费公示与适用流程。计佣记录、现金已收、扣佣后金额、个人收入及利润各自不同。

## 外部规则与需复核的边界

核对日2026-10-13，仅以官方文本作参考；以下是产品设计上的推论，项目具体主体和适用范围须核验，不能以本文宣称已通过合规审查。

- [市场监管总局《网络交易平台收费行为合规指南》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/jjjzs/art/2025/art_e4eca064b20843c6a97ead0c94fda00e.html)第二、十四条要求考虑经营成本和经营者状况，明确收费及相应服务内容。由此建议把15%对应的平台服务说明清楚，不能仅以百分比本身判断合理。
- [三部门《互联网平台价格行为规则》](https://www.cac.gov.cn/2025-12/20/c_1767870953332182.htm)自2026-04-10施行。第四、五条涉及自主定价及价格约定/变更，第六条涉及合理收费、公示及收费变更征求意见不少于七日；第十八条涉及真实成交价格记录。不能把反规避目的直接推导为永久禁止真实议价，亦不能篡改真实成交价。
- 据此建议区分“初始价历史不能覆盖”“真实双方议价应如实留记录”“计佣基数的减少需双方确认和运营核验”。这可能需要细化现有普通调价下限，目前保留已确认规则，待第十六轮第3题用户决定后再写入业务规则；具体合规适用仍需核验。

本次不将其它10%、封顶、真实议价改动或收费展示当成已确认实现。下一轮见[8题](commission-operation-questions-20261013.md)。
