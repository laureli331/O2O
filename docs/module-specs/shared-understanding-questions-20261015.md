## 来源与边界

- UA01：[原规则](application-reopen-rules.md)。原AR04/B只批准未选人关闭后重开排序，原文明确不自动覆盖已选服务取消后重开。
- UA02：[原规则](application-reopen-rules.md)。原AR06/A只批准理由选填、最多300字，未批准可见范围；必要运营处置权限不因本题扩大。
- UA03：[原规则](fulfillment-rules.md)。履约规则将返修/质保列为未确认，原45题没有确认首版是否独立建设该流程。
- UA04：[原规则](commission-billing-rules.md)。CQ18/A只批准同账户跨业务抵扣和先抵较早到期款，没有决定注销时余额如何衔接。
- UA05：[原规则](closing-rules.md)。阶段按当前有效版本累计已确认，但同名允许性与阶段排序在原文仍待确认。

UA01不恢复旧申请、联系授权、费用或佣金快照，普通编辑不刷新排序。UA02只决定关闭理由展示，不夹带未授权电话/私密地址，不给运营新增权限。UA03只决定首版是否建设独立返修流程；A不免除服务者或平台依法应尽的职责、不关闭原异议/投诉/申诉，不默认所有返修免费；B还须补专门规则，没有默认返修次数或质保天数。

UA04是平台佣金的已核准差额抵扣，不是客户钱包。A只定人工处理原则，不代表每笔抵扣可直接换现金或已经退款；须核对原因、已缴/抵扣事实、应退金额、合法保存要求和实际可用渠道，不重复退还。不能因余额无限期拖延受理、要求强制放弃，或把注销当立即销毁依法必要记录。具体渠道、时限/告知和必要保留在E02/E03据实核对，不能借此恢复已关闭的全部私密资料。B明确延后，不默填方案，也不授权上线缺失注销规则的功能。UA05不按名字合并阶段，每阶段仅取当前有效版本，不改变99,999.99元上限或整次佣金只封顶一次。

账号注销及时处理和避免不合理条件参考[网信办规定](https://www.cac.gov.cn/2019-12/27/c_1578986455686625.htm)；售后权利边界参考[网络交易监督管理办法](https://www.samr.gov.cn/wljys/gzzd/art/2023/art_09c394cce74f424a8d82dbc4811a11ec.html)。这些依据不等于项目主体/渠道或具体退款金额已获核实，不把征求意见稿当生效规定。本文件仅提案，没有真实答案、退款、注销或产品实现。
