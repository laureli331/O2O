# 维修和其它：异常及评价规则

更新：2026-10-11。实际回复：“全A, 4B, 5B”。依据：[第四轮8题](exception-rating-questions-20261011.md)。两项例外分别为完成与取消可同时待确认、运营不介入服务调解；其余六项A。

## 已确认决定

| 来源 | 决定 | 边界 |
| --- | --- | --- |
| EQ01 / A | 完成说明必填1—500字，图片/凭据选填0—9张 | 第八轮已确认JPEG/PNG、每张5MB；计数与存储细则待补；不将可选图片变成必传付款证据 |
| EQ02 / A | 取消或异议说明必填1—500字，附件选填0—9张 | 私密服务证据不因提交而公开，不证明费用结清 |
| EQ03 / A | 可以明确不同意完成/取消申请，理由必填 | 不结束服务，继续协商或提出异议；第八轮已确认理由1—500字；第七轮已确认不同意关闭该申请，记录/并发细则待补；接单申请仍不设单独拒绝 |
| EQ04 / B | 完成与取消申请可同时待确认，先确认生效的一种结束服务，另一种关闭并留历史 | 先点击、客户端时间或网络返回先后不算生效依据；同一服务只能有一个有效结束结果；不改变费用最多1份待确认规则 |
| EQ05 / B | 只记录双方服务异议，双方自行协商，运营不介入服务调解 | 不新增运营代扣款、裁定资金或代替双方确认的权限；既有举报、内容审核、评分核查和评价申诉仍按原职责处理 |
| EQ06 / A | 新维修服务在接单员提交完成、发布者确认后直接开启双方评分资格，沿用既有体系 | 不需再走一轮独立实际经历确认；旧联系模式的合法资格与评分保留，迁移与去重待补 |
| EQ07 / A | 其它加入既有双向三维评分体系，发布者确认完成后开启双方资格 | 按其它业务及被评角色分开统计，不混入维修/跑腿角色汇总；相关页面和统计字段尚需同步 |
| EQ08 / A | 新维修/其它服务取消不新增评分资格 | 不撤销历史已有合法资格和评分；不采用另行确认取消服务经历来新增资格的未选方案 |

现有体系的身份/真实经历要求、态度/效率/沟通三项整数1—5、双向独立评分、7日首次评分窗口、一次修改、图文审核、一次回应、公开打码及申诉规则继续有效，依据原PRD M10/F14—F16/RA01—RA16。评分启用仍须满足既有条件，本轮不表示真实评分服务已启用。

## 验收依据

1. 完成、取消、异议说明为空或超500字时不能提交；无附件不阻断合法说明提交。可选附件允许0—9张，不能要求付款票据。
2. 对方明确不同意完成/取消时必须有理由，服务不因不同意而结束；这种动作不能被套用到接单申请。
3. 完成和取消可同时等待确认。完成先有效时，服务只为已完成、取消申请关闭并留历史；取消先有效时，服务只为已取消、完成申请关闭并留历史。
4. 同时确认、重复点击或网络重试不能产生两个有效结束结果，也不能重复开启评分资格、关闭联系权限或计数。技术并发实现和失败提示需后续定义。
5. 取消胜出不生成该次服务评分资格；完成胜出必须已有接单员完成申请和发布者明确确认，才形成双方评分资格。
6. 其它双方评分按各自被评角色分开统计，不变成混合个人总分。重复结束通知或重开同一需求不能用需求编号合并不同服务，也不能把同一服务重复记为多次经历。
7. 只记录服务异议、由双方协商，不出现运营服务调解/代扣款入口；与举报或评价申诉并存时，原审核、核查和申诉入口仍可使用，且不会自动改变履约结束或资金事实。
8. 取消、评分及回应不恢复旧服务联系方式或完整地址权限；历史合法资格与评分不因新服务取消被删掉。

当前仅验证文档一致性和决定边界，没有实现或验证真实并发结束、评分或运营功能。
