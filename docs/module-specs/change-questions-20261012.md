# 维修和其它清除预约与内容变更：第十轮8题

日期：2026-10-12。状态：8题全部待答。A推荐，均是提案，同时适用于维修和其它。清除预约须双方确认、不取消服务；内容/区域变更须双方确认、确认前原内容有效；服务结束后未决变更关闭留历史的规则继续有效。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（CH01） | 清除预约请求与预约/改期是否共用待确认上限？ | 共用，同次服务合计最多1份 | 清除请求单独最多1份，可与1份待确认预约/改期并存 |
| 2（CH02） | 对方不回应清除预约请求怎么办？ | 保持待确认，不自动清除；原预约保留 | 48小时后关闭该请求并留历史，原预约保留、不自动清除 |
| 3（CH03） | 清除请求的撤回、修改、不同意怎么处理？ | 沿用预约规则：可撤回，修改先撤回重提；不同意关闭，理由选填最多300字 | 其余同A，但不同意理由必填1—300字 |
| 4（CH04） | 谁可提出服务内容/区域变更？ | 双方都可提出，另一方确认 | 仅发布者提出，接单员确认 |
| 5（CH05） | 内容/区域变更最多几份待确认？ | 同次服务合计最多1份 | 双方各最多1份，合计最多2份 |
| 6（CH06） | 修改待确认内容/区域变更怎么办？ | 发起方可撤回，修改先撤回再提交 | 发起方可撤回，也可提交更新版本，须对方确认新版本 |
| 7（CH07） | 不同意内容/区域变更，需要理由吗？ | 选填，最多300字 | 必填1—300字 |
| 8（CH08） | 对方不回应内容/区域变更怎么办？ | 保持待确认，不自动同意；原内容仍有效 | 7天后关闭该请求并留历史，原内容仍有效 |

以上均用于成功选人且服务未结束期间，不新设单方结束、付款或评分资格。撤回、修改、不同意均保留历史；未获双方确认的内容不能覆盖原有效内容。

第1题只讨论预约/改期/清除的共用数量，不合并费用或内容变更的待确认数量。第2题清除请求不因原预约时间已过自动清除。第3题不同意仅结束该清除请求，原预约保留；撤回和修改仅限发起方，已确认结果不允许单方撤回。

第4—8题内容和区域作为同一份变更方案处理；不同意结束该方案、原内容继续有效，不结束服务。两种无回应方案都不自动同意；B的期限从服务端有效提交时间计算，不默认填入已确认规则。具体字段、变更对费用的影响、通知、并发与保存期限另议。
