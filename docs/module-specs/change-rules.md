# 维修和其它：清除预约与内容变更

确认日期：2026-10-12。依据：[第十轮8题](change-questions-20261012.md)，用户实际回复“全A”。与[预约细则](appointment-rules.md)、[履约规则](fulfillment-rules.md)共同使用；仅用于成功选人且服务未结束期间。

## 已确认规则

| 来源 | 决定 | 边界 |
| --- | --- | --- |
| CH01 | 预约、改期、清除预约共用同次服务最多1份待确认名额 | 不合并费用或内容变更的待确认数量 |
| CH02 | 清除请求无回应保持待确认，原预约保留 | 不自动同意、不自动清除或关闭；原预约时间已过也不触发清除 |
| CH03 | 发起方可撤回；修改先撤回重提；不同意理由选填最多300字 | 不同意关闭本次清除请求，原预约保留，不取消服务；历史保留，已确认结果不能单方撤回 |
| CH04 | 发布者或选中的接单员均可提出内容/区域变更，另一方确认后生效 | 其他申请者没有权限，确认前原内容有效 |
| CH05 | 内容和区域作为同一份方案，同次服务合计最多1份待确认 | 不是双方各1份；不占用预约或费用名额 |
| CH06 | 发起方可撤回；修改先撤回再提交 | 撤回及重提保留历史，新方案须另一方确认，已确认结果不能单方撤回 |
| CH07 | 不同意内容/区域变更的理由选填最多300字 | 关闭本次方案、保留历史，原内容继续有效，不结束服务；不是单独拒绝接单申请 |
| CH08 | 内容变更无回应保持待确认，原内容仍有效 | 不自动同意或关闭，没有7天默认期限 |

服务完成或取消时，未确认清除预约及内容/区域变更按第九轮关闭留历史，不视为同意。完成前处理待确认费用的要求继续有效；不新增付款事实、评分资格、逾期处罚或平台服务调解。

## 验收依据

1. 已有待确认改期时不能另提交清除；撤回改期后可以提出清除，改期及撤回历史保留。
2. 清除请求等待期间原预约仍有效；经过原预约时间、48小时或7天均不自动清除或关闭该请求。
3. 发起方撤回清除或另一方不同意后，原预约不变；不同意理由为空可提交，超过300字不可提交。
4. 双方可以发起内容/区域变更，非当前选中接单员不可发起；已有待确认方案时另一方不能再新增一份。
5. 修改内容方案须先撤回再提交；撤回不修改原有效内容，不能直接覆盖对方待确认版本。
6. 不同意内容变更只关闭该方案，原内容仍有效，服务继续；理由选填最多300字。
7. 内容方案无回应超过7天仍待确认，不能默认生效；服务结束后关闭留历史，不能再确认使其生效。
8. 无回应与有效服务结束是不同触发条件；各类方案名额分开，未确认方案不授权付款、联系或评分。

当前仅运行文档一致性检查，没有实现或验证真实申请提交、权限、提醒、到点任务及并发操作。

## 尚未确认

内容变更具体字段、公开展示与费用影响；私密地址与联系方式变更；预约时间显示与可选范围；版本标识、并发冲突提示、通知渠道/频率、文字计数、保存用途与期限；完整页面、状态和接口合同。原跑腿、闲置、旧维修联系与资格迁移不因本轮自动变更。
