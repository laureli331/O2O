# 第2题重述与范围、异议：第六轮8题

日期：2026-10-14。状态：8题全部选择A。实际回复：“全A, 以后都直白点；还有多少条问题?”。下表保留提问时选项，当前规则见[本轮已确认规则](deadline-completion-clarification-rules.md)。依据：[第五轮部分回复与初次30天/延期七天](deadline-completion-operation-rules.md)。提问时第1题重述尚未选的原DO02，用户之前“没听懂”不算A/B；本表使用新的展示编号1—8，对应DX01—DX08。

原DO02的意思：未选定接单员前，你把预计结束时间改了，价格保留，接单员必须接受新时间，你才能选择原报价。例如原要求下午5点办完，改为下午3点；这里不指交易生效后的正式延期。本次DX01/A已确认：在原报价旁直接点“接受新时间”。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（DX01） | 你改了时间后，接单员怎样确认接受？ | 在原报价旁直接点“接受新时间”，价格不变，你再选择该报价 | 你先发时间确认申请，接单员回复同意后，你再选择原报价 |
| 2（DX02） | 初次30天、延期七天怎样计算？ | 按连续24小时计算一天 | 按北京时间自然日，起算日为第1天，最后一天23:59截止 |
| 3（DX03） | 延期七天从哪个时点起算？ | 从原有效预计结束时间起，最多再延后七天 | 从双方确认延期成功时起，新的结束时间须晚于原时间且不超七天范围 |
| 4（DX04） | 自动完成前，什么情况下异议可以暂停流程？ | 交易当事方明确提出未完成/未成交/取消争议并说明，符合资料要求且提交成功即可暂停 | 双方都明确认可发生争议后才暂停，等待对方时不暂停 |
| 5（DX05） | 同一异议允许几份待确认解除请求？ | 最多1份 | 双方可各发1份，任一份获得对方明确确认后解除，其余关闭留历史 |
| 6（DX06） | 解除异议请求能否撤回或修改？ | 发起方可在待确认时撤回；修改先撤回重提，解除成功不能撤回 | 提交后不能撤回或修改，只能由对方同意或拒绝 |
| 7（DX07） | 不同意解除异议，理由是否必填？ | 选填，最多300字；关闭解除请求，原异议继续暂停 | 必填1—300字；关闭解除请求，原异议继续暂停 |
| 8（DX08） | 确认解除、拒绝、撤回同时发生，按什么顺序？ | 按服务端先成功的有效操作，保留结果；迟到请求不回退 | 确认解除优先，其它操作只要还未成功就不能先完成 |

第1题追溯原DO02，只确认接受新时间的入口；不改价格、不把旧时间接受当新时间接受，不新增选定后的二次接单。A推荐为直接入口，必须显示当前预计结束与最终期限；B增加选定前的独立确认动作。更新/接受/选定之间版本并发和过时校验另行明确，不擅自实现任何入口。

第2题A会使30天/七天分别成为连续720/168小时的范围，但初次/延期基准仍按已确认或第3题选择；不是每笔固定时长。B会产生不足连续整天的范围，须明确日期和分钟/秒边界，不影响已批准72小时申报/缴佣。第3题A会细化此前延期相对确认时点的候选范围方向，使用原有效预计结束，不是原自动完成截止；B在原结束离确认时超过七天时可能没有可选延期日期，须明确提示，不能偷偷改时点。

第4题仅针对尚未正常自动完成的同笔有效交易，不将资料提交成功当争议事实已核实。A只允许该笔合法当事方提出，具体类别、说明字数、附件和审核/滥用处理随后收口；不擅自复制维修/其它字段到所有业务。B等待期间仍走完成时钟，可能来不及暂停，不能把它说成已批准的处理。完成后的晚到异议按既有核验/更正出口，不自动回滚完成或主记录，也不授予运营服务裁决。

第5题B也需对方对同一版本明确确认，不能把双方分别发请求直接当已解除。第6题不撤回已经生效的解除结果；后续新异议是独立事件，不覆盖旧历史。第7题只关闭不同意的解除申请，不把拒绝理由空白当原异议撤销；原异议有效性及费用核验保持原范围。

第8题讨论成功生效优先级，不按用户设备点击时间。B不回退已成功的撤回或拒绝，但需要另行明确未成功操作的仲裁范围和等待方式，不能凭此宣称实际服务端实现已有。两项都最多产生一次有效解除，记录实际解除成功时点作恢复依据，不重复重启72小时。

本轮实际答案：DX01—DX08全A；日口径、延期基准与解除处理已确定，以上提问时的“待确认/随后收口”按[当前规则](deadline-completion-clarification-rules.md)读取。原DO02未理解历史不回填，具体异议资料、并发实现等未在本轮获准的内容仍需核对。没有追加下一轮问题；剩余总数见[核对记录](remaining-planning-audit-20261014.md)。
