原“初始价保留”继续有效，“普通调价一律不能低于初始价”以本轮CO03明确细化。真实约定价、计佣基数、已收客户款、已缴平台佣金是不同记录；本轮未确认金额调整前后的计佣差额算法，不将真实新价自动当已批准基数。历史原价和既有账单不能覆盖。

封顶金额、单位、锁定和缺失处理未齐，当前不能据此计算实际最终佣金或开放收费。支付产品、收款主体及资格依旧未核实；维修/其它服务完结规则、跑腿RUN11、评分资格和HD02个人收入沿用原规则，不由佣金变化自动替换。

## 验收依据

1. 四类比例分别为15%、15%、5%、10%；其它10%可标试运行，不再显示其它待定，也不能回写旧轮历史中的null。
2. 封顶适用于维修、闲置及其它，不限于原问题中的闲置；三类封顶金额均未知，未知不能表现为0元、无限额或已配置金额。
3. 双方真实降价确认后新约定留记录，原价继续可追溯；没有计佣核验批准时计佣基数不因此减少，审批状态不证明退款或客户款到账。
4. 交易确认前承担佣金方看到规则并知悉，金额未知不编造预估；缺失比例不能绕过确认阻断，但不禁止正常发布或申请。
5. 当前时间在截止时刻之前不判逾期；到截止时刻仍未核实缴清即逾期；已核实缴清不再因同张账单限制新业务。
6. 争议部分暂停催缴/限制，无争议部分保留原期限；旧服务履约、必要取消协商、费用异议、举报及申诉继续开放。
7. 全部逾期应缴金额经核实结清自动解除欠费限制，其他原因限制仍保留；单张支付成功不能自动等同全部欠费已清。
8. 所有新确认均与原题、实际回复、补充范围对应，不替用户填封顶金额、跑腿封顶决定或其它试运行期限。
