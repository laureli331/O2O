# 维修和其它履约与结束：第三轮8题

日期：2026-10-11。状态：8题全部待答。建议同时适用于维修和其它；A推荐，均未批准。选人直接生效和费用按阶段双方确认已定，取消不代表费用结清；本轮只补充服务流程，不新增代收或自动付款。第1、2、5、6题讨论选人后、服务完成前；第7题仅讨论已确认取消的服务。

## 1. 选人后修改服务内容或区域怎么办？（LQ01）

A：双方确认修改后生效，确认前原内容有效。B：不允许修改，须先取消再重新发布。

## 2. 是否在小程序记录预约时间？（LQ02）

A：选填，双方确认后记录；改期也需双方确认。B：双方线下约定，小程序不记录预约时间。该题是新业务规则，不按旧图“服务时间”标签生成默认值。

## 3. 谁发起服务完成？（LQ03）

A：接单员提交完成，发布者确认后完成。B：发布者可直接确认完成，也可确认接单员提交的完成申请。

## 4. 发布者一直不确认完成怎么办？（LQ04）

A：保持待确认，不自动完成；可提醒或提出异议。B：24小时无异议自动完成。

## 5. 服务取消如何生效？（LQ05）

A：任一方申请，另一方确认后取消。B：任一方可直接取消，已发生费用另行协商记录。两种均不表示费用结清。

## 6. 对方不回应取消申请怎么办？（LQ06）

A：保持待确认，不自动取消；可提醒或提出异议。B：48小时无异议自动取消。本题以第5题需对方确认的方案为前提；如第5题选B，本题不适用。

## 7. 已取消的需求能否再次找人？（LQ07）

A：发布者主动重新开放同一需求，重新申请和选人；旧申请不自动恢复。B：原需求关闭，要找人需重新发布。历史服务和费用不能被覆盖。

## 8. 完成或取消后，完整联系方式和地址还能看吗？（LQ08）

A：小程序内重新打码联系方式，关闭接单员对完整地址的访问；发布者仍可管理自己的地址。B：原服务双方继续可查看该服务已获授权的联系方式和地址。具体保存期限另议，均不向其他申请者开放。
