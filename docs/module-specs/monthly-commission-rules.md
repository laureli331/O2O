## 已确认

| 环节 | 规则 | 边界 |
| --- | --- | --- |
| 收入模式 | 月末根据骑手/维修员服务费及闲置卖家成交价按比例计佣 | 改变旧PRD不抽佣方向；具体费率、到账和收取方式未定，原PRD保留作历史 |

| 计费范围 | 仅已完成/已成交的交易计入佣金 | 跑腿主动/自动完成的具体资格、维修完成与费用阶段衔接、闲置成交依据另议；不能仅靠联系获准或选人就收费 |
| 月末账单 | 从符合计费条件的交易记录生成账单 | 不直接读取可编辑展示价格；后续确认加价、退款/减免及跨月差额的金额口径另议 |

以上用于原话具名的跑腿、维修、闲置；其它适用性需单独确认。未指定费率、自动扣款、居民款项代收、旧交易追溯收费或扣佣后的个人收入显示方式。维修已确认完成后费用只读仍有效，新增独立调整不是重新开放原费用编辑。

## 验收依据

1. 双方确认初始价格后，该原记录不能被当前展示价、编辑或月末出账覆盖。
2. 普通改价低于初始价格不得通过；对方未确认的加价不能成为有效费用或直接计佣。
3. 退款、减免或误录须另有调整记录，保留原因、证据与确认事实；正常纠错不借普通改价覆盖原交易。
4. 未完成/未成交的记录不能仅凭联系授权、申请或选人计佣；自动完成是否计佣仍须第十四轮确认。
5. 月末账单须可追溯到对应交易和确认金额；不得因卖家改商品展示价而悄悄更改旧交易基数。
6. 账单生成不等于收款成功，调整批准也不等于线下退款到账；不能无支付条件实现自动扣款。

本次验证仅为文档/决定/资源一致性检查，没有实现调价拦截、账单、退款、收款或佣金结算。
