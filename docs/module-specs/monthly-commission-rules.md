## 验收依据

1. 双方确认初始价格后，该原记录不能被当前展示价、编辑或月末出账覆盖。
2. 普通改价低于初始价格不得通过；对方未确认的加价不能成为有效费用或直接计佣。
3. 退款、减免或误录须另有调整记录，保留原因、证据与确认事实；正常纠错不借普通改价覆盖原交易。
4. 未完成/未成交的记录不能仅凭联系授权、申请或选人计佣；第十四轮已确认跑腿RUN11条件自动完成也计佣，但评分/收入统计不自动改变。
5. 月末账单须可追溯到对应交易和确认金额；不得因卖家改商品展示价而悄悄更改旧交易基数。
6. 账单生成不等于收款成功，调整批准也不等于线下退款到账；不能无支付条件实现自动扣款。

本次验证仅为文档/决定/资源一致性检查，没有实现调价拦截、账单、退款、收款或佣金结算。
