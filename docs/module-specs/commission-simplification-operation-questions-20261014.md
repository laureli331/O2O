# 简化机制适用与窗口细节：第三轮8题

日期：2026-10-14。状态：8题全部待答，A为推荐提案。依据：[第二轮衔接](commission-simplification-boundaries-rules.md)。不将本轮提案作为已启用规则，旧单不回溯方向保留。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（SO01） | 新机制具体适用于哪些交易？ | 仅切换后新确认的交易，旧交易继续原规则 | 旧未结束交易也可在双方重新明确同意后切换 |
| 2（SO02） | 预计交付结束时点怎样填写？ | 必填、精确到分钟，确认时必须晚于服务端当前时间 | 只填日期，以当天23:59作为结束时点并明确告知 |
| 3（SO03） | 已有明确金额/时间后，改价或延期请求无人回应时？ | 满24小时关闭未确认调整，原有效约定保留；不自动同意 | 一直待确认，继续暂停暂定计佣 |
| 4（SO04） | 窗口内确认了金额变化的费用新版本，计时怎样变化？ | 从费用版本生效时点与当前预计结束时点中较晚者重新72小时 | 保留原窗口截止，不重新给完整窗口 |
| 5（SO05） | 正好在窗口截止时点收到有效异议，如何处理？ | 异议仍有效，暂停相应计佣；过截止时点才可自动形成记录 | 到截止时点即可形成记录，后续异议走更正 |
| 6（SO06） | 明确真实交付完成时，未决延期/取消请求怎样处理？ | 关闭留历史，不视为同意旧请求；待确认改价仍须先处理 | 先处理完延期/取消，再确认真实交付 |
| 7（SO07） | 暂定计佣归档后，完整联系方式怎样处理？ | 恢复打码，保留必要历史/异议入口，必要联系恢复方式另定 | 在原授权有效期内继续展示 |
| 8（SO08） | 后续辅助提醒失败，是否暂停窗口？ | 事前双方知悉已有效核实时不停止窗口，记录提醒失败；知悉未核实则不自动计佣 | 任何后续提醒失败/未知都暂停窗口 |

第1题A需确认实际切换时点、规则公示与启用门槛，旧交易/已出账事实不改；B仍须保留双方重新同意记录，不能静默升级。第2题不把预约开始时间当结束时间；分钟的显示/存储精度、时间范围、过时确认提示及补录处理后续补齐，缺失金额不因有时间而允许计佣。

第3题A用于新机制下已有明确金额/时间后的变更请求，会细化此前维修/其它费用改动无回应保持待确认的策略，旧记录保留；不套用首次费用未知、真正未成交/未完成或金额异议核验。24小时起点、通知、同类数量/修改/撤回、关闭后的计时恢复与并发后续补齐。B存在一方提出调整而对方不回应即可长期阻断计佣的风险，不能宣称防规避已完善。第4题只讨论窗口内金额变化的有效费用版本，仅改备注等不重置计时；不让未经核验的降价自动减佣。已形成记录后的加价/降价修正、是否归档后还允许费用编辑另议，不重置原记录首次形成月份。

第5题以服务端有效接收事实为准，不能用用户设备时间倒填；晚到合理申诉仍有出口，不等于超过窗口一概拒绝核验。原出账后72小时缴款截止规则独立保留。第6题不补批准未确认请求为同意，也不删除历史；完成/取消并发先成功规则与同类数量等继续补齐，不把暂定归档当真实完成。

第7题不删除本人历史或封锁必要履约/异议，联系方式恢复目的、对象及核验流程后续确认，不仅页面遮盖服务端已泄露字段；其它私密地址/附件权限仍按必要范围核对。第8题A区分事前真实知悉证据与后续辅助提醒，不把消息已发当用户已读；若选A，会细化前轮对通知失败的宽泛阻断，具体渠道、同意/送达凭据及法定告知义务仍须核实。B不能假装已获订阅/短信许可。
