# 闲置交易确认与完成：第十九轮8题

日期：2026-10-14。状态：8题全部待答。A为推荐提案，不从第十八轮“全A”推导确认。依据：[封顶金额与确认动作](commission-confirmation-rules.md)及[原PRD](../prd.md)M03/F03/RV01：联系获准或单方已售不足以认定成交或评分资格。用户已确认卖家发起、买家确认、金额事先明确；以下补齐新交易流程，不代收买家款。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（IT01） | 卖家可以向谁发起交易确认？ | 仅向该闲置帖联系申请已获准的买家 | 可向任何已注册买家发起 |
| 2（IT02） | 同一闲置帖允许几份待确认交易？ | 最多1份待确认，确认后只保留1笔进行中交易 | 允许多份待确认，首份确认成功后关闭其余 |
| 3（IT03） | 卖家想改待确认交易金额/内容时？ | 先撤回再提交新版本，买家重新确认 | 直接修改待确认版本并通知买家再确认 |
| 4（IT04） | 买家不回应交易确认，怎么办？ | 保持待确认，卖家可提醒或撤回，不自动同意 | 满24小时自动关闭待确认请求，不自动同意 |
| 5（IT05） | 买家不同意交易确认时，理由如何填写？ | 选填，最多300字；该请求结束并留历史 | 必填1—300字；该请求结束并留历史 |
| 6（IT06） | 交易确认后，闲置帖如何展示和联系？ | 标记交易中，暂停新联系申请，既有合法权限保留 | 继续展示并允许联系申请，但不新增进行中交易 |
| 7（IT07） | 闲置交付后，谁发起完成确认？ | 卖家提交交付完成，买家确认后完成 | 任一方发起，另一方确认后完成 |
| 8（IT08） | 买家不回应完成申请时？ | 保持待确认，不自动完成，可提醒或提出异议 | 满24小时无异议自动完成 |

第1题不自动新增搜索用户/分享收单接口，目标选择及角色资格须随后核实；已获准联系的权限仍沿原规则，不因能发起交易扩大其它私密信息访问。第2题只确定数量方向，重复点击、撤回/修改、关闭及并发与提示另议；多份待确认也不能产生多笔有效交易。

第3题A不覆盖旧版本；B需要保留版本、避免买家确认旧金额并补齐并发规则，不能直接替换已生效交易。第4题不回复从不等于同意，24小时如何起算若选B再定义。第5题只讨论拒绝交易确认，不等于取消已生效交易。

第6题暂停新申请不撤销既有授权，保留期限按原规则，联系方式终止与完成后的打码另议；交易中与已售不同，不以状态证明付款。第7题是交付完成与计佣事实，评分资格衔接及原单方已售操作另议，不把完成等同现金结清。第8题B若选需定义计时起点/异议/评分条件，不直接套用跑腿RUN11；A不增运营代确认或自动结束。

取消、退款/减免、金额变更、重新开放、证据/隐私、金额范围、完整页面和状态映射仍需继续规划。本轮不改旧PRD源文本、不接通真实收费。
