# 闲置请求处理与取消后开放：第二十一轮8题

日期：2026-10-14。状态：8题全部待答，A为推荐提案，不将第二十轮“全A”沿用到本轮。依据：[闲置取消改价与完成规则](idle-change-rules.md)。已有明确完成、双方取消及单份改价原则，以下讨论请求的处理和结束后权限。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（IR01） | 完成与取消申请能否同时待确认？ | 可以，先成功确认的结果生效，另一请求关闭留历史 | 不可以，有一种待确认时暂不提交另一种 |
| 2（IR02） | 改价方案无回应时？ | 保持待确认，原有效金额不变，不自动同意 | 满24小时关闭方案，原有效金额不变 |
| 3（IR03） | 改价方案如何修改或撤回？ | 发起方可撤回，修改先撤回再提交新版本 | 待确认时可直接修改，保留版本并要求对方重新确认 |
| 4（IR04） | 不同意改价时，理由如何填写？ | 必填1—300字，方案结束留历史，原金额不变 | 选填最多300字，方案结束留历史，原金额不变 |
| 5（IR05） | 待确认完成／取消申请能否撤回或修改？ | 发起方可撤回，修改先撤回再提交 | 提交后不可撤回或修改 |
| 6（IR06） | 买家不同意交付完成时？ | 理由必填1—300字，完成申请结束留历史，交易继续 | 记录异议，完成申请保持待确认 |
| 7（IR07） | 双方确认取消后，闲置帖如何恢复？ | 卖家主动重新开放，才恢复在售与新联系申请 | 自动恢复在售与新联系申请 |
| 8（IR08） | 取消后既有联系权限如何处理？ | 重新打码，关闭旧授权，再联系需重新申请 | 已获准联系权限保留至原有效期 |

第1题A以服务端成功结果为准，不按客户端点击时间；待确认改价仍按IC06阻止完成，完成/取消数量、请求失效以及其它待确认方案结束处理另议。第2—4题不自动同意或修改生效原价，不用拒绝理由替代取消；真实降价的计佣核验仍独立。

第5题只允许原发起方撤回自己的未确认请求，不能撤销已生效完成/取消；修改并发、旧版本拒绝确认与通知细节后续补齐。第6题只讨论不同意本次完成，不新增自动取消、退款或运营代确认；完成再次提交和异议记录衔接另议。

第7题不删除旧交易历史，也不恢复旧待确认请求或自动开启新交易；重新开放与新交易对象、确认及费率锁定后续明确。第8题只讨论取消后的授权，既有合法评分/历史不删除，必要交易历史/异议入口保留；本人管理自身信息不受打码影响。再联系不继承旧授权或扩大公开隐私。
