# 维修和其它费用录入与方案处理：第五轮8题

提问日期：2026-10-11。确认日期：2026-10-12。用户实际回复：“全A”，8题全部选择A。同时适用于维修和其它。本轮不修改跑腿金额规则及既有共同输入格式（不允许负数/货币表达式、最多2位小数、价格输入防误填上限99,999.99元）；新字段映射与合计校验需整理，不能把格式校验当作付款证明。正式费用仍需双方确认，每条需求最多1份待确认费用方案；未填报价不等于0元。

## 1. 垫付条件在哪里确认？（FQ09）

A：与费用方案一起记录是否垫付及上限，由双方确认。B：单独提交垫付条件并由双方确认，与费用方案分别处理。两种都必须自愿且在垫付前确认。

## 2. 服务费能否明确填0元？（FQ10）

A：允许，明确填0表示免费；未填仍为待协商。B：服务费必须大于0，不支持免费服务。本题仅定服务费，不把未知支出改为0。

## 3. 何时允许发起正式费用方案？（FQ11）

A：选人后，由发布者或选中的接单员发起。B：选人前候选接单员也可发起，发布者确认费用仍不等于选人。本题不修改申请时预估服务费选填规则，单条需求最多1份待确认费用方案仍有效。

## 4. 每个费用项目录入什么？（FQ12）

A：名称1—30字、类别（服务费/实际支出）、该项金额；备注选填最多300字。B：名称、类别、单价、数量，自动计算该项小计；名称与备注长度同A。本题不把材料/配件/商品变成固定必填项。

## 5. 一份费用约定最多多少项？（FQ13）

A：最多20项。B：最多50项。费用约定至少1项，按本轮第4题逐项填写。

## 6. 项目金额尚未确定时能否发起正式确认？（FQ14）

A：本阶段项目金额确定后再提交正式确认；未知后续费用暂不加入，可后续分阶段确认，不强填0。B：允许包含明确标记的估算项，实际支出前再确认具体金额；估算合计不能当作已确定金额。

## 7. 发起方想改待确认费用方案怎么办？（FQ15）

A：先撤回原待确认方案，再提交新方案。B：可以更新并提交新版本，重置对方确认并通知。两种均保留历史，原已生效约定在新版本双方确认前仍有效。

## 8. 对方不同意费用方案怎么办？（FQ16）

A：理由选填，结束本次待确认方案；保留原有效约定，可再协商提交新方案。B：理由必填，其余同A。不同意不等于取消服务或否认历史已确认费用。

保留本轮原题与A/B选项用于追溯；仅A获批准。已确认规则和验收依据见[费用录入与方案处理规则](fee-detail-rules.md)。
