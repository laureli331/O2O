## 本轮已确认

| 来源 | 规则 | 边界 |
| --- | --- | --- |
| AF01 / A | 确认交易时，双方一并确定预计结束时间，精确到分钟 | 按各类既定确认动作生效；不能新增接单员二次接单或把未知报价当正式金额。时间由谁先填、过时确认与范围待下一轮 |
| AF02 / A | 预计结束时间后保留连续72小时异常申报窗口，再到最终期限自动完成；两个时间明确展示 | 最终期限为约定预计结束时间加72小时，不再叠加第二轮窗口。异常解除、改期、截止瞬间和真实提前完成的具体时序需衔接 |
| AF03 / A | 有效未完成、未成交或取消争议暂停自动完成 | 按确认后的异常解除规则恢复；不能把普通未回应请求全当真实争议，也不授予运营代双方确认交付或服务调解权 |

| AF05 / A | 未经双方确认的延期不改变既有结束期限，普通待确认延期不单独阻断到期完成及其符合条件的计佣 | 正式延期仍须双方确认；有效履约争议仍按AF03暂停。由此细化SB04对待确认延期一律暂停计佣的此前设计，不沿用两套冲突阻断规则 |

## 完成、费用与展示分别记录

正常情况下，预计结束时间到了不立即自动完成，要等其后的连续72小时窗口结束并满足异常条件。自动完成期限展示给双方，系统结束来源与用户明确确认来源可区分；精确截止先后规则未回答，不在本文擅自指定。

费用未知或待确认时，流程仍可自动完成，费用待处理入口继续存在，不能把“已完成”当费用只读、已结清或按0元计佣的依据。这个例外针对自动完成，不自动取消手动明确完成之前须处理待确认费用的已有条件。真正已确认取消的交易不能被后续计时再次自动完成；已明确完成并形成记录的交易不重复新增佣金，具体并发细则仍待补齐。

正式延期须双方确认。仅发起延期不能无限推迟期限或计佣；若实际未完成，应走有效履约异议，不能把客户不回应当作同意延期或真实交付确认。已生效延期怎样更新预计结束、何时恢复72小时窗口，及异常解除后与原SB05公式的准确衔接仍须单独明确。

个人页主金额仍是明确确认交付的本人跑腿服务费，不因已计佣、自动完成或具备评价资格而增加。自动完成部分在详情独立展示；后续取得符合口径的交付确认后，不在主金额及自动完成明细中重复累计，明细字段、更正和金额异常标识后续补齐。没有费用值时不展示伪造0元。

自动完成可以产生本轮批准的自愿评价资格，但计佣记录本身仍不是评价资格。评价资格也不证明已付款、已到账或可以计入HD02主收入。费用异议与交付异议的区分、完成后新异议导致资格如何暂停/恢复，以及已有评分如何保留、更正须继续确认。

## 费用与月结仍保留的边界

跑腿15%不封顶；维修15%上限30元；闲置5%上限20元；其它10%上限20元。维修/其它整次服务的各阶段当前有效服务费合并，只使用一次封顶；材料、商品等实际支出不计作服务费。按双方有效费用及已核验计佣依据，未经批准的真实降价不直接减少计佣基数。

主记录按首次成功形成月份归账（Asia/Shanghai），自动完成而金额未知时尚未形成计佣记录，不能把完成月份冒充记录形成月份。出账后72小时缴佣期限从实际出账成功起算，与本轮预计结束后的72小时窗口分开；不新增平台代收客户款或自动扣款。

| 情景 | 依据本轮已确认规则的结果 |
