# 收口第一轮：交易、异议和账单20题

日期：2026-10-14。状态：CQ01—CQ20全部待答。用户要求每轮20题、用直白的话说；[当前40题清单](business-closeout-plan-20261014.md)的第二轮尚未开始。A为推荐提案，必须收到实际选择才记录为决定。

“自动完成”只结束小程序里的流程，不证明钱已付。“补费窗口”指自动完成时费用还没确定，后来双方首次确认费用，再留72小时提出费用异议；不是缴佣金的72小时。

| 编号 | 问题 | A（推荐） | B |
| --- | --- | --- | --- |
| 1（CQ01） | 闲置的完成申请和取消申请，能同时等回复吗？ | 能，各最多1份；先成功确认哪个，就执行哪个，另一份关闭留记录 | 不能；同一时间只留1份，先处理完才能提另一种 |
| 2（CQ02） | 闲置普通改价，对方一直不回复怎么办？ | 保持待回复，原价不变；交易到期仍按已定规则处理 | 24小时后关闭这次改价，原价不变 |
| 3（CQ03） | 闲置改价还没确认，发起人想修改怎么办？ | 可以撤回；修改先撤回，再发一份新方案 | 可以直接改，但留旧版本，对方须确认新版本 |
| 4（CQ04） | 不同意闲置改价，理由必须填吗？ | 必填1—300字；关闭这次改价，原价不变 | 选填，最多300字；其余相同 |
| 5（CQ05） | 闲置的完成/取消申请，发起人能撤回或修改吗？ | 待回复时能撤回；修改先撤回重提 | 不能撤回或修改，只能等对方处理 |
| 6（CQ06） | 买家说还没交付，拒绝完成时，原完成申请怎么办？ | 理由必填1—300字；关闭完成申请，保留未交付异议、暂停自动完成 | 理由同样必填；保留完成申请待回复，同时保留异议、暂停自动完成 |
| 7（CQ07） | 闲置双方确认取消后，帖子怎么恢复出售？ | 卖家主动点“重新开放”；旧交易记录保留 | 自动恢复在售；旧交易记录保留 |
| 8（CQ08） | 闲置取消后，原来的完整联系方式还能看吗？ | 不能；重新打码，以后联系重新申请，确认新交易才显示 | 仅原交易双方再保留24小时，然后重新打码 |
| 9（CQ09） | 四类业务单独提“未完成/未成交/取消有争议”时，说明怎么填？ | 必填1—500字 | 必填1—300字 |
| 10（CQ10） | 上述异议的图片怎么限制？ | 都选填，最多9张JPEG/PNG，每张最多5MB | 都选填，最多3张JPEG/PNG，每张最多5MB |
| 11（CQ11） | 一笔交易有几项未办完的问题，怎么记录？ | 合并为一份当前异议，可补充内容；全部解决后双方确认解除 | 分别记录多份异议；全部解除后才恢复自动完成 |
| 12（CQ12） | 补费72小时截止这一刻，收到有效费用异议还算及时吗？ | 算；超过截止后，条件齐备才形成计佣记录 | 不算；从截止这一刻起按条件形成计佣记录 |
| 13（CQ13） | 自动完成后出现未交付异议，尚未评分的人怎么办？ | 暂停评分；异议解除后再给双方7天评分期 | 暂停评分；解除后只恢复原评分期剩余时间 |
| 14（CQ14） | 已明确实际完成的跑腿服务费后来更正，个人页累计金额跟着改吗？ | 按双方确认的有效服务费更新，留更正记录；仍排除垫付、显示非到账 | 保留首次计入金额，最新费用只在详情说明 |
| 15（CQ15） | 对佣金账单有异议，提交时要写什么？ | 选出争议交易、填写争议金额和原因1—500字，图片选填 | 选出争议交易、填写原因1—500字，整项佣金作为争议金额，图片选填 |
| 16（CQ16） | 佣金争议核验结束后，争议部分何时缴清？ | 应缴金额确定、补充缴款通知生成成功后，再给72小时 | 沿用原截止时间；已超过原期限就算到期 |
| 17（CQ17） | 欠佣金后，限制哪些新交易？ | 四类都不能新增接单/卖出交易，暂停新申请/报价；浏览、免费发需求和旧交易处理保留 | 只限制欠费所属业务；保留项同A |
| 18（CQ18） | 已核准的佣金抵扣余额，能跨本人不同业务使用吗？ | 能；先抵到期更早的应缴款，不转给别人 | 不能；只抵原业务，先抵到期更早的款 |
| 19（CQ19） | 佣金逾期后，怎么提醒？ | 每24小时最多一次，最多3次；缴清或该部分暂缓催缴就停 | 逾期时提醒一次，以后只在账单页提示 |
| 20（CQ20） | 自动完成后，维修/其它已有费用又发现漏了一项，怎么办？ | 允许双方确认补录已发生费用，留历史，按计佣更正规则处理 | 不新增项目；只处理原未知费用和已有项目的纠错 |

## 选项的范围

- CQ01—CQ08只补闲置原IR未答问题，未选择之前不改变闲置规则。CQ02仅问普通改价；已批准的补费场景24小时自动关闭规则、首次未知费用和真实争议分别保留。普通未确认费用不自动变成双方同意。
- CQ01两种申请数量仍各最多一份；已成功结果不能撤回。CQ05只撤回发起人本人的待回复申请，交易结束后旧请求不能生效。CQ06明确提出未交付并成功提交合格说明才形成有效异议，不把笼统“不同意”或金额异议自动当未交付。
- CQ07只说双方取消后重新开放原帖；已售后再次卖发新帖已决定，不重复问。恢复在售不恢复旧申请/交易，不改变旧费用及计佣处理。CQ08/B把原IR08中未定义的“原有效期”具体改为取消成功后24小时，不假设已有授权到期时长；它是新提案，不能回填IR08为已答。即使选B，结束订单私密地址与旧凭据仍关闭；闲置新电话解码仍须有效新交易，不以普通联系批准替代。
- CQ09/CQ10提案是四类单独交付异议的统一表单，不改变评价图片、费用凭据、其它完成/取消表单。若统一范围与旧表单不同，以新明确回复为准，保留原版本。附件选填，不把缺图当不能提出合理异议；资料提交不证明说法已核实。
- CQ11合并时保留双方补充和历史；新的未解决内容不能沿用旧解除版本自动生效。分别记录时每份最多一份待确认解除请求，不能解除其中一份就恢复整笔。双方同意解除、成功一次、不由运营裁决交付的规则不变。
- CQ12按服务器有效收到时间，不按手机点击补时。没有有效费用、存在其它有效阻断或已有主记录时不能借截止重复形成主记录；自动完成期限和缴款期限分别沿原边界。
- CQ13只问正常自动完成后新交付异议影响尚未提交评分的窗口，不重开已完成交易，也不自动回滚佣金或删除已有合法评分。已有评分走原申诉/核查规则；评分仍每方向一份，不自动生成。选择A会补充原7日资格窗口的暂停恢复规则，反复点击不重复刷新。
- CQ14不改“明确实际完成跑腿费/排除垫付/非到账”范围；减计佣基数是否获准不作为双方真实费用生效的替代。金额更正不证明客户已付款，也不改为扣佣后净收入。
- CQ15只能处理本人有权查看的账单；争议不得超过所选应缴范围，无争议部分保留原期限。合格受理与核验结论分开，用户提交不等于认可免佣。CQ16只为核验后还需缴纳的争议余额起算，不刷新无争议部分，不因微信通知未送达反复延期。
- CQ17指佣金承担方的新承接或卖出，不限制无欠费买家/需求方的正常浏览/免费需求；必要旧服务处理、申诉和欠费缴纳入口保留。新交易确认也须校验相关承担方欠费限制，不能用旧报价绕过；已受理争议部分按原暂缓规则。
- CQ18只使用本人已获准可抵扣余额，不是客户钱包、现金提现、跨账号赠送或平台代付。抵扣记录可追溯，不凭客户端显示余额减少账单。并列到期排序属于技术实现，不再问用户。
- CQ19每次只提醒实际仍须催缴的金额，不对已暂缓部分催缴；不设自动罚金，不声称微信一定送达。具体消息载体沿原站内为主/微信有条件授权规则。
- CQ20只补“自动完成”的维修/其它费用衔接，不扩展用户明确完成后的普通改费权限；新增内容必须确实属于原服务、已发生且双方确认，不凭单方补录生效，不重开流程、重锁比例或再次封顶。已存在主记录的差额仍按既定更正/月结规则处理。B的已有项目纠错也须双方确认及相应核验，不能直接编辑历史价。

以上全部为提案。回复可以是“全A，4B、8B……”或逐题选择；自定义要求按原话记录，确有冲突时只追问冲突项。
