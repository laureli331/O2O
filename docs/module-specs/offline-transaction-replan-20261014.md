# 线下交易收尾与收费机制重规划评估

日期：2026-10-14。状态：研究与方案提案，尚未批准替换原业务。用户原话：

> 我发现一个问题: 在线下完成交易后, 用户往往不会再在小程序继续进行那一单的操作, 我认为我们可以重新规划相关部分, 节省资源的同时也防止用户逃佣. 你可以从心理学的角度好好考量

用户请求重新考量，不是对第二十一轮8题作答，不表示已经选择新收费模式。已有20轮决定、原图及原PRD保留；新规则明确批准前，不能改为自动完成、提前抽佣、付费解锁联系或钱包结算。采用项目现有规划目录记录评估，不创建产品工程或接口。

## 先验证的问题

平台当前不掌握客户线下付款和实际交付。原计佣依赖已完成/已成交事实，闲置/维修/其它又依赖双方完成确认。线下交易后不操作可能来自遗忘、无动力、入口负担、纠纷或规避收费，不能直接归类为恶意逃佣。提醒不等于核实成交，沉默不等于已完成/已付款。

还有更早的绕行点：闲置先批准联系并展示完整联系方式，后续才向该已获准买家发起交易确认（IT01/CT04）；买卖双方此时已可线下沟通，不需要再确认交易就可能成交。维修/其它选人后联系开放，但正式服务费可随后协商；在此时按实际费用收费，仍缺少真实费用和完成依据。修正不能只针对最后一个完成按钮。

验证方案：先做下表情景与权限/金额推演；批准方向后再制作低成本原型、安排有明确告知的试用。测试付费前流失、可核实的平台服务交付、退款/无效联系投诉、人工处理量及结果自愿登记，不能把看不到的线下交易数当成可测的逃佣率。样本量、目标值和采集资格本轮不预填，真实试用前另行确认。

## 心理学判断与设计推论

以下区分研究支持的一般机制与本项目待验证的推论，不宣称所有用户都如此。

| 机制 | 本项目的可能表现 | 设计方向 |
| --- | --- | --- |
| 操作摩擦与注意力成本 | 商品到手/服务结束后，再打开小程序处理多个请求缺少即时回报 | 普通情况尽量不要求事后收尾，多步骤仅用于真实异常 |
| 即时收益比未来责任显著 | 用户联系到对方、拿到物品后，平台此刻没有新的必要价值；下一笔不一定再来 | 将关键约定放在用户仍需要平台撮合的时点，价值和费用同屏可见 |
| 意图与行为之间存在距离 | 本来愿意确认或缴费，也可能拖延忘记；不能统一按恶意处理 | 清楚的一次操作、必要提醒、可达异常入口；不把沉默当验收 |
| 感知公平与风险（项目假设） | 收到线下款后再被扣“我的钱”，或还未联系就先付费，都可能产生抵触 | 费用事先披露，说明平台交付了什么；提前收费须验证有效联系和退款保障 |
| 规避收费的经济激励（流程推论） | 若不确认完成就不形成账单，两边又已交换电话，不操作具有直接好处 | 收费依据需要平台可核实的价值交付，不能只依赖事后自报；心理提醒无法弥补不可观察事实 |

[BIT《EAST》2024版](https://www.bi.team/wp-content/uploads/2014/04/BIT-EAST-1.pdf)解释操作负担、即时成本收益、时机和意图行为差距，并强调具体场景评估；[英国政府行为洞察工具](https://www.gov.uk/guidance/open-policy-making-toolkit/sensitive-policy-tools)也给出摩擦成本案例。本项目的“月底收费感受/提前付款抵触”等为设计假设，不是这些研究已验证本小程序的结论，也不借此设计隐藏收费或虚假社会证明。

## 三种方向

| 方向 | 收费依据与操作 | 资源与规避问题 | 主要代价 |
| --- | --- | --- | --- |
| A：明确的固定撮合服务费，极简结果记录（建议先试闲置） | 双方明确联系意向，收费方事先看到固定费用；核实平台费支付后交付合法联系方式。线下客户款仍双方直接付 | 平台自己的撮合交付较可核实，收入不依赖线下完成自报；可减少成交改价/阶段算佣/月末追缴对试点的依赖 | 可能使卖家在成交前流失；须定义有效撮合、无效联系退款、付费与权限的实际资格；不能把无效线索当已兑现服务 |
| B：保留比例抽佣，简化收尾/提醒 | 保留原比例及封顶，尽量一次结果反馈；可讨论明确的计佣申报义务、异常处理 | 与原商业模式衔接较多，但线下结果和实价仍不可核实；暂不承诺解决逃佣 | 若增设无异议自动推定计佣，必须重新批准适用、时限及争议保障；自动归档不能冒充真实完成或到账 |
| C：客户交易款在平台适用支付流程内结算 | 以核实的支付及退款结果计佣，能降低对事后金额申报的依赖 | 对平台内支付交易的数据更完整；仍不能消除私下另付或熟人直接交易 | 支付/主体资格、订单金额、退款争议及安全维护工作更多，与当前不代收基线差异大，不符合最省资源方向 |

推荐是有条件的：若优先降低维护成本、允许调整收入模型，先用A验证闲置；若坚持每笔实际成交金额按比例收费，B仍有观察盲区，C更有依据但投入更大。不能同时保证“钱全部线下付、成交无需上报、平台零核验成本、每笔都按真实成交价收佣”。

## A的待批准试点草案

公开浏览/普通发布 → 有意向的买家申请联系 → 双方明确联系意向并看到费用/交付说明 → 卖家自愿选择是否支付明确的平台撮合费 → 实际支付核实成功后，交付该对象的合法联系方式 → 线下交易 → 结果登记可选，举报/退款申请与真实经历评价按需。

付费前保留公开信息，不提供绕过的完整电话/微信/二维码；是否以及怎样调整现有公开字段、人工审核与分享需后续批准，不能假装现有防绕行已经成立。费用只为约定平台撮合服务，不是客户货款，也不是“撮合一成功就视为线下成交”；不恢复原比例作为同一次撮合的额外收费。不能在未提供服务时标交付成功，不能以金额记录、截图或发起支付作为支付成功。

试点范围、费用金额、是否保持基础发布免费、谁承担、支付资格和有效撮合的交付标准待批准。当前5%/20元闲置佣金不自动换成新撮合金额；若批准切换，须指定新交易适用与历史旧账处理，避免同一笔新试点重复收撮合费和旧佣金。其它三类费率/封顶先不擅自撤销。

结果可选只针对不再依赖线下结果收费的A草案。可以归档联系记录，但不能把归档变成已交付完成；服务/商品评价仍需要真实经历资格，不以付平台费、拿到联系方式或沉默直接生成好评/差评、评分资格、服务完成数或个人收入。若选择B，不得一面取消成交证据一面仍宣称按真实成交计佣。

撮合服务交付后的正常线下议价失败是否退款，与平台未达约定、无效电话、虚假信息等服务问题分别定义；不从“撮合服务费”四字推导任何情况下不退费。用户双方串通退费、重复找同一联系人、多账号及虚假需求仍有风险，不能保证完全杜绝。复购/熟人可以直接联系属于可见边界，平台还需靠稳定获客与可感知服务留住提供者，不能把评价/历史绑在强制付费上。

## 收费边界依据

[市场监管总局《网络交易平台收费行为合规指南》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/jjjzs/art/2025/art_e4eca064b20843c6a97ead0c94fda00e.html)第二、十四、二十三条涉及合理收费、收费与服务对应、清楚明细以及不合理收费。由此，固定撮合费必须对应真实约定服务、事先清楚告知，而不是把原佣金改名后任意提前收。主体、渠道及收费适用需要核实，本文不表示已获支付资格或合规审批。

## 情景验证清单

| 情景 | 方案必须满足 |
| --- | --- |
| 真正线下成交后不回来操作 | A的平台撮合费与交付记录不依赖收尾；实际成交/收入不虚构；B承认结果仍可能缺失 |
| 仅看帖子、未表达联系意向 | 不提前产生平台费，不把普通浏览当撮合交付 |
| 支付发起后失败/结果未知 | 不标支付成功，不提前交付付费权限；需合法重试/核对路径，不重复收费 |
| 信息虚假或联系方式不可用 | 有明确核验与退款/救济入口，不以“不收尾”否定权益 |
| 撮合成功后线下未成交 | 依事先披露的撮合服务规则处理；不伪造已完成商品交易、不替用户确认实际经历 |
| 双方谎报未成交、重复接触/多账号 | 不承诺两边一说就一定退款，不采集不必要隐私；控制规则后续确认 |
| 新规则前已确认/已出账旧交易 | 旧比例/封顶、原记录和账单保留，明确切换范围，不重复收费或追溯改价 |
