# 结束时间和异议处理：第六轮已确认规则

日期：2026-10-14。来源：[第六轮8题](deadline-completion-clarification-questions-20261014.md)。用户实际回复：

> 全A, 以后都直白点
> 还有多少条问题?

DX01—DX08全部A。“以后都直白点”是表达要求，“还有多少条问题”是进度问题，都不代表批准下一轮选项。原DO02当时“没听懂”的记录保留，这次通过DX01/A确定入口。本文件补充第五轮，不把历史未答改写成当时已答。

## 确定下来的八项

| 来源 | 谁做什么 | 结果和边界 |
| --- | --- | --- |
| DX01 / A | 发布者在选人前改预计结束时间后，接单员在原报价旁点“接受新时间” | 报价金额保留；发布者才能选择接受了当前时间的报价。不能拿旧时间的接受记录当同意新时间，不增加选人后的第二次接单 |
| DX02 / A | 初次30天、每次延期七天都按连续24小时一天计算 | 初次最多720小时、每次延期最多168小时；不是按自然日算，也不是每单必须服务这么久。此前各个72小时窗口仍分别处理 |
| DX03 / A | 双方确认延期时，从原有效预计结束时间计算最多七天 | 新预计结束须晚于原时间，最多延后168小时；不是从原自动完成期限或这次确认延期的时间起算。正式延期成功后，自动完成期限按新预计结束加72小时 |
| DX04 / A | 自动完成前，该笔交易的一方提出未完成、未成交或取消争议，说明情况并成功提交符合要求的资料 | 暂停自动完成，不必等另一方承认有争议。提交成功不证明说法已核实；具体说明与附件要求还要补齐，不能直接把维修字段套到四类业务 |
| DX05 / A | 同一异议提出解除申请 | 最多一份待确认；还须另一方明确确认同一版本，不能靠双方分别提申请或沉默解除 |
| DX06 / A | 解除申请的发起方想撤回或修改 | 待确认时可以撤回；修改先撤回再提。已经解除成功的结果不能撤回；之后的新异议另留记录 |
| DX07 / A | 另一方不同意解除异议 | 理由选填，最多300字；本次解除申请关闭，原异议继续暂停自动完成，不能因理由为空就解除 |
| DX08 / A | 确认解除、拒绝、撤回同时发生 | 服务器先成功处理的有效操作生效，后来的操作不推翻已成功结果；一次解除只生效一次，不按手机点击时间判断 |

## 时间例子

以下只用于验证规则，没有真实订单。

- 假设10月14日10:00确认交易，初次预计结束最晚可选11月13日10:00，正常自动完成参考期限为11月16日10:00。
- 原预计结束为11月13日10:00，双方延期后最晚可选11月20日10:00，正常自动完成参考期限为11月23日10:00。即便双方10月20日就确认这次延期，延期上限仍从原预计结束算。
- 不是每次都必须延七天。新时间晚于原预计结束且在允许范围内即可；同一时间不能借延期刷新72小时窗口。
- 成功解除有效交付异议后，沿用已确认规则，从“解除成功时间”和“当前有效预计结束时间”中较晚者再算72小时。重复确认不能再增加一轮72小时。
- 到自动完成期限这一刻，及时成功收到的有效异议仍可暂停；正常自动完成只能在期限之后成功处理。缴佣逾期等其它时钟按各自规则，不混用边界。

初次预计结束仍允许等于交易确认时的当前时间，不允许早于它；时间精确到分钟。分钟输入怎样与服务器秒级时间一致校验属于实现核对，不能把过去时间偷偷当作有效时间。

## 仍保留的规则

没有改变四类费率和封顶、已确认实际交付的跑腿主收入、自动完成明细单列、自愿三维评分、闲置已售及自动完成来源。自动完成、异议提交、解除成功都不证明客户已付款。完成后的迟到异议继续按申诉和更正出口处理，不自动回滚完成或改写已出账记录；运营没有获得代双方裁决交付的权限。

## 剩余事项与后续提问
