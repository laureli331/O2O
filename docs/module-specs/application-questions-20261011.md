# 维修和其它申请与选人：第二轮8题

日期：2026-10-11。状态：已答，适用于维修和其它。用户实际回复：“全A, 4选B, 6皆不设同时接单上限,”。对应1A、2A、3A、4B、5A、6A（用户明确两类均不设上限）、7A、8A。以下保留原题和选项，未选项不生效；规则及剩余细节见[申请与选人规则](application-rules.md)。资格核验仍按既有要求；选定成功才开放双方完整联系方式，费用仍需按阶段双方确认。

## 1. 发布者选人后何时正式生效？（AQ01）

A：发布者确认选择后直接生效，无需接单员再次确认。B：接单员再次确认后才生效，等待时限另议。

## 2. 选人成功后，其余申请怎么处理？（AQ02）

A：全部结束并通知申请者，不自动递补。B：保留为候补，取消后可再选；不能自动接单。

## 3. 主动撤回后能否再次申请？（AQ03）

A：需求仍可申请时允许立即重新申请，仍最多1份有效申请。B：撤回后等待24小时才能重新申请。

## 4. 发布者能否拒绝某份申请？（AQ04）

A：可以，理由选填；被拒者不能再申请同一需求。B：不设单独拒绝，只选人或等待。

## 5. 申请时允许填写什么？（AQ05）

A：选填300字说明和预估服务费；报价不填显示“待协商”，不作为正式费用约定。B：只选填300字说明，金额全部通过后续费用约定记录。

## 6. 同一接单员能同时接几条？（AQ06）

A：维修和其它不设同时接单的产品数量上限。B：维修与其它合计最多同时接1条未结束服务；结束状态口径另议。

## 7. 详细地址何时填写？（AQ07）

A：发布时选填，完整地址私密保存，只向选中的接单员开放。B：发布时不填写，选人后再私密提供给选中的接单员。公开区域不等于完整地址，两种方案均不公开完整地址。

## 8. 有申请后修改关键需求内容怎么办？（AQ08）

A：选人前修改服务内容、区域或时间，原申请失效，通知申请者重新申请。B：有有效申请后锁定这些内容，要修改需撤下重发。本题仅讨论选人前；选人后的修改、取消和联系权限另议。

答复只对应本轮8题，不表示预约、完成、取消、评价及全部字段已经确定。第4题不设单独拒绝，不能误写成拒绝后禁止重申；第6题是独立明确的同时接单不限量决定。
