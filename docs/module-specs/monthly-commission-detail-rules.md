## 已确认

| 来源 | 规则 | 边界 |
| --- | --- | --- |
| MC01 / A | 跑腿、维修、闲置分别设置比例，可相同也可不同 | 实际百分比未指定，不预填费率；其它另设比例见MC08 |
| MC02 / A | 锁定该笔交易确认时公布的比例，新比例只用于新交易 | 不按完成日或月底的新比例改旧交易；各业务确认动作与金额冻结映射仍待补齐 |
| MC03 / A | 按完成/成交确认成功所在月份归账 | 沿用Asia/Shanghai；不按开始交易月份追补旧月，月末截止与生成时间另议 |
| MC04 / B | 跑腿满足既有自动完成条件也计佣 | 沿用RUN11，完成申请有效产生后连续24小时既未确认又无异议才自动完成；不从发布/期望时间/午夜起算，存在异议停止计时 |
| MC05 / A | 退款/减免/误录须双方确认，运营核验批准后才调整计佣金额 | 不覆盖原交易价，不证明实际退款到账；只授予计佣调整核验，不授予维修/其它服务调解权限 |
| MC06 / A | 已出账后的获准调整保留原账单，下月记录差额 | 不重算覆盖原月账单；实际抵扣/退款、差额不足抵扣、已缴费衔接仍待确认，不自动转账 |
| MC07 / A | 佣金由骑手、维修员或闲置卖家主动缴纳，客户仍直接付给对方 | 不预留居民交易资金，不自动扣佣；缴纳渠道、资格、期限、欠费和核对另议；其它缴纳角色随MC08沿用维修 |
| MC08 / A | 其它纳入计佣，沿用维修的调价下限并单独设置比例 | 以其它服务费为计费方向，仍需明确阶段基准；没有另增其它自动完成或评分规则 |

首次交易确认时冻结比例，完成/成交时决定月份，两者是不同事实。跨月任务保持原比例，归完成月份。RUN11自动完成也是完成事实，但不等于客户明确确认、评分资格或付款成功；原个人页收入仍按HD02的本人提供服务且已确认完成的跑腿服务费口径；自动完成计入口径仍为原待定事项，不因本题默认计入，也不扩展到维修/其它或变为到账金额。

旧维修/其它仍需发布者明确确认完成，没有自动完成；闲置联系获准不是成交。当前没有客户钱款托管、钱包余额、自动代扣、历史交易追溯收费或佣金支付资格开通。各阶段实际支出及凭据规则不因计佣自动改变。

## 验收依据

1. 同一笔交易的确认比例锁定后，平台调整配置不改变该笔比例，未完成前也不能用新比例替换。
2. 开始交易在前月、完成在后月时，归后月，保留原比例；月底可编辑展示价不是抽佣数据来源。
3. 跑腿完成申请满足RUN11满24小时无确认/异议而自动完成时计佣；有异议、尚未满24小时或仅过期望完成时间不能计为自动完成佣金。
4. 自动完成计佣不自动新增评分资格、不改变原个人收入统计、也不产生付款成功记录。
5. 双方确认调整但运营未批准，计佣金额不能改变；批准后保留独立原因/证据/确认及核验记录，不覆盖原价。
6. 原账单已出账时，下月记录差额，原账单保留；不得凭调整状态自动转账或标退款到账。
7. 佣金出账待缴不等于已缴，客户直接付给服务者或卖家也不等于佣金已付；具体平台收款渠道仍待核实。
8. 其它可单独设置比例，沿用维修下限和明确完成规则，不套用跑腿24小时自动完成。

当前仅运行文档与资源一致性检查，没有实现或验证真实费率配置、状态计时、佣金计算、支付、核验或账单。
