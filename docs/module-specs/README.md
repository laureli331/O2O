1. 其它是业务模块，纳入本次规划；归集维修、跑腿、闲置之外的需求数据，作为后续更新迭代依据。用户确认公开发布并允许申请接单，先申请再由发布者选人；2026-10-11确认每条需求最终选1位且申请人数不设产品上限，申请时不强制填写服务费报价，金额后续协商。自愿预估报价已由第8项确认，共同金额格式沿用原PRD，阶段标识与排序、分类判断及禁止范围细则仍需明确。

3. 2026-10-11确认两类申请操作：同一人对同一需求最多1份有效申请，选定前可修改或撤回；重复点击不新增申请记录。

4. 2026-10-11确认两类联系权限：选定前查看对方联系方式仍打码；选定成功后仅发布者与选中的接单员互看完整联系方式，其他申请者仍打码。仅在卡片草选、发起申请或选择请求失败/结果未知时，不能视为选定成功。服务端授权沿用原PRD可见性要求，不能把完整信息下发后仅在页面打码。

5. 2026-10-11确认两类费用约定：协商后的费用在小程序内记录并由双方确认，供后续完成确认、变更和异议处理参考。进一步确认分项记录：服务费与材料、配件、商品等实际支出分开，页面同时显示合计。记录金额不代表已付款；检查费/上门费归类和变更/撤回/无回应的基本规则已由第7项补齐，字段映射、并发及异议细则仍待讨论（录入字段与不同意方案规则已由第11项补齐）。不新增平台代收、余额或自动结算；个人收入目前仍仅按原确认的跑腿口径，不自动包含维修和其它。材料/配件/商品是支出示例，不是三项必填或封闭枚举；本阶段项目金额未确定时不能提交正式确认，未知未来费用先不加入，不能直接填0元；每份合计上限已由第12项确认，阶段累计及整次服务上限已由第13项确认，阶段标识与排序另议。
