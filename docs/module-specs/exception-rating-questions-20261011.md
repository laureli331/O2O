# 维修和其它异常及评价：第四轮8题

日期：2026-10-11。状态：已答，用户实际回复“全A, 4B, 5B”，对应1A、2A、3A、4B、5B、6A、7A、8A。第6题仅维修、第7题仅其它，其余两类适用。原题与选项保留，未选项不生效；已确认规则和验收见[异常及评价规则](exception-rating-rules.md)。本轮是在既有双向三维评分体系下讨论新服务的资格衔接，不重新选择已确认的评分维度、7日窗口、图文审核和修改规则；真实启用条件仍需满足。

## 1. 提交完成需要什么说明和凭据？（EQ01）

A：完成说明必填1—500字，图片/凭据选填0—9张。B：完成说明选填，填写时1—500字，图片/凭据仍选填0—9张。

## 2. 取消或提出异议需要什么？（EQ02）

A：说明必填1—500字，附件选填0—9张。B：说明选填，填写时1—500字，附件仍选填0—9张。附件类型、大小和字数计数细则另议。

## 3. 能否明确不同意完成或取消申请？（EQ03）

A：可以，理由必填；不结束服务，继续协商或提出异议。B：不设单独“不同意”，只能确认或提出异议。本题是履约申请，区别于已确认不设单独拒绝的接单申请。

## 4. 完成和取消申请能否同时等待确认？（EQ04）

A：同一服务最多1份，已有待确认申请须先处理，再发起另一种。B：允许同时存在，先确认生效的一种结束服务，另一种关闭并留历史。本题不限制费用约定和内容变更的待确认数量。

## 5. 运营是否介入服务异议？（EQ05）

A：记录必要证据、核实并协助调解，保留结论与理由；不代扣款或裁定资金归属。B：只记录双方异议，由双方自行协商，运营不介入服务调解。既有举报/评价申诉流程不因此取消。

## 6. 新维修服务何时开启评分？（EQ06）

A：接单员提交完成、发布者确认后，直接开启双方评分资格，沿用既有体系。B：完成后再独立进行双方实际经历确认，确认成功才可评分。旧信息联系的合法资格与评分保留，迁移细节另议。

## 7. 其它是否加入评分体系？（EQ07）

A：加入，发布者确认完成后双方可按既有三维体系互评，按其它业务及被评角色分开统计。B：其它首期不开放评分。不能混入维修/跑腿的角色汇总。

## 8. 已取消服务是否形成评分资格？（EQ08）

A：该次取消不新增评分资格，不撤销历史已有合法资格或评分。B：允许双方另行确认实际完成的服务经历，确认成功后形成资格，取消本身仍不足。本题仅补充新维修和其它服务。

答复仅对应本轮8题；第4题不设“只能存在一种申请”的限制，第5题不新增运营服务调解职责。完整字段、并发处理、评分迁移及异议结案仍需补齐。
