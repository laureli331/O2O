| CQ02 / B | 取消时，只涉及已发生费用的方案继续待确认；含未发生费用的方案关闭留历史，可重新协商 | 不阻止取消、不自动确认费用或表示结清；第八轮已确认双方一致才保留，分歧/未明确关闭；入口与版本细则待议；凭据及联系访问不恢复 |
| CQ03 / A | 实际支出允许明确填0元，但必须实际已确定为0 | 未知金额不能填0；服务费明确0元仍表示免费 |
| CQ04 / A | 各收费阶段独立约定，修改只替换该阶段有效版本 | 累计仅取各阶段当前有效版本之和；待确认方案和旧版本不重复相加；未知未来费用先不加入；每条需求仍最多1份待确认费用方案 |

## 费用累计依据

阶段1有效约定100元，阶段2有效约定200元，则当前已约定累计300元。阶段2提出250元但仍待确认时，累计仍300元；250元版本双方确认后，累计改为350元，而不是550元。旧200元版本仍保留在历史中，不计入当前累计。以上为计算验收示例，非真实运营数据或默认收费。

每阶段只取当前有效版本，分别汇总服务费与实际支出，再得整次服务合计。阶段名称不等于唯一标识，两个同名阶段是否允许、阶段排序与复制时如何关联仍需确认。累计是已约定费用，不代表已支付、待收余额或个人收入；本轮不扩展维修和其它的收入统计。

## 结束与历史边界

完成申请可以提出，但发布者确认完成前必须处理待确认费用；没有待确认费用不代表费用已结清。并发提交新费用与确认完成时，必须依据服务端有效状态执行两个约束：完成前不存在未决费用、完成后不能改变费用，具体冲突提示待补。

取消时保留符合条件的待确认方案，不自动视为双方认可金额。含未发生费用时关闭整份方案而非自动删掉部分费用并认可其余金额；仅已发生部分可重新提交协商。第八轮已确认保留待确认方案须双方一致认为全部已发生；有分歧或未明确时关闭留历史，不代表认可金额。取消后的方案继续遵循双方确认、不同意/撤回及历史保留规则，但完整联系方式、详细地址、费用凭据仍关闭访问。

完成和取消申请的撤回、不同意与服务结束是不同动作；撤回/不同意只结束本次申请，不清除服务历史。结束申请仍可并存，先有效确认者结束服务，另一类申请关闭留历史；费用未决阻止完成确认，不阻止符合既有规则的取消确认。重开后新服务的费用及申请与旧服务分开。

## 验收依据

1. 存在待确认费用时不能确认完成；处理该方案后可继续完成确认，不要求付款截图或自动认可金额。
2. 取消可以生效；仅已发生费用的方案仍待确认，含未发生费用的方案关闭留历史，不自动确认其中任何金额。
3. 确定实际为0的支出可录入，未知支出仍不能强填0或提交为确定费用。
4. 多阶段分别保留版本，只累计各阶段当前有效金额；待确认方案及被替换版本不重复计算，100+200改为100+250的累计应为350。
5. 每项和每份方案都不超上限，但各阶段有效累计超99,999.99元时，也不能使新版本生效；不能拆成多阶段绕过服务累计上限。
6. 重复提交完成或双方分别申请取消，不能形成同类多份待确认；最多1份完成加1份取消，并且只能有一个有效结束结果。
7. 发起方可撤回未决结束申请；修改必须先撤回再提交。已确认结果不能撤销，历史保留，服务不会因撤回自动结束。
8. 对方不同意完成/取消须填理由，本次申请结束，服务继续；重提不自动复用旧同意或新增评分资格。

当前仅运行文档一致性检查，没有实现或验证真实累计计算、并发、权限或履约申请功能。
