# 维修和其它费用细则：第一轮8题

日期：2026-10-11。状态：8题全部选择A，用户实际回复“全A”，适用于维修和其它。第1题只在存在检查费/上门费时适用。以下保留原题和A/B选项以便追溯，B未采用；已确认规则与待定细节见[费用规则](fee-rules.md)。已有决定是费用分项记录、显示合计、双方确认及分阶段收费前确认。

## 1. 检查费、上门费如何归类？（FQ01）

A：归入服务费，但分别列出名称和金额。B：作为服务费、材料支出之外的独立费用类别。这里只定归类，不规定每单必收。

## 2. 谁能发起费用约定？（FQ02）

A：双方都能发起；发起方提交即认可该版本，另一方确认后生效。B：仅接单员报价，发布者确认后生效。

## 3. 已确认费用如何变更？（FQ03）

A：可新增或修改费用项，但新版本须双方确认；确认前原版本有效。B：只可新增费用项并双方确认，旧项金额不允许修改。

## 4. 同时允许几份待确认费用方案？（FQ04）

A：每条需求最多1份，避免双方同时提交不同版本。B：允许多份候选方案，双方最后明确选定其中1份。

## 5. 对方一直不确认费用怎么办？（FQ05）

A：保持待确认，可提醒或由发起方撤回；不自动同意。B：24小时未确认自动关闭该方案，不视为同意；如选B可另指定时长。

## 6. 服务取消但已发生费用怎么办？（FQ06）

A：双方可先确认取消服务，已发生费用另行协商记录；取消不代表费用结清。B：双方先对已有费用达成一致，才能确认取消服务。

## 7. 材料、配件、商品支出是否必须上传凭据？（FQ07）

A：选填，支持上传票据或照片供双方核对。B：存在这些支出时必须上传凭据。

## 8. 是否允许接单员垫付实际支出？（FQ08）

A：允许自愿垫付，双方事先确认是否垫付及金额上限。B：不支持垫付，由发布者直接支付或预付。平台继续不代收居民服务款。

答复对应：FQ01—FQ08全部为A。该回复仅批准本轮8个明确选项，不代表完整业务流程已经可开发。
