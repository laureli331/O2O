## 三色与层次

| 用途 | 源色 | 使用方法 |
| --- | --- | --- |
| 主色 | `#527A63` | 主操作、选中态、线性图标 |
| 暖米白 | `#F5F3EC` | 背景、卡片、毛玻璃表面 |
| 深炭绿 | `#25382E` | 正文、标题、透明阴影 |

所有新增色阶仅由这三种源色的透明度或混合形成。摄影示例也采用同色系。源色限制约束设计变量和 SVG；生成位图包含渐变、抗锯齿和纹理，不把它解释成文件内只能有三种 RGB 像素值。

留白遵循 8/16/24 的逻辑像素节奏。卡片圆角 8，控件圆角 6，触控区域目标不小于 44。毛玻璃限导航和少量叠层；高斯模糊用于装饰背景，文字层保持清晰。阴影用深炭绿透明度，噪点保持轻微，不覆盖正文。渐变限绿色至透明或三色间混合。

## 字体与图标

字体使用系统无衬线中文字体；字体栈、字号和字重见设计变量。页面标题 24、区块标题 18、正文和按钮 16、辅助信息 13，逻辑像素为设计标尺，不能直接把缩放总览图上的像素当实现字号。字重限定 400/500/600，避免依赖未安装的商业字体。

SVG 图标为可编辑的矢量源文件，20 个 symbol，统一 24 × 24 viewBox、1.75 描边、圆端点、单色 currentColor。文件本身同时呈现图标预览；实现时可引用对应 symbol。PNG 内的图标是位图渲染示意，不是内嵌可编辑 SVG。SVG 定义了源色和线宽；实际实现以源文件为准。

总览不是二十组页面和全部异常状态的完整交互原型；页面上的示例资料、金额、时刻和资格状态仅用于设计展示，不能当成本地实际记录或服务开通结果。真实村名、服务人员及细分类配置仍按 PRD E05 核实。推广与评价的启用门槛保持 E01—E06/QG01。

底部五项导航“首页 / 服务 / 发布 / 消息 / 我的”为本轮六页方案的设计组织方式，不新增业务。发布仍需原有资格，消息仍是通知及业务申请，不能扩展成自由聊天。
