# 首页与服务页：查看后继续，退出前保护填写

2026-10-25。承接用户继续优化前序页面的指令，检查V01/V02与服务订单主路径。本轮沿用双列瀑布流、分类多选、订单关键卡片、同页管理和既有交易权限，不重新设计已确认布局。

## 实际问题及处理

- V01卡片进入V02后，“返回首页”原先总聚焦搜索框。本轮记录当前卡片、首页内部滚动与外层预览页面位置；返回时恢复原卡片焦点、筛选和浏览位置。重绘选中卡片不改变首页内部滚动。若用户另行筛选、原卡片已不在结果中，则回到首页搜索入口，不恢复已被筛掉的条目或撤销新筛选。预览状态切换/收藏直达等没有原卡片来源的入口继续使用首页回退。
- V06服务页编辑需求、填写关闭说明或重开条件时，顶部返回与底部返回原先会直接丢弃填写。本轮仅有实际改动时使用现有底部弹层样式确认；未改或改回原值可直接返回。继续编辑、Esc及点遮罩都保留原填写，放弃后才离开；提示不等同保存。打开通知和重置也使用同一保护，刷新/外部跳转由原生离开提示保护。保存及确认业务操作仍须明确点击原按钮。
- 保护只保存当前界面的输入，不增加自动草稿、真实提交或刷新恢复承诺；不改变关闭/重开的状态规则、旧申请隔离和合成时间。固定按钮、胶囊安全区和通知浮钮沿用当前实现。

## 参考与适配

[NN/g滚动位置建议](https://www.nngroup.com/articles/saving-scroll-position/)说明从静态列表查看详情再返回时，保留位置可减少重复查找；同时提醒内容或任务改变后不应盲目恢复旧位置。本项目在原卡片仍符合当前筛选时恢复，否则使用搜索入口。[W3C模态对话框规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)要求关闭后返回合理焦点，重要退出默认落到较安全的操作。本项目复用服务页现有底部弹层，默认“继续编辑”，保留键盘循环和退出反馈，不照搬其它平台视觉。依据公开资料，不声称实际体验最新版应用。
