| 组件 | 结构 | 必须交付的状态/边界 |
| --- | --- | --- |
| 导航/操作底栏 | 首页、发现、发布、服务、我的；发现用线性指南针，服务用统一包形图标 | 当前项、未选项、未登录跳转后返回；发布不直接提交；轻按缩放后复位；减少动态效果时禁用缩放；底部安全区与最后内容留白 |

| 商家主帖卡 | 封面、标题、经营名称、服务范围 | 骨架/缺图/长标题/失效/风险下架；双列瀑布流；只展示审核通过且当前可展示版本 |
| 商家主帖编辑 | 1—9 图、封面与排序、标题、正文、只读经营资料 | 无资格/可编辑/校验失败/提交中/待审/驳回/已发布；普通用户和待审核商家不能提交；不采集主帖电话、微信或详细地址 |
| 主帖版本状态 | 当前已发布版本、待审新版本、驳回结果、风险处理记录 | 待审期间旧版继续展示；批准原子替换；驳回保留旧版；高风险内容可立即下架且留痕 |
| 搜索/筛选 | 关键词、业务、村社区、最新 | 初始/筛选中/无结果/失败/下一批；组合条件保留；不搜索私密地址或草稿 |
| 优选卡 | 标题、较大公开图片、名称、项目、查看资料 | 无有效对象/图片失败/加载；付费标记差异门禁；不称评分担保 |
| 双列需求卡 | 题图、最多两行标题、对应金额或面议 | 缺图/失效/加载/长标题；不绘制位置行，不泄露详细地址 |
| 需求图文区 | 说明标题、整宽大图、正文 | 多图/零图/加载失败/长说明；不覆盖文字到图片上 |
| 联系与资料 | 打码字段、申请/授权说明 | 无申请、待处理、已授权、24小时冷却、失效；首次登录不直接解码 |
| 候选与费用 | 昵称、报价、意愿和上限标签、草选 | 未选/草选/提交中/报价变更/申请撤回/结果未知/成功；不垫付不能有上限徽标 |
| 三维评分 | 三项各5星、可选图文 | 初始无预选/不完整/提交中/成功/无资格/已过期/一次修改用完；失败不清空 |
| 个人资料 | 头像占位、昵称、登录/资格、核验提示 | 访客/已登录待核验/通过/失败/服务不可用；成功必须来自服务端结果 |
| 我的交易/工具箱 | 四入口、收入位置、三工具行 | 仅本人、空记录、错误、过期收藏；收入未知不得显示假数据 |
| 通用反馈 | 骨架、空态、错误、禁用、二次确认 | 给原因与重试途径；颜色不单独传递状态；加载和禁用不能混同 |

## 状态不能简化为三个步骤

联系授权按 CT03—CT09逐人逐信息生效；拒绝/撤回后冷却、信息结束恢复打码。跑腿按 RUN01—RUN12覆盖待承接、未承接超期、履约中、待确认完成、争议、完成及取消。异议停止自动完成计时；完成不等于线下付款成功。变更/取消/费用协商独立记录，不能点击按钮立即覆盖旧任务。

评分按 ER/RA/RS规则，数值有效和图文公开各自显示。先确认实际资格，不因为画了提交评价按钮就允许提交；无图文不产生空审核任务。推广审核、支付、权益、退款各自独立，不能一个“成功”文案代替所有结果。

## 可供 UI 使用的数据

公开：合法标题/说明/公开题图/村社区/允许公开的服务项目、合法评分；本人：自己的草稿、收藏、地址簿、申请及历史；当事人：服务端授权后必要联系、任务快照；运营：按职责必要记录和汇总。页面只接收获准字段，不能先把全部信息下发再用 CSS 隐藏。

content.json 的示例只用于设计预览；开发数据不写真实姓名/村名/门牌/证件，也不将设计价12/15/50写成默认表单值。居民普通图片最多9；商家基础主帖为1—9图、标题≤20个可见字符、正文≤1000个可见字符；推广/评价最多3、回应不配图。失败保留表单，先校验、再安全检测、再按资格提交。
