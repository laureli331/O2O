# 视觉实现规范

## 基准与数值来源

[当前选定图](../../assets/ui/selected-20261009/overview.png)为 1086×1448 总览，不是五个独立设备画板；图上页码、信号栏和微信胶囊是示意，不能照搬成固定像素。评分页页签旁多余状态栏痕迹属于生成图残留，实现时不绘制，选定原图仍原样保存。

[变量](../../assets/ui/development-handoff-20261009/design-tokens.json)将来源分成三类：历史明确变量（主绿/米白/炭绿、小圆角和字体层级）；本轮明确视觉表达（红色价格、黄色提示、灰色资格说明、居中个人资料、双列需求和大优选）；实施候选（具体语义色和页面适配数值）。这些候选不是用户逐个批准的 RGB，也不是从图片测量的结果。

采用 375 逻辑像素宽作为实施标尺，比例样式按 750 rpx 标尺生成；固定图标描边与文字字号使用 px 基线。实际窗口和字号适配在实现阶段验证，不能把 1086 总览宽度代入页面换算。基础库版本与渲染器尚未在交接阶段选定。

## 色彩与字体

源色保留柔和绿 `#618872`、浅米白 `#FCFBF7`、深炭绿 `#263A31`。用户已经明确允许绿/黄/红状态色，原“三色”约束不能再禁止这些语义颜色。文本不能仅靠颜色表达状态，配文字和状态图标。

| 角色 | 原提示词色 | 本交接文字色候选 | 说明 |
| --- | --- | --- | --- |
| 价格红 | #AA655F | #9B514C | 加深但保持低饱和，金额不再用绿色 |
| 黄色提示 | #A38B56 | #806C3E | 小字用深赭黄，不用刺眼亮黄 |
| 中性辅助文字 | #858B87 | #68726B | 核验说明、普通元数据，不代表禁用 |
| 浅绿标签字 | 主绿 | #365C49 | 配淡绿底；候选 B 垫付与上限一致 |
| 主按钮字 | 米白 | #FCFBF7 | 按钮填色需另行检查文字对比度 |

候选金额、提示和灰字在米白背景上计算对比度不低于 4.5；这是本地数学检查，不能代表毛玻璃、照片和真机所有场景已满足。按钮保持绿色渐变，但使用较深候选端点以保证按钮字可读。已采用原图不重绘；实施候选须在开发版中比较后确认。

系统中文无衬线，不打包未授权字体；系统不同导致字宽不同时允许自然换行，不缩字塞图。沿用 26/18/16/13 px 标尺和 400/500/600 字重。标题与辅助信息分别处理；金额使用独立数字/单位节点，便于实现颜色例外。

## 布局、层次和图片

- 页面安全区、顶部胶囊与底部遮挡由实机信息决定，禁止硬编码截图的 9:41、胶囊位置或信号图标。
- 沿用历史外边距32、区块间距36、卡片内边距24逻辑像素作为起始标尺；双列较窄卡片用单独16候选内边距。数值可在实机校准，不能用减少点击区域和字号解决拥挤。
- 主图为整宽大图，图下显示说明，不加覆盖图片的区域/示例条。没有图或加载失败用统一占位图；有真实已获权限图片时展示真实图片，不能将视觉稿“全占位”理解为生产禁用照片。
- 优选标题首行居左，较大题图与服务资料/查看资料分列；列表双列。手机纵向滚动，最后内容不能永久被底栏遮住。
- 个人区使用58px居中头像和紧凑昵称行，16px编辑SVG保留44px点击热区；登录/资格紧随昵称并保持独立语义。资格待核验黄色；收入在“我的功能”标题行居右，全行黄色，包括金额和元。“我的收藏”在功能区之后，以三图横向预览展示且不加“最近收藏”副标题。
- 所有底部服务入口使用同一包形图标；不恢复拼图或星形图标。中央发布为加号，但导航行为另依 V04，不能默认一按发布。

## 毛玻璃、渐变和微质感

玻璃集中在底部导航和操作托盘，不对文字施加模糊。默认可回退为半透明米白加边框/轻阴影；背景模糊是否支持与性能必须在选定渲染器和真实设备验证，不能仅写 backdrop-filter 就宣布完成。基础样式故意没有未经验证的滤镜依赖。

绿色背景柔光和按钮渐变、轻阴影保留。静态噪点为纯装饰资源，默认叠加透明度0.015；不盖文字、不动画、不增加真实定位。叶片氛围可用后续可编辑装饰资源补齐，本包不从生成总览中抠出被卡片挡住的叶片冒充完整原素材。
