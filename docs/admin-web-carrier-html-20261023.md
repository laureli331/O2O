## 参考与适配

参考 [Ant Design 布局](https://ant.design/components/layout/)的稳定侧栏、层级与响应式原则，以及[工作台](https://5x.ant.design/docs/spec/research-workbench/)的短路径思路。这里只借鉴公开设计原则，未声称体验其它平台后台。项目沿用绿灰色调、圆角和轻按反馈；队列与证据不随页面切换丢失上下文，危险动作继续核对对象与影响。

## 实现边界

V15 继续使用原业务模型及账号能力、独立限制、终态重开、费用与退款、故障保护规则。本次增加网页承载与搜索/分栏，不改模型。V16 新建合成配置模型，不预填虚构地区或服务人员；所有新项目必填依据和变更原因，佣金初始快照取已确认四类标准。

V16 采用固定合成时钟 2026-10-23 10:00（北京时间），未来生效校验基于此时钟，不是实时生产时钟。演示会话保存30分钟；未知请求可刷新恢复，只查询原编号，不重复生成版本。失败、非管理员、旧版本冲突不写入配置或成功日志。

两端共用真实后端是已确认架构目标。当前 V15 与 V16 仍是各自的合成状态，V16 日志展示本页配置变化、V15 日志展示处置变化；不冒充统一生产日志或 V14 联动。未接入真实账号、支付、通知、CloudBase、托管、数据库或自动生效任务。
