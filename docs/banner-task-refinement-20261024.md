# 广告管理、订单与统计任务式整理

2026-10-24。承接用户继续优化前序HTML的要求，范围是V11—V13的展示层和小交互；沿用此前已确认的状态驱动管理、当前期与下一期独立、先审核排期后付款、退款终止与未知查询规则。不改模型、不启用真实广告或资金操作。

## 实施与取舍

- V11审核进度保留广告摘要及一张状态/时间线卡，合并大图标介绍卡和进度卡的重复说明；退回原因在对应步骤完整显示，修改稿仍明确原广告继续展示。首页退回原因与编辑恢复路径保留。
- V12订单卡集中显示当前状态、金额、周期、排期、实际开始和保留截止；取消顶部重复状态介绍。退款场景优先显示广告摘要及退款金额/进度，原订单金额和全部字段在下方保留，避免把原实付误当预计退回。待核实退款的查询操作固定到底部，内容区不重复放同一按钮。付款及退款前的重要核对不删。
- V13更换日期或趋势指标后保留内部滚动位置，并恢复对应控件焦点；短内容导致可滚动高度缩短时按浏览器实际范围夹取。原三指标、零曝光不计算点击率、未知不填零、截至时间和口径说明保留。

选择局部合并与位置保持，沿用现有页面和事件；不增加新向导、第二套队列或广告功能。重排只改变阅读顺序，不改变提交、付款、终止或退款事实。
