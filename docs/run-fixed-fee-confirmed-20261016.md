# 跑腿固定服务费与 V03 界面审阅确认

日期：2026-10-16。用户批注“跑腿申请者，不可修改服务费报价”；经明确询问“直接接受发布者金额，不允许自行报价”或“首次可以报价，提交后不能修改”，用户实际选择：**直接接受发布者金额，不允许自行报价**。

## 验证方案

核对跑腿发布、申请、候选、选定及计佣的金额来源都为发布者服务费；同需求候选不出现自行报价差异。校验只读显示并不足够，提交逻辑也不能采用申请者篡改值。再核对维修/其它预估选填、跑腿垫付正数上限、申请唯一及排序、时间接受和计佣标准不误改；浏览器检查标签位置、头像、后置状态提示、确认与窄屏；运行相关与既有测试后提交。

## 金额规则

跑腿从多人报价改为多人申请、发布者选一位。发布者填写明确正数服务费，申请者只读并明确接受，不能首次自行报价或修改该金额；同一需求当前金额版本相同。原“服务费预算/报价”字段或历史名称不能继续解释为允许申请者另行出价。选人前可修改本人说明、是否愿垫付及上限，或撤回；修改保本次首次有效时间，重申用本次新时间。选定时重新核对发布者金额与当前时间版本，过时版本不直接确认；实际改价仍须按既有双方约定规则，不新增单方改价权限。

跑腿15%且无佣金封顶、材料/货款/垫付不计佣、主动月结、唯一承接及联系权限均保持原规则。用户批注“不封顶这几个字不需要”仅移除界面重复字样，不批准佣金上限或费率变化。维修/其它申请预估仍选填，正式费用按阶段双方确认。

## 其余已授权界面调整

跑腿申请页标题为“申请接单”；左右任务卡的业务标签放在标题下。状态提示移到表单后，写“你已申请，正在等待发布者选人。”或“申请已更新，等待发布者选人。”候选卡加入通用头像占位，不伪造真实用户头像。

“新时间待接受 · 不可选”表示发布者改变了服务时间，候选人还没有接受新时间，因此发布者暂时不能选他。保留该权限规则，提示改为“还未确认新时间，暂不能选”，不把说明问题当作自动同意时间。

## 后续界面审阅（优先于上文早期布局）

用户再次批注并明确确认：已有申请标题改回“修改申请”；业务标签放在需求标题旁同一行。跑腿服务费用静态摘要，不用输入框样式；去掉“发布者填写 · 不能修改”和候选卡重复的固定金额，状态提示居中。时间版本仅内部处理，不向用户展示T1等编号；上限文字写“封顶30元/封顶20元”，实际仍按原整次服务单位计。配置异常提示用户联系开发者，不显示内部缺项、不捏造联系方式。跑腿发布者定价及接受/版本校验规则保持。
