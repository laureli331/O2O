# 评价关联事项识别与列表预览

日期：2026-10-24。按用户三张截图实施；公开列表范围由用户补充确认。

## 参考与适配

查阅[闲鱼收到的评价入口旧版图文](https://jingyan.baidu.com/article/cbf0e5007341d06fab289320.html)，文中标注2024-01-11、闲鱼v7.13.90，展示个人主页进入评价的路径。另查阅[2020年闲鱼产品分析](https://www.woshipm.com/evaluating/3635186.html)中的交易评价模块。它们属于第三方历史资料，不作为已体验当前闲鱼界面或现行业务规则的证据。本轮首图与原标题绑定、正文预览的具体排布是结合用户明确要求和本项目现有风格作出的适配。

## 已实施

- V17 列表和详情展示原历史事项首图、标题，仍为合法历史只读。
- V18 待评价、我评价的、收到的、首次填写、修改、回应、本人详情显示同一关联事项的首图和标题。新增评价成功时保存对应来源快照，不接受表单伪造来源标题。
- 我评价的和收到的直接展示正文最多三行、三项评分、图片数量、时间和状态，详情查看完整内容。作者看到当前版本；收到的只看到已审核合法内容，未审的新版本不会替代旧合法公开文字。
- V19 按用户答复不展示关联需求首图或标题；卡片提供明确“查看详情”，进入已有评价详情，不增加私密订单字段。
- 演示首图使用既有合成SVG。缺少原图不借另一单图片；旧合成会话仅对身份与原记录匹配的已知示例补齐图片字段，不修改评分或审核状态。
