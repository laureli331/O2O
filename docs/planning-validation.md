| D03 | 检查年龄门槛及覆盖范围 | 跑腿发单/接单、维修求助、二手发布均须满16周岁；未满16岁只浏览公开信息；16—17岁不被自动视为成年人。 |

| D06 | 区分联系许可与成交 | 跑腿选定接单者并正式承接后解码；维修/二手申请联系获同意后定向解码，确认联系对象不被写成已成交。 |
| D07 | 检查跑腿承接与费用 | 同一用户可发单和接单，多人申请报价、发布者选一人，确认最终服务费；自愿垫付及其上限在承接前确认。 |
| D08 | 检查完成与取消 | 完成申请后24小时无确认且无异议自动完成，有异议人工处理；承接后取消须双方确认，已发生费用先协商；取消不等于结清。 |
| D09 | 检查资金与准入边界 | 平台不代收或结算跑腿费用；自身广告费与跑腿费用区分；没有将线下付款、年龄门槛或湖南说明写成项目已获准上线。 |
| D10 | 核对咨询草稿 | 统一业务说明同步年龄、联系方式、每类3个广告名额、7/30天期限、固定展示、先审核后付款、实际展示起算、满额暂停、排序、24小时审核以及到期和续购，以及15分钟名额保留、自动展示和修改复审；同步目录/推广联系申请、专用联系方式字段和修改拒绝流程；多名联系人、权限撤回和每人同类占位上限按主记录确认，未写成订单多人承接；微信咨询保留项目支付分类和付款后异常处理问题；草稿未被写成已发送或获答复。 |
| D11 | 检查文档完整性 | UTF-8可读；内部相对链接存在；不残留“本文件仅在临时目录、未改项目文件”等错误描述；未决事项明确列出。 |
| D12 | 核对Git交付 | 本轮只纳入两份文档；git diff --check通过；创建对应提交，并确认提交后工作区状态。 |
| D13 | 核对虚拟支付证据及边界 | 区分已认证个体工商户开通规则、个人工具路线限制、推广权益分类推断及本项目未获官方确认；iOS不支持开发者主动退款，普通退款提交不等于成功；现行费率与适用类目/标准费率分开，不把月末后45—60天写成每笔支付后固定到账；没有执行代码接入、开户或真实支付。 |
| D14 | 核对最新三项选择 | 虚拟支付方案以微信确认适用为前提，用户认可不等于官方批准；所有终端统一先审核后付款，期限从实际开始展示时起算；同类3个名额满额暂停购买，空出再开放，无后续时段预订；不把并发及超时支付异常等未决细节写成已经确认。 |
| D15 | 核对推广排序、审核及到期续购 | 按本轮实际开始展示时间排序、先开始排前；推广资料提交后24小时内给出审核结果，不能混为跑腿24小时自动完成或24小时值守；到期自动撤下仅影响付费位置，保留免费资料；客户手动续购且重新审核，无自动扣款，不擅自确定同时间排序、超时支付处理或修改申请撤回规则。 |
| D16 | 核对名额保留、自动展示与修改 | 审核通过后点击购买才保留名额15分钟，已满额不能购买，超时未付款释放；保留名额纳入3个位置的容量控制；系统确认支付成功后自动展示，从实际展示起算；修改审核通过后替换，审核期间原内容继续展示，期限不重置。超时释放须核实支付，迟到支付确认、已付款未展示及修改申请撤回等仍为未决，不承诺iOS自动原路退款。 |
| D17 | 核对目录联系方式及修改拒绝 | 免费服务人员目录和付费推广对所有访客打码，申请联系获服务人员同意后定向解码，无公开完整业务电话例外；电话、微信号只填专用字段，正文和图片不放。推广修改拒绝时有效期内保留原内容、告知原因、由客户重提交，期限不重置；内容识别和处置仍待设计，不误写成逐帖人工预审或已实现自动检测，多名联系对象、撤回权限及每人占位上限按D18已确认规则核对，不擅自确定具体通知或关联账号识别机制。 |
