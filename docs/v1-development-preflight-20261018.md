## 3. 已采用架构下的技术方案

已采用原生微信小程序＋TypeScript＋Node.js云函数＋CloudBase，管理入口在小程序内，本人及伙伴共用本人管理账号。这里只提出实际实现边界，不重问已采用架构，不杜撰集合、接口或SDK版本。

| 选择 | 优点 | 代价及验证条件 | 当前建议 |
| --- | --- | --- | --- |
| CloudBase传统文档数据库 | 沿用云开发方向，服务端事务可覆盖多文档关键状态 | 需按实际SDK验证事务限制、文档定位与冲突重试；不能在事务里发模型/支付等外部副作用 | 首选待审，尚未选定实际模式 |
| CloudBase PostgreSQL | 约束与关联查询适合账单/事件等关系数据 | 权限、事务、存储API和迁移路线另核实；不得混用传统模式接口或假设原SQL接口支持事务 | 备选，不在本轮自动切换 |

[官方事务说明](https://docs.cloudbase.net/database/transaction)的检索摘录确认服务端Node SDK和文档定位限制，但本轮直接正文抓取失败。编码前须取得完整接口/版本依据并在实际环境验证。

运行时发现：CloudBase配置文档仍列Nodejs20.19为推荐，22.21/24.11为公测；[Node官方](https://nodejs.org/en/about/previous-releases)已列20为EOL、22/24为LTS。不能自动选Node20，也不能把本机Node24等同云端可用。候选为仍受维护的22/24，最终运行版本、SDK/CLI和锁文件均待实际环境核实，当前留空。

### 3.1 关键业务的实现与验收边界

| 领域 | 实现要求 | 产品验证必须观察到 |
| --- | --- | --- |
| 登录/身份/手机号 | 服务端分别校验；核验失败或未知不记成功，16—17适用条件仍需证据 | 未登录、未满16、身份变更、手机号未验分别无法绕过；不刷脸不存原始完整证件 |
| 申请/选人/闲置确认 | 同一当前版本原子地决定唯一有效承接/交易；操作者及身份去重服务端校验 | 两个并发选定最多一个成功；旧金额/时间版本被拒绝；自接/自评被拒绝 |
| 到期/延期/故障保护 | 持久化服务端时点；定时器只负责唤醒，读取和扫描均能补偿 | 到期不额外加72小时；重复扫描不重复结束/计佣；停机恢复保留合法异议和故障保护 |
| 费用/佣金/账单 | 整数分、原锁定快照、唯一主计佣记录、调整差额及支付分配分别记录 | 重复事件不重复计佣/实缴；原账单不覆盖；佣金实缴不当居民货款付款证明 |
| 自营充值/购买/退款 | 外部付款事实、充值本金流水、消费和权益批次分别核对；未知先查证 | 不能凭前端成功增加本金/次数；重复回调只生效一次；退款与权益处理不产生重复返还 |
| AI请求/次数 | 明确请求/表单版本、资格、候选状态与实际模型用量；额度消耗和供应商成本分别记录 | 技术失败不扣用户次数但实际供应商成本如实记；需选择需求不当可用草稿；重复点击不重调 |
| 私密文件 | 公开图、待审图、凭据/执照分权限，读取时检查当前业务授权 | 直链/转发/撤权/到期逐项测试；临时URL仍可用时不能宣称撤权即时生效 |
| 运营及日志 | 仅本人管理账号，日志归登录账号；不记录原始证件/模型原文/密钥 | 普通用户直接调用也被拒绝；共用账号不虚称识别具体自然人 |

异步通知/模型/支付等外部动作放在数据库原子状态之后，以可重试事件/对账补偿管理；事务重试不得重复发外部请求。逻辑模型复用PRD第13.3节对象，不提前写未核实接口名。

私密文件若现有临时URL无法满足撤权要求，需评估服务端受控读取及成本，不靠前端隐藏；不承诺删除用户已另行保存的副本。备份恢复要同步应用删除/撤权记录，避免恢复已删除敏感数据。

这里明确数据类别、用途和访问边界，具体期限未获证据的不填统一90天或永久。[个人信息保护法全文](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_04a0f1fb5df244e39688fd5372623a8d.html)关于告知保存期限、必要最短时间的要求是核对依据；本项目是否还适用交易/账务/安全日志等其他留存要求需逐项核实，不能用一条通用原则替代。

| 数据类别 | 当前用途与可见范围 | 期限/删除方案的具体缺项 |
| --- | --- | --- |
| 原始姓名/身份证 | 经必要授权仅用于核验传递，自有库/普通日志不存，不上传证件照/人脸 | 供应商处理/保存、请求链路日志和传输协议待核实；不把“不入自有库”当成供应商不留存 |
| 核验状态/年龄资格/去重标识 | 资格复用、防自评及必要去重，受保护，非运营日常公开资料 | 有效期、身份变更、注销保留依据；免费次数去重用途须本次单独确认 |
| 手机号/微信/私密地址 | 仅按当前合法联系/业务授权开放，结束后关闭对方地址权限 | 本人管理、历史业务必要留存、撤权后文件/缓存和注销删除时点 |
