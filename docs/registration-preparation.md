# 永兴县个体工商户注册准备清单

更新日期：2026-10-07。用于本次申请准备，不是登记机关的官方材料清单。系统专用模板和永兴县实际审核要求优先。当前尚未提交申请、取得营业执照或确认完整业务准入。

## 一、已确认的申请情况

- 经营者：你本人，已满18周岁；组成形式为个人经营。
- 地点：湖南省郴州市永兴县湘阴渡；按系统现行行政区划与产权证地址核对，不擅自修改证载地址。
- 候选场所：父亲名下、有房产证的自建住宅，父亲同意提供使用；拟无偿使用。
- 使用方式：自己办公，不接待客户、不存放货物。
- 业务：通过微信小程序提供本地生活服务信息发布与撮合、付费推广展示，不代收居民交易款。
- 账号路线：旧个人账号和cloud1保留作受控测试，拟另注册个体工商户小程序。此文不授权改名、注销或购买资源。

## 三、可能需补充，尚不能认定全部必交

1. **住宅用途证明**：住宅改为经营性用房可能涉及有利害关系业主一致同意。父亲授权借用不等于其他利害关系人同意；谁属于利害关系人、如何证明，需要当地确认，不预设只需父亲签字。
2. **自建房安全相关材料**：是否需要场所证明、安全鉴定或其他核验，以及具体办理顺序，以实际业态及地方有效要求确认。仅一人办公不构成已获豁免的证据；也不要现在就付费做鉴定。
3. **共有产权材料**：如果证件显示共有权人，需核实其授权要求。
4. **地址不一致材料**：证载旧行政区划与系统新名称、证载村组地址与实际地址如有不一致，核实是否需要地址对应证明；没有门牌号不能编造。
5. **许可或批准文件**：只有实际选择或开展的业务依法涉及许可时按规定准备。当前没有依据要求添加食品、维修、配送等直接经营许可。
6. **委托材料**：本人办理通常不需要委托代理人材料；如改为代理办理，再按系统准备。

这些项目不是要求你现在全部开证明。进入“申请材料”页查看实际附件清单和官方模板，再确认缺项。不得将尚未核实的要求描述为永兴县已确认要求。

## 六、办理顺序与提交前检查

1. 拿到身份证、房产证信息，确认房屋使用范围、期限和实际地址。
2. 主申请先暂存；查看“申请材料”页附件清单及模板。若系统必须完成前项才能查看，不编造未知值绕过。
3. 核实住宅/自建房材料、互联网经营与地址选项、经营范围覆盖、无字号平台适用；仅补实际必要材料。
4. 填写材料，产权人和经营者分别真实签署；实名或扫码由本人完成。
5. 最终核对名称、经营范围、地址、使用权、金额/面积/人数及全部承诺内容；由用户明确确认后提交。当前没有最终提交授权。
6. 有补正通知时按具体要求修改，不虚构许可或地址。保留申请编号、材料版本和审核结果。
7. 获照后核实税务信息及申报义务、年报安排，再注册新小程序并核实认证/类目/备案/支付等条件。获照不等于产品可以商业上线。
