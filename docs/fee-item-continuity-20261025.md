# 阶段费用：增删项目保留其余填写

2026-10-25。延续已确认的前序页面优化，修复V07-I动态增删费用项目时的输入丢失；V04发布流程进行回归，本轮不改发布实现。

## 实际问题与处理

- 原添加/删除项目会重建整个详情，只恢复阶段名称和费用行的文字。已选择的凭据、垫付意愿和上限会丢失，并回到详情顶部。专项用例已复现添加项目后垫付意愿恢复“不愿意”。
- 现在只添加新行或移除指定行，保留其它行的原文件选择控件，以及阶段和垫付字段；不复制或重新选取用户文件。编号、无障碍名称、凭据标签和删除按钮索引同步更新，文件仍归属存活的原项目。
- 新增后定位新项目名称，删除后定位相邻项目名称；不重建详情或强制回顶部。保留1—20项限制，小计按当前项目重新计算。删除某项只移除该项，保留项的金额、备注、类别及本地凭据不变。
- 只修复当前编辑中的连续性，不新增跨页/刷新草稿、真实上传或费用自动生效。服务费/实际支出分类、累计上限、垫付约定和另一方明确确认规则不变。

## 参考与适配

[GOV.UK表单校验指导](https://design-system.service.gov.uk/patterns/validation/)强调保留已填内容，避免重复输入。本项目将该原则用于动态项目操作，复用现有行样式、费用汇总和固定提交区；不新增确认步骤，不改已确认的交易模型。此处为基于公开规范的项目适配，不声称实际体验其它应用最新版。
