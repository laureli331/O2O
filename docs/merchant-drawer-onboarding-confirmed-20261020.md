## 1. 商家快捷抽屉

- 抽屉位于“发现”页，是商家专用的快捷功能面板，不在抽屉内直接发布帖子。
- 头像与昵称沿用当前居中布局；头像和昵称所在的资料区整体作为商家主页入口，入口文案为“查看主页”。
- 数据区只显示“订阅”和“收藏”，不再与它们并列显示“帖子”；帖子数量及相关状态放入“帖子管理”。
- 主要功能入口包含“帖子管理”和“经营推广”。“经营推广”承接平台可向商家提供的经营、盈利和推广能力；内容加热仍按既有决定先观察真实发帖数据，第二版酌情评估，不因本入口名称而提前启用。
- 抽屉底部固定为“客服 / 草稿 / 设置”。优先复用现有 SVG；确无对应图标时再补充资源。
- 抽屉不保留“发布帖子”和独立“预览商家主页”按钮。
- 商家经营消息拟从抽屉移至“发现”页右上角；消费者服务消息拟在后续放到“服务”页右上角。两处消息的字段、分类和交互仍需后续单独确认。

## 2. 商家入驻流程

1. 申请人选择经营身份：持照门店/个体户，或无营业执照的独立服务者。
2. 不同身份提交不同的认证材料，并使用可区分的认证标识；无营业执照不自动阻止独立服务者申请。
3. 申请人填写并预览拟公开的经营资料，包括头像、名称、经营分类、服务项目、服务区域、联系电话、营业时间和图片等；联系方式是否公开须由申请人明确授权。
4. 平台先审核申请材料。审核中只能查看进度或补充材料；未通过时显示原因并允许修改后重新提交。
5. 审核通过后再收取99元／连续30天的商家入驻费；审核未通过不收费。购买页直接标注“连续30天”，不写成自然月。
6. 99元实际支付成功且入驻权益实际开通后，才正式开通商家身份、商家主页、快捷抽屉、帖子管理和已确认的商家基础工具，并从实际开通时起算连续30天。支付失败、取消、开通失败或结果未知时不得标记为已开通或开始计时，未知结果须先核实。
7. 不自动续费。有效期内可主动续费，新期限接在当前有效期之后；已经到期时，从再次实际开通时重新起算连续30天。

## 3. 收费边界

- 原“99元／30天商家工具会员”不再作为独立商品；其已经确认的经营宣传资料维护、主帖草稿与发布管理、活动与优惠券管理等基础工具统一并入99元／连续30天的商家入驻权益。
- 99元是按单个门店或独立服务者经营档案收取的商家入驻费；同一经营主体的多个经营档案不共用一份入驻权益。它不是帖子发布费、内容加热费、Banner费或平台交易佣金。
- 审核通过商家的基础图文主帖仍可免费提交，不因收取入驻开通费而改成按帖收费。
- 加热、置顶、推荐位、Banner、会员或其它经营推广服务如未来启用，须按各自已确认或待确认规则另行计费；入驻费不包含这些权益。
- 真实收费前仍须完成项目适用的主体识别、代表授权、分类资质、支付能力、退款/撤销、重复支付、对账、发票/凭证和异常处理核实。本轮没有授权立即上线真实收款。
