# 服务订单中心 HTML 预览

文件：[services.html](../previews/services.html)。本地地址：`http://127.0.0.1:8765/services.html`。

依据[当前确认](service-order-center-confirmed-20261021.md)，服务页承载V06“我发布的”和V07“我承接的”，不再有维修/跑腿人员目录。V23发现预览使用`v23.html`，旧`v06.html`仅兼容跳转，文件名与页面编号保持一致。

- 我发布的：普通用户发布的四类需求/闲置、申请处理、发布管理及双方交易。
- 我承接的：本人申请、正式承接和闲置买家交易，申请中不等于已承接。
- 按业务/状态筛选；右下角悬浮消息按钮支持查看单条或全部标为已读，有未读才显示角标；入口为56px圆形按钮，避让底部导航与固定操作区，列表底部预留滚动空间。
- 未选人的发布可编辑、关闭，关闭后可主动重开；旧申请不恢复，已售只能复制新草稿；保留原发布时间与各轮历史。
- 列表使用84px首图、标题、状态、金额与关键时间/申请进展；已结束卡片弱化按钮，不重复展示发布时间和订单角色（闲置买家必要标识保留）。四张本地SVG为合成演示首图，不代表用户上传图片。
- “查看订单”一次进入`v07.html`完整详情，带入业务、状态、标题、说明、金额和本人角色；专注订单模式隐藏预览索引及重复列表，直接展示约定、时间、对方资料、费用明细与本页历史；返回保留分栏、筛选及滚动位置。
- 待接单需求详情显示首图、内容、时间和申请进展，底部固定“更多 / 编辑需求 / 查看申请”；关闭、撤回等次要操作收进“更多”。交易详情固定“更多操作 / 费用详情”，更多操作按当前状态展示；二级操作返回订单详情，详情返回服务列表。
- 详情及通知页隐藏底部五栏导航。通知的“全部 / 未读 / 全部已读”固定在标题下方，小程序胶囊安全区外；已读不删除记录，未读为0时禁用全部已读。顶部增加“多条通知”演示，以30条合成通知验证长列表。
- 既有预览底栏“服务”及V05发布/承接快捷入口均指向本页。

顶部可切换正常、游客、无订单、失败保留内容和加载中。均为合成演示，只保存在本页内存；跨页面未连接同一真实记录，刷新重置，不发送消息或创建真实交易。

本次布局依据与ASCII见[页面优化方案](superpowers/specs/2026-10-21-service-pages-refinement-design.md)。
