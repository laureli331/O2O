# 服务订单中心 HTML 预览

文件：[services.html](../previews/services.html)。本地地址：`http://127.0.0.1:8765/services.html`。

依据[当前确认](service-order-center-confirmed-20261021.md)，服务页承载V06“我发布的”和V07“我承接的”，不再有维修/跑腿人员目录。`v06.html`仍是V23发现预览，明确区分文件名与页面编号。

- 我发布的：普通用户发布的四类需求/闲置、申请处理、发布管理及双方交易。
- 我承接的：本人申请、正式承接和闲置买家交易，申请中不等于已承接。
- 按业务/状态筛选；右下角悬浮消息按钮支持查看单条或全部标为已读，有未读才显示角标；入口为56px圆形按钮，避让底部导航与固定操作区，列表底部预留滚动空间。
- 未选人的发布可编辑、关闭，关闭后可主动重开；旧申请不恢复，已售只能复制新草稿；保留原发布时间与各轮历史。
- 当前交易进入`v07.html`时带入业务、状态和本人角色，返回保留分栏与筛选。
- 既有预览底栏“服务”及V05发布/承接快捷入口均指向本页。

顶部可切换正常、游客、无订单、失败保留内容和加载中。均为合成演示，只保存在本页内存；跨页面未连接同一真实记录，刷新重置，不发送消息或创建真实交易。

模型/合同：[services-preview.test.cjs](../tests/services-preview.test.cjs)。浏览器：[verify-services-preview.cjs](../scripts/verify-services-preview.cjs)。本机证据保存在`.local/services-verification/`，覆盖四业务、两分栏、发布管理、权限、通知、各入口、详情角色与返回、320/375/414像素、键盘和减少动画。
