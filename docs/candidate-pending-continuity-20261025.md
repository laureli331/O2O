# 选人待确认：保留原操作并说明结果

2026-10-25。本轮沿用结果未知时先查询的已确认规则，完善V03合成预览。

## 问题与处理

- 已复现：选人结果未知时切换演示状态会重建会话，丢掉原查询。现在切换演示状态、切换业务或打开接单资料时保留原业务、候选和状态，使用现有结果层引导查询本次操作；查询明确后可继续操作。
- 未知及已选定期间，申请输入、垫付选项和确认项暂不可修改，避免填写了却无法保存。提交、撤回、正式选人处理器也检查待确认状态，不能通过重复事件改变原申请或再次选人。
- 申请者提示跟随实际结果：正在确认、已选定本人、已选定其他人，取代结果明确后仍等待选人的旧提示。
- 保留候选单选焦点修复、现有卡片与视觉、唯一选定、固定跑腿费用及原资格规则；不新增真实选人、订单或通知。本页刷新仍恢复初始演示，不声明持久化或完整跨V10返回恢复。本轮只保护上述页内切换及资料入口。
