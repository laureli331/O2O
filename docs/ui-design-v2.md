# UI 视觉设计 v2

日期：2026-10-06（Asia/Shanghai）

基于 [PRD v1.3](prd.md) 与用户对 v1 的明确修正：增加呼吸感，三色限制仅针对 UI，示例图片可自然彩色，米白底更浅，实际呈现渐变与毛玻璃。本轮已完成 image_gen 两次编辑。后续视觉基准采用 v2；[v1](ui-design-v1.md) 仅作为历史版本保留。

## 验证方案

1. 对照 v1 目视检查首屏记录量、重复说明与包围式卡片是否减少，区块间是否有可见留白。
2. 检查米白更浅、照片自然彩色、按钮有实际渐变、照片叠层和底栏有可见透明与背景柔化，文字不被高斯模糊。
3. 检查六页主要业务操作与权限：广告标识、联系打码、跑腿报价与垫付、选择一人、三维未预选评分、登录与资格分开。
4. 自动检查 PNG、源文件链接、三种 UI 源色与彩色照片例外、留白变量、渐变与毛玻璃参数、SVG 完整性、PRD 页面映射及 Git 差异。

命令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\validate-ui-design-v2.ps1
```

这些是视觉及资源验证，没有小程序运行或生产接口验收。留白比例是设计目标，没有伪称已经按像素测出百分比；位图色值和抗锯齿也不按三种 RGB 值计数。

## 人工复核

- 新版的重复说明和同屏记录减少；评分、详情和二手页有明显空白区。
- 更浅米白底；洗衣机、快递、红色自行车与木色书架为自然彩色示例图片。
- 主按钮可以看到斜向明暗渐变；维修照片的信息叠层透出模糊图像；底栏具有透明叠层与柔和阴影。
- 图文与正文未作高斯模糊；毛玻璃施加在背景与表面层。
- 电话继续打码；推广有广告标签；跑腿为发布者选人，报价与垫付分开；三维评分未预选；登录与资格分开。
- 生成图存在少量中文小字偏差，尚不作为精确文字排版稿。独立 SVG 文件是矢量源；图里的图标是位图表现。
