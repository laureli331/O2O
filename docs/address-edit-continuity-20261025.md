# 地址编辑：保存后接着操作

2026-10-25。承接私人工具的连续性优化，修复V09地址编辑的保存定位、选址模式取消及刷新保护。V05个人页仅回归，本轮不修改资料或联系方式业务。

## 实际问题与处理

- 原保存重绘地址列表后焦点落空，长列表里新地址可能在视野外。现在保存后聚焦本条“编辑地址”，必要时将其滚到可见位置；取消或放弃编辑返回原地址，退出空白新增返回新增按钮。延续既有列表位置，不强制回顶部。
- 原“演示任务选址”开关先改变，取消离开后仍显示新模式。现在确认前保留旧开关，继续编辑/Esc保留当前表单；明确放弃才切换，未保存内容不写入地址簿。
- 截图检查发现旧保存提示可能遮住后续确认说明；打开确认层时清除旧提示。离开确认改为“放弃未保存的修改？／继续编辑／放弃修改”，不再用没有保存按钮的“离开前保存修改？”误导用户。
- 地址内容与默认选项按现有初始值比较，有实际改动才请求浏览器原生刷新/外部离开提醒；未改或改回原值不提醒。校验失败不清除修改保护，不增加自动保存、跨刷新恢复或移动端关闭拦截保证。
- 本轮不改变默认地址唯一性、私人权限和选入任务后的独立快照；地址簿修改或删除不追改任务快照。

## 参考与适配

[W3C对话框规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)说明关闭后的合理焦点返回，本项目将完成/退出编辑后的焦点落在对应地址或新增入口。[MDN离开事件说明](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event)说明原生提醒用途和移动端局限，本项目只在实际未保存修改时请求提醒。沿用现有卡片与确认层，依据公开文档适配，不照搬其它平台视觉。
