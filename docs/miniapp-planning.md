3. 首期维修、跑腿、二手；招聘后置，待招聘资质核验。仅在微信生态经营，不另做公众独立网站或APP。
4. 居民信息发布、浏览免费。维修及二手最新流程为信息展示、意向人申请联系、发布者同意后向该对象解码联系方式，再由双方自行联系。确认的是联系对象，不代表已成交；未批准为维修及二手加入完整报价、履约、付款或完成订单功能。
