# 接单资料与认证入口恢复确认

接单多类别确认（2026-10-22）：接单资料补齐“维修／跑腿／其它”。三类时段各自独立，用户明确选择支持多选批量设置；概览列出各类摘要，保存前确认覆盖范围，未选类别不变，之后可分别修改。忙碌按类别分别设置，不自动串类；仅作提示，不引入预订/自动拒单或并发限制。见[本轮确认](provider-multicategory-confirmed-20261022.md)。本条覆盖此前仅维修/跑腿及仅当前类别时段的范围。

用户在讨论 V10 改版后的认证和信息管理缺口后，要求补回，随后选择完整恢复接单资料、服务时段与忙碌状态，保留取消人员目录的决定；同意发布者从申请卡查看公开接单资料。固定入口最终明确放在“我的收藏”下面。

当前入口：V05 我的收藏下方的独立整行“我的接单资料”→V10管理概览；资格继续复用V05-B/C，个人账号信息仍由V05-D管理。V10恢复本人维修/跑腿服务资料、选填图片与执照、选填时段、忙碌设置，不创建独立接单准入审批。资料未填不成为原资格之外的新申请门禁。

首页申请→V03；新申请必要资格不满足时临时保留当前需求业务、公开标题/费用/时间及本人申请输入，进入V05核验。核验满足后由用户明确继续回到原申请，不自动提交。有效资格复用；未知、失效、年龄不满足、身份变更中按原规则处理。现有申请的撤回/修改及既有交易处理不因选填资料缺失关闭。

发布者在当前候选申请卡点击“接单资料”查看公开介绍、区域、图片、时段、忙碌、限定核验状态及执照提交状态。联系方式到对应订单按原权限展示，执照原图及原始身份不公开；不增加目录联系或陌生人搜索入口。真实访问关系、资料存储、核验调用与文件安全必须由后续服务端实现，HTML只展示合成流程。

本决定覆盖[服务订单中心确认](service-order-center-confirmed-20261021.md)中对“服务资料/时段/忙碌管理一并取消”的范围。人员目录、找人入口、目录普通联系和目录经历评价继续取消；服务页继续为订单中心，商家内容仍在发现。旧决定与历史原话保留，不删除已有合法历史。
