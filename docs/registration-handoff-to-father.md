# 给爸爸及登记工作人员：个体工商户登记信息核对单

日期：2026-10-07。用途：爸爸协助联系当地登记工作人员时说明真实情况，避免申请信息被误填。本文不是官方表格，也不是已提交申请；之前线上表单只是草稿。请在提交前把完整申请预览发给经营者本人核对。

## 一、先说明这段业务

拟由我本人注册个人经营的个体工商户，通过微信小程序提供本地生活服务信息发布、撮合及付费广告展示。居民之间的交易款由双方直接结算，平台不代收、不代结算、不收跑腿佣金。不是由本经营主体直接开维修店、销售二手商品、经营餐饮或组织自营配送。

爸爸负责协助联系，不因此成为经营者或共同经营家庭成员。登记与经营责任对应实际经营者，不能为方便办理改成爸爸名下。

## 三、经营范围：先核实覆盖，不堆无关项目

目前线上草稿仅选：

- 信息咨询服务（不含许可类信息咨询服务）。
- 广告发布。

“广告发布”对应平台收费推广展示。信息咨询服务是否准确、充分覆盖用户发布生活服务信息及撮合，尚未得到明确结论。请工作人员根据上面的真实业务给出规范条目，并让本人确认最终范围；不能把“两个条目已选”说成“已经足够覆盖全部业务”。

目前没有确认对外承接软件开发、维护服务，没有确认由本主体直接经营维修、保洁、配送、餐饮、商品销售。不要仅为别人填得多或据说有优惠就自动加入这些条目。若工作人员建议新增，请记录条目、对应实际业务、是否涉及许可及理由，再给本人确认。

不得仅为方便登记，用“信息咨询服务”替代实际依法需要的许可。也不要只因为使用互联网就自动添加“互联网信息服务”“在线数据处理与交易处理业务”等许可项目。

行业分类草稿为：信息传输、软件和信息技术服务业 → 互联网和相关服务 → 互联网平台 → 互联网生活服务平台；经营类别草稿为其它类。最终由登记工作人员核对与主营业务是否一致，不等于微信服务类目或业务准入已经获准。

## 四、两个网络经营选项请分别解释

1. 主表“是否通过互联网开展经营活动”：真实业务通过微信小程序开展，不能为了填写住宅地址而虚假选择否。请确认系统是否将该字段用于网络经营场所登记、使用实体地址时应如何填写。
2. 经营范围窗口“仅通过网络开展经营活动”：草稿保持关闭，尚未确认湖南系统具体含义。全国规定把该标注与平台内经营者使用平台提供的网络经营场所登记联系起来，不能直接等同“业务在线上做”。

本次拟用实体住宅登记，没有取得电商平台出具的网络经营场所证明。若工作人员建议更换登记路线、改填网络地址或开启标注，请先解释材料要求和影响，交本人确认，不能将旧小程序链接随意当作经营场所证明。
