## 实际遗漏与修复：V08

既有回归通过后，补充走查复现了联系申请返回列表的原卡片焦点丢失；源码同时确认联系确认弹层只做遮罩和Tab循环，没有暂停预览外的重置/状态控制。跨V07返回原申请详情时，也没有恢复原操作按钮及详情位置；原返回偏移参数在进入详情时会被列表DOM的零偏移覆盖。

沿用已确认的原入口恢复和弹层隔离方式：

- 列表记住原申请、位置与外层阅读位置。原记录被当前筛选排除时定位相邻项，列表为空则定位当前标签；改变筛选或重置不沿用旧入口。
- 联系确认打开时暂停内外背景操作，保留原inert值；取消、Esc、遮罩及成功/失败收起后恢复原值。取消返回原按钮，危险动作仍须明确确认。说明文字关联原确认层，预览工具栏暂停时变淡。
- 从V07返回原联系详情，定位“提出交易时间/约定交易/查看当前订单”的原按钮与位置，再返回原列表卡片。保留收到/发出及状态筛选、首页来源；不导入其它用户记录。
- 滚动参数只接受0—100000的有限数，异常归零；原ID只在实际可见记录中匹配，不拼接成选择器。跨页面仍为独立合成预览，不伪造同步后的联系状态或交易权限。

参考[GOV.UK返回链接规范](https://design-system.service.gov.uk/components/back-link/)和[W3C模态弹层规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。适配现有手机预览的内外两个滚动区域、独立演示工具栏与原确认样式，没有新增页面或权限。
