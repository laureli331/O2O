## 打开与范围

直接双击[单文件HTML](../previews/v03.html)，或通过本地预览服务器打开。无需联网、构建或安装依赖；图标、样式、脚本及合成数据均在文件内。左侧为申请者本人，右侧为发布者；二者是明确分开的演示角色，不表示普通申请者有权读取所有候选。

- 跑腿：本人服务费报价、是否垫付、正数上限、说明、时间与规则知悉；可修改、撤回、重新提交。
- 维修/其它：说明及预估服务费选填，未填显示待协商；预估不是正式费用，不据此伪算正式佣金。标准为维修15%整次30元、其它10%整次20元；跑腿15%不封顶。
- 候选：发布者按有效申请时间查看，空说明不占行；时间版本未接受的候选不可选，点选只草选。
- 确认：当前版本时间、金额/待协商、垫付条件与锁定规则；本地模拟唯一选定，结果明确标注演示。
- 状态演示：正常、开始时间已过、报价已更新、确认结果未知、需求已关闭、欠费限制及配置缺失。未知后先查询，不直接重选。
- 候选评价仅演示对应角色入口与暂无评价，不造五星；V07不在本文件范围。

所有人员、金额、时间、已有申请与操作结果均为合成演示，不发送真实申请、通知或交易，不提供完整电话、地址或私密凭据。手机号/身份/实际通道、交易幂等和计佣生产条件仍须后续产品实现验证。状态选择器位于产品画板外，不是用户产品内的状态修改功能。
