幂等决策实现位于 `packages/shared/src/contracts/idempotency.ts` 并从共享入口导出。它只接收调用层已得出的载荷比较结果；同载荷时保留原 `CommandResult`（包括处理中/未知），不会自动发起新副作用。`parseCommandResult` 只检查输入形状、五态状态、错误类别和请求 ID 一致性，再构造仅含合同字段的对象；成功形状仍需业务/API owner 的服务端事实证据，处理中/未知仍需实际接口按原请求有权查询。新增的 `parseTrustedCommandContext` 也只是结构收窄：只有已由服务端认证与时钟适配器提供的值才能进入可信上下文使用路径；本函数本身不能证明该来源可靠。共享层无平台 API、DOM、云 SDK 或新运行依赖；自有代码保持 `strict` 且不使用 `any`。

本轮 F09 字段校验实现位于 `packages/shared/src/contracts/private-address-book.ts`，来源为 [PRD F09](prd.md) 与第 13.1 节普通文本规则，以及本轮用户确认的默认地址方案。联系电话只接受 11 位 ASCII `0`–`9`，不增加号码段判断。文本先去首尾空白，联系人、详细地址、备注按已确认的 Unicode 码点口径检查 1–20/1–200/0–100；一个由多个码点组成的表情修饰序列按其码点数计数。社区只要求非空，不擅自增设最大长度或地点白名单。备注可省略，省略时规范化为 `''`。默认值通过一个可空指针表达；删除当前默认地址后清空，不提升其它地址。以上纯函数不验证号码控制权/联系同意、社区服务范围、地址存在/归属、服务端授权、并发唯一性或物理存储。
