- 后端合同 BA01–BA13、BA15、BA16：本增量映射的是命令数据边界、可信事实分离、错误结果分层和金额整数分表示。它没有完成任何物理实现/能力实证项。
- 后端架构合同第4节第3–5项：用于界定可信actor/归属、操作与操作键范围，同键同载荷重放、同键异载荷拒绝及未知结果不自动重发。新函数只编码纯复用决策；没有选定载荷规范化算法、物理幂等记录或查询 API。
- PRD 的金额上限：99,999.99 元。本代码将其转成 9,999,999 分；此换算由测试覆盖。
- CloudBase 索引文档说明数据库支持索引管理，但未据此选择业务索引或唯一约束；CloudBase 官方 CRUD/Node 文档也不定义本产品端点。

## 未证明及后续归属

下列事项仍按原门槛保留，阻断 SP08 及其依赖功能的对应验收：

- CloudBase 实际安全规则与客户端/服务器身份适配；真实业务读写权限。
- 可信上下文各字段的实际来源、请求 ID 与调用/业务请求的关联、服务器时间可信度；本地形状解析不证明这些适配器正确。
- 业务对象的公开/私密字段拆分、具体数据对象/字段/集合、索引与所有权路径。
- BI01–BI10 全部唯一性、关系和跨对象不变量的物理实现及原子证据。
- TX01–TX12 业务读写集合、提交/回滚、并发与故障注入用例；既有 SP01 探针只覆盖它自己的合成记录。
- 业务状态迁移、可信服务器时钟、服务费/佣金/账单、付款/退款事实、未知结果的同请求查询及恢复。
- 幂等范围的可信构造、每个业务操作的载荷校验/规范化/等价比较、幂等记录唯一约束，以及幂等接受与业务写入同一致性边界的原子证明。
- 模块级输入策略仍未完整定义：除本轮 F09 字段外，操作 allowlist、其它字段长度及计数语义、payload/金额/资格规则、期望版本的操作级必需性与取值范围、基于服务器当前对象版本的冲突判断待各业务 owner 定义并写测试，不能从通用解析器推断。F09 的社区允许值目录未定；默认地址的逻辑指针与删除转换已验证，但物理唯一性、地址存在/归属、并发设置及删除/清理事务仍未验证。
- F03 标题/说明长度及计数规则尚未在共享合同实现；本次仅完成有明确金额语义的价格字段。交易履约时的双方金额一致、付款/退款事实仍由对应业务模块及后续真实验收证明。
