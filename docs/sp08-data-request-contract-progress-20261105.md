## 新增逻辑对象映射

- 交付：[SP08 对象归属与公开/私密快照映射](sp08-object-ownership-map-20261105.md)及 JSON 配套记录。
- 来源：PRD F01–F22、PRD 第3/13节，以及后端架构合同第3节的 Module 唯一事实所有者表。
- 内容：为全部 22 组字段记录逻辑 Module、公开/条件/私密视图和快照规则；跨事实对象（F21）按事实拆分所有者。
- 保留的未决边界：F04 附件可见性；F22 主帖规则唯一 Module；F11 具体页面读者；E03 保存/删除期限；物理模型及 TX01–TX12 真实读写/并发/恢复证据。
- 适用影响：未决边界只限制相应功能的物理设计/启用；本映射不等于这些功能通过验收，也不阻断已有依据可完成的其它 SP08 数据合同工作。

幂等决策实现位于 `packages/shared/src/contracts/idempotency.ts` 并从共享入口导出。它只接收调用层已得出的载荷比较结果；同载荷时保留原 `CommandResult`（包括处理中/未知），不会自动发起新副作用。新信封解析器只负责结构收窄，不能独立放行命令；执行端仍须按拥有该操作的服务端模块完成其余验证。共享层无平台 API、DOM、云 SDK 或新运行依赖；自有代码保持 `strict` 且不使用 `any`。

本轮 F09 字段校验实现位于 `packages/shared/src/contracts/private-address-book.ts`。其唯一业务限制来源是 [PRD F09](prd.md) 明文“联系电话11位数字”。11 位数字用 ASCII `0`–`9` 表示并拒绝空白/分隔符，是本项目代码层对电话号码输入的字符编码表达；它不增加号码段判断。F09 其余字段虽有长度范围，但长度单位及计数语义尚未确认，因此没有在本次实现中自行选定 UTF-16、码点或可见字符计数。
