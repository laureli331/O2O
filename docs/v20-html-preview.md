## 参考及适配

查阅[Carbon表格规范](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)，借鉴工具栏统一筛选/搜索、表格排序分页及行级操作；本项目只在工作台作结论，队列不批量通过。查阅[Stripe争议参考](https://docs.stripe.com/api/disputes)和[YouTube审核说明](https://support.google.com/transparencyreport/answer/9209072)，参考事项、材料、状态与人工复核分开表达的方式；不套用外部平台的期限、处罚或支付业务，也不声称体验过它们的最新内部后台。

本轮采用 [GOV.UK Task list](https://design-system.service.gov.uk/components/task-list/) 的任务名称与状态表达、[Check answers](https://design-system.service.gov.uk/patterns/check-answers/) 的提交前核对原则；首图、评价摘要、待办动作与评价优先顺序是本项目适配。前述表格参考仅保留研究过程，本轮不使用密集表格。

沿用V15/V16的绿白配色与侧栏。默认“待我处理”，另有“等用户补充/已处理/全部”；卡片展示首图、标题、评价摘要、需要做什么、时限和入口。详情先评价与材料、后处理选项，初次提交不显示空的旧版对比，修改评价才对照。编号、版本、检测及日志收在“更多信息与处理记录”；确认层先呈现结论、影响和理由，编号与版本可展开核对。1280/1440/1920px双栏，窄屏单栏；标题两行截断，详情展示完整标题。此网页窄屏适配不等于小程序具备审核权限，小程序使用独立只读入口。

## 行为与边界

- 四类任务只有一个队列，默认待我处理，类型/状态/标题或编号搜索、从旧到新、每页10项；空筛选与无任务分开，模拟读取失败保留最近成功合成列表并标过期。
- 图文和回应只处理当前候选版本，图片共享预览；回应仅文字。实际理由1—1000字必填，确认层列出对象、版本、结论及公开影响。
- 图文拒绝不改变数值资格，修改待审/拒绝保留旧合法图文；检测通过/命中/失败/未知均不是人工结论。通知记录仅为“待发送（合成）”，不冒充实际送达。
- 首次回应、请求材料、最终结论分开记录。请求补充不重置原目标和首次回应；材料到达用明确的外层合成场景演示。
- 开放历史资格和申诉更正需引用有实际支持的合成材料；缺乏材料可以记录无法认定，不默认开放资格。低分、同IP/住址、付费身份不构成单独失效依据。
- 申诉围绕原结论同一对象，展示新的结论与影响；保存原结论、新复核阶段、材料引用、前后状态、共用管理账号及时间，不新增账号处罚或具体操作者身份。
- 并发更新后保留理由，要求读取当前版本并重新选结论。旧候选版本保留折叠历史，迟到结果不能覆盖新版本。
- 失败保留填写；结果未知时只查询原请求，刷新后可继续。原请求幂等，日志、通知和公开变更不重复；查询确认版本冲突时不覆盖新对象。
- 草稿在当前合成会话暂存。普通离开提示暂存，重置场景明确告知会清空合成填写；待确认请求未解决前不允许重置场景。
