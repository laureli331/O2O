# 前序页面任务式优化：V03/V05/V07/V14/V23

2026-10-24。用户要求按已满意的V15、V21标准继续优化前面的页面。本轮处理既有审查U05—U09，保留业务规则、原接口、视觉风格与页面合同，不涉及真实提交或生产权限。

## 具体方案

- V03申请者的跑腿服务费保留在表单只读摘要，并由接受服务费的勾选承接；顶部任务摘要去掉重复金额。发布者另一视角仍显示金额。维修/其它预估与跑腿固定金额分工不改。
- V05登录/资格总览去重复介绍，直接显示必要资料、当前状态、用途与同意。身份核验直接展示姓名/证件示意和用途同意；保留身份变更、年龄限制、未知查询、来源返回与不自动提交规则。
- V07当前服务的常用操作区，只有存在当前未解决交付异议时才显示异议解除；模型校验、申请/回应及19个评审合同仍保留。
- V14处理记录按待补充、处理中、已有结论、全部切换，当前只渲染一份本人记录清单。默认优先待补充，否则展示当前有记录的分类；每一分类含真实数量。待核实提交保留独立查询卡；原记录、申诉、补充及回执不删，返回保留筛选与位置。
- V23作品详情只保留顶部商家身份/公开资料入口，沿用其粘性定位；底部同功能入口删除。长正文仍可从顶部固定入口打开商家资料，收藏/分享/返回与授权规则不改。

## 参考及适配

[NN/g渐进披露](https://www.nngroup.com/articles/progressive-disclosure/)说明重要内容先呈现，次要内容按需查看；[GOV.UK内容切换](https://design-system.service.gov.uk/components/tabs/)说明相关内容一次呈现一组。这里使用现有项目按钮样式及移动端触控尺寸，V14采用带数量的筛选按钮组，不照搬桌面标签或擅自删除数据。资料收集用途、同意、异常与提交反馈始终保留。

## 验证方案

修改前确认当前页面与规则的对应关系；修改后验证费用仅同一视角去重、登录/电话/身份分别同意及核验未知恢复、异议发起/解除后入口显隐、V14每份清单唯一和筛选计数/失败未知/申诉补充完整路径、V23短长正文均可访问唯一商家资料入口。检查320/375/414px与桌面、长内容、按钮触达、焦点与返回位置。同步ASCII/规划记录，运行相关与全量测试、浏览器回归、14项文档检查与交接验证，通过后提交Git。
