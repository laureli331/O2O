# V08 联系申请 HTML 预览

入口：[打开 V08](http://127.0.0.1:8765/v08.html)。页面文件为 `previews/v08.html`，状态模型为 `previews/assets/v08-model.js`。

当前范围沿用已确认规则，以闲置物品联系申请为主。维修/跑腿人员目录不恢复；合法历史不清除。合成数据中的“已失效历史”只用于演示该状态，不表示目录撤销时所有历史授权自动失效。

## 页面与入口

- V08-A：我发起的、我收到的、授权与历史；状态筛选、首图、头像、物品价格、当前进展。仅显示本人相关记录。
- V08-B：申请详情、独立行的打码电话与微信、可折叠记录、按当前状态开放的固定底部操作。
- “我的”联系申请直达 V08，未登录先进入登录页；首页闲置物品的联系申请入口进入对应物品。维修、跑腿等原申请演示不变。
- 获准后买家进入 V07-D 提时间，卖家进入 V07-E 约定明确金额；复用 V07-F 的交易确认。进行中或有有效异议的交易进入 V07-G。返回保留分栏、筛选、记录及列表滚动位置。

## 交互与边界

同意、拒绝、撤回、撤销和发起申请均有确认弹窗，取消不改变记录。每人每物品最多一份待处理申请；拒绝、撤回、撤销后24小时可明确重新申请，不自动重申。同意仅限当前申请，不开放完整联系方式。正式交易与有效异议不能通过此页单方撤销联系。

待核对状态仅允许查询本次结果，避免重复提交；重复查询不会重复变更记录。陈旧状态不能覆盖较新的记录。未知结果、权限限制及所有状态校验只是本地状态模型的演示，不能代替服务端权限、安全或一致性控制。

页面顶部可切换正常、未登录、空态、加载中、失败保留记录、结果待核对、物品关闭及24小时后。刷新恢复初始合成记录，跨页面为独立演示，不共享真实授权、时间提案或订单状态。交易页人物及时间仍为该页独立示例，不代表真实对象已被授权。
