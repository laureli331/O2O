## 演示边界

分类与村社区没有冒充真实配置，全部明确标为演示；任务类型来自已批准清单。已有值、地址簿、旧帖均为合成。草稿只在本页内存保存；恢复不调用AI，模板/再发布清空私密地址、领取码、费用及未来时间，不继承旧权限。正式产品仍需云端草稿及服务端资格/内容安全/权限校验。

图片选择仅创建本机临时预览，支持删除，限制 JPEG/PNG、每张≤5MB、总数≤9；私密图不进入公开核对区域。真实发布前仍需服务端内容安全和元数据处理。

AI只演示固定合成样例，未接入模型，不宣称可处理任意文字或识别全部隐私；未知文字提示手填。输入先经演示级敏感提示，不读取专用私密字段、历史或图片；无自动重试/采用/发布。明确采用后仍需另行核对与确认发布。时间按 Asia/Shanghai 解释；本地720小时校验仅作合同演示，正式交易以服务端当前时刻重验。

验证方案：Node 合同测试覆盖字段、金额/字符/时间边界、复制隔离、离线与九页完整性；Edge 浏览器验证四类、草稿、地址/图片、核对、编辑影响、失败/未知、AI隐私/失败/多需求/冲突/过时、320/375像素布局与减少动画。截图存于本地忽略目录 `.local/v04-verification/`。

验证结果：全部 Node 合同/文档/资源测试、14 项相关 PowerShell 检查及 Edge 交互验证通过。桌面、四类表单、F/G/H/I 和窄屏截图已生成。此结论仅适用于本地 HTML，不代表微信真机或生产服务验收。

本轮审阅：导航复用 V01 的同组 SVG 线性图标，维修/其它也提供 AI 文字整理与合成样例；维修/其它时间仍手填。缺失项按短句逐行列全，状态采用简短说明和明确下一步。
