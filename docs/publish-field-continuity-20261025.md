# 发布表单的小交互不中断填写

2026-10-25。沿用已确认的焦点与阅读位置连续性，完善V04任务、地址和图片操作。

## 实际问题与处理

- 已复现：切换跑腿任务类型会重建条件表单，焦点离开任务控件。现在重绘后恢复该控件焦点与表单内/页面外的阅读位置，继续填写，不改任务字段、必填或隐私规则。
- 打开地址选择时记录原类别、字段及内外位置，焦点进入首个地址选项。选择后或点顶部返回取消，回到原地址入口和原阅读位置；取消不改地址，选择只填原字段。若条件变化令原入口不存在，焦点回到任务类型。切业务或进入其它流程不沿用旧地址返回位置。
- 添加图片后聚焦“添加图片”；移除后聚焦同位置的下一张，末项则前一张，没有图片时回到添加入口。重绘保留当前阅读位置，内容变短时按浏览器可滚动范围自然收敛，不刻意制造空白。
- 添加入口可用Tab聚焦、Enter或空格打开原生选图，补齐可见焦点；取消选图不新增图片。沿用0—9张、JPEG/PNG、单张5MB、本地预览及公开/私密用途约束，不新增上传能力。
- 地址、图片、AI等修改仍需重新核对与明确发布，未知结果保护、替换保护保持不变。本轮不增加页面、确认步骤、持久化或自动保存。

## 参考与适配

[W3C焦点顺序说明](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html)强调合理、可理解的焦点顺序。本项目将规则适配到条件表单重绘、地址往返与相邻图片操作，避免控件消失后焦点落空，不照搬外部视觉或新增业务流程。地址选择仍是原有左侧流程页，未将其宣称为模态弹窗。
