### R03 候选 iPhone 逐帧工具审查（未验收）

按用户选择，外拍/光学路径保持关闭，iPhone 逐帧证据缺口继续开放。GameBench Pro Desktop 经官方资料初筛后仅作为候选工具，尚未安装或验证；这不是源码复用或正式工程依赖，未把它加入项目依赖。用户明确表示没有 GameBench 账号，不要求用户注册或另建账号。该产品是商业测量工具，源码及开源许可未核实；官方发布记录显示仍在维护，但与本机目标设备的兼容性不能从版本公告推出。

- **Windows/iOS 兼容性有资料冲突。** 官方 v1.30.0 发布记录称支持 Windows 分析 iOS 17.4+；当前 iOS 17.4+ 无线设置指南给出 Windows Apple Devices 流程。但当前 Requirements 页面同时写明 iOS 17 分析需要 macOS 13.0+ 和最新 Xcode，并另要求 Windows 端使用 iTunes 与 Developer Disk Image。这个矛盾尚未由实际 iPhone XR（iOS 18.7.11）验证，不能假设 Windows 有线采样可用。
- **指标能力尚未满足合同。** 当前 v1.38.4 发布记录称 iOS 无线模式为每秒一次平均 FPS，而有线仍保留 frame time 和 jank；Dashboard 支持导出 timeline 数据，但官方页面没有说明导出格式或是否包含逐帧时间戳。短段识别、手势边界精度和合同所需逐帧>100ms归因都必须实际验证。
- **小程序归因未知。** 官方 FPS 文档明确提醒可能记录错误的屏幕元素，且截图与指标的时间关联约有1–2秒误差；没有证据表明它可以把微信 App 的画面指标单独归到内嵌小程序 WebView。即使能录到 WeChat 帧率，也不能直接当作小程序页帧率。
- **隐私与成本需在试用前核验。** 官方配置允许关闭截图和自动同步，入门文档显示会通过 Cloud 按钮上传会话；因此可先检查本地记录流程，但不得把“自动同步关闭”当成没有任何网络通信的证明。官方试用页显示28天试用含30分钟测试且无需信用卡；账号注册流程、试用后价格和服务端会收到的诊断数据尚未核实。
