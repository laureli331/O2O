# G01—G04 共用状态 ASCII 优化提案

范围：设计已获用户确认，现已完成四个独立预览网址 g01.html、g02.html、g03.html、g04.html；它们用于审阅共用状态，不给产品底栏新增“G系列”入口。现有V页面继续复用自己的业务状态、原请求和权限，后续按验证结果适配，不在本轮批量重写。

## 设计取舍

采用“原任务中的状态＋独立状态预览”：四个网址各按任务分组展示，演示切换控件放手机外，手机内每次只展示一个当前状态。没有选用把所有提示堆成说明页，也不为每个错误加中转页。主操作通常一个，次操作仅在任务需要时出现；保留上下文、说清结果和下一步。

## 参考与项目适配

- [Carbon空态](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states)：区分首次无数据与搜索无结果；本项目不采用示例数据填充真实空列表。
- [GOV.UK错误提示](https://design-system.service.gov.uk/components/error-message/)：输入问题就近提示并保留输入；本项目不把服务端异常归咎于用户填写。
- [GOV.UK服务异常](https://design-system.service.gov.uk/patterns/problem-with-the-service-pages/)：讲清当前问题、已有内容的实际保存情况和下一步；不照搬其保存期限、文案或政府页面视觉。
- [W3C模态弹窗](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：隔离背景、限制焦点、关闭后返回来源。手机仍提供可见按钮，不依赖鼠标悬停或键盘快捷键。

以上为公开规范查证与本项目建议，不声称体验过相关平台最新版。

## 共用边界

纸白/苔绿视觉、已确认SVG、44px触控沿用现有预览。胶囊独占安全区域；G页不新增底栏，原业务页的底栏由其既有归属决定。文字直白，不显示内部编号、版本号或“幂等”；主标题不在正文再抄一遍。输入、选择、图片和来源条件按本次实际状态保留，不承诺刷新或跨设备永久恢复。

空态只用真实无数据事实，弱网不伪装暂无内容；金额未知不填0。未核实成功不显示已提交/已付款/已退款；处理中与未知不新建重复请求。图片及分享沿用原字段限额与权限，不新增真实微信分享、服务器鉴权、支付或后台能力。

## 状态清单与闭环

每行是状态实例，不是新增产品页面或业务状态。G01—G04仍为四组。

| 编号 | 触发 | 用户看到什么 | 操作后去哪里 |
| --- | --- | --- | --- |
| G01-01 | 首次加载 | 接近原列表的骨架；确有需要才显示加载文字 | 加载完成回原内容；失败转首次失败 |
| G01-02 | 确实没有数据 | 还没有收藏的需求 | 去看看需求→V01原公开列表 |
| G01-03 | 筛选无匹配 | 没有符合条件的需求 | 调整筛选→原筛选区，保留当前条件 |
| G01-04 | 首次读取失败 | 暂时没加载出来 | 重新加载→原读取；不冒充空列表 |
| G01-05 | 已有内容更新失败 | 暂时没更新，先看看已有内容 | 重试→更新原列表；不清空已见内容 |
| G01-06 | 需要登录 | 登录后查看 | 去登录→V05现有流程，再回原任务，不自动提交 |
| G01-07 | 没有查看权限 | 暂时无法查看这项内容 | 返回来源；无本人依据不显示私密原因或申诉 |
| G01-08 | 对象失效/下架 | 这条需求暂时无法查看 | 返回列表；有权本人按既有记录查看处理进展 |
| G02-01 | 正在提交 | 正在提交… | 同一按钮等待，不重复触发 |
| G02-02 | 提交结果未知 | 还没查到提交结果 | 查询结果→原请求，不新建请求 |
| G02-03 | 查询后仍未知 | 结果还在确认中 | 保留查询入口；不显示失败或让用户再次付款 |
| G02-04 | 已证实成功 | 已按实际动作更新 | 原对象展示结果；确需进入详情才给查看入口 |
| G02-05 | 已证实未成功 | 本次没有提交成功 | 原请求可重试时重试，保留全部输入 |
| G02-06 | 原内容已变化 | 这项内容有更新，请重新核对 | 显示差异→按最新内容重新核对/返回修改 |
| G03-01 | 有权图片预览 | 当前图片与张数 | 关闭→原记录、原缩略图、原滚动位置 |
| G03-02 | 大图读取失败 | 图片暂时没加载出来 | 重试当前张；保留其它已加载图片 |
| G03-03 | 格式不符 | 请选择JPG或PNG图片 | 重新选择；合法已选图片不清空 |
| G03-04 | 单张超过5MB | 这张图片超过5MB，请换一张不超过5MB的。 | 更换这张；不影响其它输入 |
| G03-05 | 超过字段张数 | 本处最多添加<字段实际张数>张图片 | 拒绝超出的图片；已有合法图片保留 |
| G03-06 | 公开分享卡片 | 公开标题＋首张公开图/统一分类图 | 有真实微信能力才调用；接收方重新鉴权 |
| G04-01 | 放弃未保存修改 | 要放弃这次修改吗？ | 继续编辑/放弃修改；草稿按原表单显式动作 |
| G04-02 | 删除已允许删除的对象 | 删除这个地址？ | 保留地址/删除地址；成功后才移除 |
| G04-03 | 原业务需重要核对 | 具体动作、具体对象、具体影响 | 一次核对沿用原规则；未知先查询 |
| G04-04 | 普通反馈 | 已按真实结果完成对应动作 | 轻反馈；关键信息保留在原对象 |

## 主要 ASCII

### G01 读取与空态

```text
+------------------------------------------------------+
| < 返回                  我的收藏                     |
| 需求                         作品                    |
| <接近卡片布局的骨架>                                 |
| <读取结束后展示实际内容>                             |
+------------------------------------------------------+
```

```text
+------------------------------------------------------+
| < 返回                  我的收藏                     |
| 需求                         作品                    |
| 没有符合条件的需求                                   |
| [调整筛选]                                           |
+------------------------------------------------------+
```

```text
+------------------------------------------------------+
| < 返回                  我的收藏                     |
| 暂时没更新，先看看已有内容     [重试]                |
| [首图] <原列表内容继续显示>                          |
| <不清空筛选或阅读位置>                               |
+------------------------------------------------------+
```

### G02 提交与重新核对

```text
+------------------------------------------------------+
| <原表单与已填内容>                                   |
| [正在提交…]                                          |
| <不可重复提交；不提前显示成功>                       |
+------------------------------------------------------+
```

```text
+------------------------------------------------------+
| <原表单与已填内容>                                   |
| 还没查到提交结果                                     |
| 请先查询，避免重复提交                               |
| [查询结果]                                           |
+------------------------------------------------------+
```

```text
+------------------------------------------------------+
| 这项内容有更新，请重新核对                           |
| 期望时间     <原时间> → <最新时间>                  |
| <只显示本次确实变化且有权读取的字段>                 |
| [按最新内容重新核对]  [返回修改]                     |
+------------------------------------------------------+
```

### G03 图片与分享

```text
+------------------------------------------------------+
| [关闭]                         1 / 3                 |
| <本人当前有权查看的大图>                             |
| <点第2张进入第2张；关闭回原缩略图>                   |
+------------------------------------------------------+
```

```text
+------------------------------------------------------+
| 说说这次感受                                         |
| <原输入不变>                                         |
| [原合法图片] [添加图片]                              |
| 这张图片超过5MB，请换一张不超过5MB的。               |
+------------------------------------------------------+
```

```text
+------------------------------------------------------+
| 分享给朋友                                           |
| [公开首图] <公开标题>                                |
| <缺公开图：使用原统一分类图>                         |
| [分享给朋友]                                         |
| <HTML只演示，不伪造微信分享成功>                     |
+------------------------------------------------------+
```

### G04 确认与反馈

```text
+------------------------------------------------------+
| 要放弃这次修改吗？                                   |
| 未保存的修改将丢失。                                 |
| [继续编辑]                  [放弃修改]               |
+------------------------------------------------------+
```

```text
+------------------------------------------------------+
| 删除这个地址？                                       |
| <原地址的必要摘要>                                   |
| <仅按现有地址删除规则说明影响>                       |
| [保留地址]                  [删除地址]               |
+------------------------------------------------------+
```

```text
+------------------------------------------------------+
| <原处理对象与当前实际结果>                           |
| 已完成对应动作                                       |
| <轻反馈；必要结果仍可在原记录查看>                   |
+------------------------------------------------------+
```

## 实现与验证约束

- G01：分别验收首次加载、确实空、无匹配、首次失败、刷新失败、未登录、无权、失效/下架；空态不可用其它用户记录补齐。有权本人的历史/申诉仅在现有规则允许时出现。
- G02：同一原请求提交、超时、查询仍未知、成功、明确失败、内容变化均可演示。未知状态没有“再次提交/再次付款”捷径；差异不自动采纳，核对前保留输入。
- G03：从原张打开、缩放/切换、关闭返程、当前张失败重试；JPEG/PNG、5MB及字段张数分别校验，错误保留合法内容。公开发布0—9、商家主帖1—9、评价0—3、每费用项目凭据0—3，其它按现有字段。原证件、地址、联系、领取码、未审原图、定位元数据不可分享，接收方重新鉴权。
- G04：无修改不弹退出确认；有修改先明确影响，继续编辑不丢输入，放弃后才离开。遮罩/Escape/返回键均不执行破坏动作，长内容可滚动，关闭焦点回来源。已有原业务确认不重复叠层；不新增自动保存、永久恢复、退款或账号处罚规则。
- 所有组覆盖320/375/414px；有需要的运营弹层另验桌面。检查大字、长文、软键盘下操作可达、胶囊和安全区、非颜色反馈、44px目标、键盘焦点与减少动态效果。真实小程序/弱网/权限仍须接入后验收，不以合成演示冒充。
- 设计检查先验24个状态实例、4个主组、原23组/116页图及82验收映射、Markdown链接与ASCII边框；设计审阅通过后已实现HTML及对应浏览器测试。当前不修改已有业务HTML。
