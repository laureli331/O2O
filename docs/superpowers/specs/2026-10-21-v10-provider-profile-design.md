# V10 接单资料恢复与认证衔接

用户确认完整恢复接单资料、时段与忙碌，不恢复人员目录；发布者可从申请卡查看公开资料。固定入口位于 V05“我的收藏”下方，为独立整行“我的接单资料”。这覆盖先前对服务资料管理一并取消的范围，人员目录、找人、目录联系、目录经历评价继续取消，合法历史不清除。

V10-A 管理概览和资格入口；V10-B 申请人公开资料；V10-C 本人编辑；V10-D 时段与忙碌。资料沿用原已确认维修/跑腿类别和字段规则：名称1—30、服务介绍1—500、至少一个已配置社区、展示图片0—9、微信号选填≤50、营业执照选填1张。时段选填，同日重叠合并，忙碌默认否，仅作提示，不自动拒单/取消或限制并发。未填写选填资料不成为额外接单门禁。

资格核验复用 V05，登录、手机号、身份、年龄及身份变更状态分别检查。新申请缺资格时保留当前业务与表单，进入核验，再由用户明确继续返回原申请；不自动提交。已有申请的撤回、修改与已有交易处理不因资料未填而丢失入口。首页申请入口接通 V03。

公开查看只包含服务介绍、区域、公开图片、时段、忙碌、限定核验状态和执照提交状态。电话/微信到对应订单按原权限查看，执照原图及证件信息不公开。无陌生人目录、搜索或新目录联系入口；当前本地模型仅模拟当前申请人名单，正式访问必须由服务端检查发布者和申请关系。

布局参考 Vant 官方 [Cell](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/cell/README.zh-CN.md) 的分组管理与状态行，以及 [Uploader](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/uploader/README.zh-CN.md) 的本地选择、预览和数量限制。依据公开文档，不声称体验最新版应用。沿用现有绿白风格、居中空态、固定主要操作、44px热区及确认弹窗。

验证方案：模型验证资格组合、资料字段边界、上传限制、时段合并/非法时间原子拒绝、公开投影隔离、临时状态过期与单次恢复。浏览器验证收藏下入口顺序、四页编辑/预览/图片/时段、取消不丢输入、申请人只读、认证回跳保留输入不自动提交、有效资格复用、未满16/待核验不能继续、320/375/414px布局与触控/遮挡/键盘/减少动画。回归 V01/V02、V03、V05 和全量 Node及文档校验后提交 Git。

所有资料与核验均为本地合成预览。图片不上传、不写临时跨页存储；资格交接只保留合成状态，30分钟有效，不包含原始姓名/证件，不能代替服务端鉴权或真实核验。资料刷新重置；申请详情与资料仍为独立合成记录，不宣称已接入真实数据。
