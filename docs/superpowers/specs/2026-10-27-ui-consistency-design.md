# UI 一致性规范与实施边界（候选稿）

日期：2026-10-27。状态：待用户审阅具体数值；尚未修改产品 HTML/CSS。

已确认采用“先定规范 → 代表页验收 → 批量统一”的工作方式。本稿将数值建议与现状测量分开记录，不能作为已经验收的最终视觉稿。对应正式开发计划 SP05 的视觉交付，不代表任何开发任务已完成。

## 1. 验证方案

先校验本规范、候选数据与页面清单一致，检查本地引用有效，并运行项目已有测试。具体数值确认后，仅调整 services.html、v24.html、v15.html 三个代表页，提交前比较改前改后截图。手机按 320、375、414px，后台按 1280、1440px 验证；每页覆盖初始、长内容、弹层和相关失败状态。验收再扩展到全部有效页面。

逐页检查：无横向溢出；长标题、长按钮可换行；底部操作、输入键盘和安全区互不遮挡；触控区至少44×44；焦点清晰；按压反馈及减少动态设置有效；返回路径、失败重试、输入保留和未知结果查询不退化。不能用“声明了变量”代替实际计算样式与交互检查。

## 3. 参考及适配

- [Ant Design 主题定制](https://ant.design/docs/react/customize-theme/)：借鉴基础变量与组件变量分层，避免逐页修改数值；不引入其框架或默认外观。
- [Ant Design 布局](https://ant.design/docs/spec/layout/)：借鉴稳定的间距节奏及弹性布局。下文4px细分尺度是本项目建议，不冒称官方要求。
- [W3C 目标尺寸增强标准](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)：44×44 CSS像素属于增强级AAA规则。本项目继续采用44px触控下限；小图标的视觉尺寸不必跟着放大，不宣称据此已通过完整无障碍认证。

参考提供组织方法，具体数值取舍依据本项目已认可的服务页与V15；它们不是其它平台最新版应用的体验证明。

## 4. 密度选择

| 方案 | 手机页边距／卡内边距／卡间距 | 适用及代价 |
| --- | --- | --- |
| 紧凑 | 12／12／8px | 信息更多，长文及多按钮容易拥挤 |
| 均衡（推荐） | 16／16／12px | 便于阅读和点击，同时控制空旷感 |
| 宽松 | 20／20／16px | 留白明显，小屏可见内容更少 |

推荐均衡方案。后台仍保留24px页面留白与更宽的信息区，不机械套用手机密度。

## 5. 具体候选规范

所有数值单位为CSS px；候选值保存在[结构化规范](2026-10-27-ui-consistency-design-tokens.json)。不得在未确认时自动全局生效。

| 组件 | 推荐圆角 |
| --- | --- |
| 小标签 | 4 |
| 按钮、输入框 | 8 |
| 普通内容卡片 | 12 |
| 居中弹窗 | 16 |
| 底部抽屉顶部两角 | 20 |

统一间距尺度：4、8、12、16、20、24、32。手机页边距16、卡片内边距16、卡间距12、模块间距24、表单字段间距16；后台页边距24、普通卡内边距20、卡间距16、模块间距24。各层级选定后按语义复用，不能只因同一数值相近就全局替换。

主按钮最小高度46，支持长内容自然撑高；图标操作触控区至少44×44。手机正文14、卡片标题16、导航标题18、辅助信息12；后台正文14、卡片标题16、页标题20。正文建议行高1.6，标题1.4。金额、首页品牌标题和已有宣传主标题保留独立角色，不按普通字号强制替换。中文沿用系统字体。

本轮保留现有绿／米白视觉与语义颜色，不同时开启配色重设计。字体大小统一也须检查辅助信息对比度，不能为了弱化层级而变得看不清。

## 6. 必须保留的合理差异

- 头像保持圆形；胶囊保持胶囊；预览手机外框不是产品卡片，不改成12px。
- 图文卡封面贴边，文字区单独16px内边距；不能给封面再加一圈留白。
- 发现页抽屉与消息入口已确认的轻量组合外形、16px图标及44px触控范围保留。
- 底栏选中态继续用原SVG轮廓填绿，不改图形；头像居中、瀑布流和发布独立页保留。
- 小程序胶囊避让、安全区、全屏发布无TabBar、已确认的隐私展示规则保持。
- 业务内容顺序、关键文案、按钮含义、收费与退款规则不属于此次视觉统一范围。
- 有效页统一规范；独立改版、旧归档及其隔离测试基线不修改。

## 7. 实施方式与回退

采用“基础变量 → 手机／后台密度 → 组件角色 → 明确例外”四层规则，避免无作用域的button或.panel覆盖整个预览器。先识别.phone与.device及演示控制区域，控制台不能混入产品组件统计。

第一批只做服务列表／详情／通知、V24表单与付费确认、V15任务列表与处理区。每页列出组件映射，记录改前截图和提交版本。用户查看代表页后，再逐批覆盖其余有效页；不把33页一次改完后才验收。共享文件变更按既有规则更新引用版本并检查所有使用方。

每批完成相关交互测试、计算样式检查及既有回归测试后单独Git提交。回退以批次提交为单位，不混入其它未提交改动。发现问题先回退本批，不重新下载或覆盖历史素材。
