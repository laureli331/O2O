# V11首页场景预览

用户明确要求广告预览呈现首页效果，允许用骨架屏。沿用现有V01首页：搜索在上、广告在中、分类和双列瀑布流在下，使用静态骨架代表非广告内容；真实广告首图及当前版本保持可见。该占位是场景示意，不是等待网络加载，不显示“加载中”或持续闪烁。

参考[Ant Design Skeleton](https://ant.design/components/skeleton/)的输入、图片和列表占位组合方式，按项目米白/浅绿适配，不引入组件依赖。本次仅调整V11-C，不改变价格、审核、付款、广告位置和表单保存规则。

首页周围结构参照V01；广告图沿用当前已实现20:11预览比例，宽度随手机画板，完整展示素材，避免预览裁掉文字。这不是新增正式上传规格。预览直接显示所选位置，三点指示和文字说明位置，不假装次位是首页默认首位。其他页面的素材大图仍保留原比例。

首页场景优先展示，广告详情折叠为“查看广告详情”，可点击真实广告图展开；详情沿用原字段及独立联系方式授权。静态骨架不进入键盘焦点；底部返回编辑与提交审核继续固定可达，返回保留原填写和首图。

验证：先检查预览场景的搜索→真实首图→分类→双列卡片顺序、实际首图来源、授权字段与折叠详情；再运行浏览器320/375/414px无溢出、横幅完整显示、首图点击/键盘展开、返回保留输入、当前/下期版本与提交流程；最后运行全量测试、检查资源版本并提交Git。
