# 全页体验优化与ASCII同步

日期：2026-10-21。用户授权：“根据已经更新了的agents.md，思考一下对ASCII和html要有哪些优化，这次直接做”。沿用已认可的服务页设计方法与绿色视觉，不变更已确认业务规则，不新增真实接口或收费能力。

## 查证依据与项目适配

- [Vant Form](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/form/README.zh-CN.md)：字段拥有各自校验规则与错误信息。本项目复用发布校验模型，增加字段定位、字段旁提示和修正后的即时清理，不再要求用户看完顶部错误后自行找字段。
- [Vant Empty](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/empty/README.zh-CN.md)：空态说明与下一步操作放在一起。本项目补充草稿空态的轻量插画、简洁说明及填写入口，不用虚假记录填空。
- [W3C触控目标说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)：小目标与间距影响操作。项目继续采用自身44px目标，补充次数保留48px；这是项目适配值，不把44px说成该AA条款的统一要求。轮播视觉圆点保持小尺寸，实际按钮扩大。
- [W3C焦点可见性](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)：固定内容不能完全遮住当前焦点。本项目增加滚动留白、字段定位及安全区留白，并验证固定操作区与窄屏。
- 延用[服务页已确认参考与布局](2026-10-21-service-pages-refinement-design.md)：信息按重要性分层，主要动作固定、次要动作分组，通知已读操作放标题下方。

## 本次实施

1. 七份现有HTML加载同一份本地移动端基础样式；返回、筛选、文字入口与图标入口至少44px，主/次按钮至少46px，AI补充次数保留48px。小图标本身不强制放大。辅助说明、候选卡片与评价入口提高可读性。
2. V02窄屏公开详情将标题、价格分行，标题优先；未知金额使用说明字号。跑腿公开状态由遗留的“等待报价”更正为“等待接单”，与发布者定价规则一致。
3. V03候选头像、昵称、说明及评价入口保持清晰层级；移除手机内容区中描述左右演示画板的文字。本人可见权限规则仍由原模型和文档维护。
4. V04保留校验规则与旧消息接口，新增结构化字段错误。错误摘要每项可以直达字段，字段旁显示具体原因，修正后即时清理；草稿空态给出“去填写需求”，去掉依赖桌面“右侧表单”的说明。
5. V05保留居中资料、交易金额同排、卡包四项同排及已有支付方式顺序；统一点击区域，去掉依赖桌面“左侧”的入口描述。
6. V23发现详情轮播按44px点击区域切换，视觉仍为小圆点；商家审核状态展示审核结果、当前是否展示和可继续的操作，不展示“版本1/2、原子替换”等内部术语。版本、审核和替换模型保留。
7. 商家通知演示与服务通知使用相同的标题下固定工具栏、全部/未读筛选及全部已读。已读不删除记录，单条点击记录为已读，不恢复旧权限；不使用右上角胶囊区域放入口。
8. ASCII覆盖V01—V23与G01—G04的体验约束，展开原V23英文占位示意，校正通知入口和底栏、价格层级、表单定位与技术术语。已撤销目录与延后模块保留历史属性，不因补图启用功能。
