# 时分菜单、首页Banner点击与独立发布流程

用户明确指出时分仍弹出浏览器长菜单、首页Banner不可点击，并要求底栏发布进入独立全屏页面、隐藏TabBar、顶部返回/关闭。

## 已有规则与本轮范围

1. 保留已确认底部整月日历；时分改为弹层内的两个滚动列表，点击/滑动/键盘均可选择，选中行绿色标记，不使用原生select弹出菜单。保留最早时间、取消和确认语义。参考[Vant TimePicker官方说明](https://github.com/youzan/vant/blob/main/packages/vant/src/time-picker/README.zh-CN.md)的小时/分钟分列和范围约束，不引入Vue依赖。
2. 按已有2026-10-17确认，首页当前招商占位图点击进入独立广告合作说明，列明已确认九档位置价、可选99元制作及先制作/审核/系统复核档期再付广告费的顺序；不伪装真实售卖或把本人未发布草稿公开。公益图及付费广告的既有不同点击规则不改。V11内嵌预览仍直接查看本人素材详情。
3. 底栏“发布”跳到`v04.html?mode=publish`独立页面，单次只呈现选择、表单或辅助流程之一，全屏展示，不显示TabBar。选择页顶部返回/关闭可回来源；表单返回选择、关闭退出。未保存修改先询问，结果未知先核对；保留既有草稿/表单/AI/审核规则。`v04.html`默认即独立发布，`v04.html?mode=review`保留双栏评审入口，也隐藏原发布页底栏，避免暗示发布是可常驻切换的Tab。
4. 来源路由白名单，仅站内已存在的页面；优先浏览器返回，必要时回到已记录来源，恢复页面/内部滚动位置，不接受任意外链跳转。不新增真实发布或云端存储。

## 验证方案

- 日历内没有时分原生select；测试点击、滚动停靠、键盘选择、最早时分、取消、确认、短屏完整显示。
- 首页招商图鼠标/键盘进入说明，返回保留阅读位置；说明展示九档已确认价格，无虚构客服电话/真实下单。
- 从首页、发现、服务、我的底栏进入独立发布；验证全屏单画板、无TabBar、选择到表单/AI/核对/地址的往返，保存入口、未保存退出确认、来源返回和未知结果保护。
- 原V04双栏评审、原首页、Banner制作与日期上传回归；320/375/414px和短屏、所有相关资源哈希、全量Node测试及Git提交。

### 商家发布兼容
发现页现有商家身份的发布按钮进入独立全屏商家主帖编辑页，沿用商家审核资格、图片、正文、主题、预览与提交逻辑；普通居民进入四类发布选择。两者均隐藏底栏，顶部返回与关闭，未提交修改退出前确认。身份参数仅控制合成预览，不构成真实授权。

### 验证记录
覆盖320／375／414px独立页面、来源返回及滚动恢复、未提交退出保护、商家编辑、居民AI／地址／预览返回、结果未知查询保护、首页合作说明与九档价格、时分滚动及键盘选择。原双栏核对入口显式使用 `?mode=review`，供原业务验证继续使用。

最终验证：1274 项自动测试全部通过；独立发布与时分选择、V04、首页、Banner 首页嵌入、日期与上传、服务、V23、V05、V09，以及发布字段连续性、待查询保护、替换保护和结果失效回归通过。`git diff --check` 通过。
