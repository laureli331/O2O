# V08 联系申请与权限记录 HTML

日期：2026-10-21。依据用户“给我v08”、现有V08-A/B及已确认移动端风格制作本地交互预览。

## 依据与范围

- 当前人员目录已撤销，优先采用[服务订单中心确认](../../service-order-center-confirmed-20261021.md)。V08的新操作仅覆盖闲置联系申请；旧服务资料仅以明确已失效的合成历史示例展示，不推断所有真实旧授权失效，不删除合法历史，不恢复目录入口。
- [PRD](../../prd.md)3.2、闲置交易规则与[ASCII V08](../../ascii-design-prd-2.1.md)：本人申请、收到的申请、授权与历史；同一人同一对象最多一份待处理；按既有V08规则，拒绝/撤回/撤销后24小时才允许明确重申，不自动申请。获准联系仍打码，交易须按原流程明确确认。当前交易或有效争议联系不能从本页一般单方撤销。
- [Vant Cell](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/cell/README.zh-CN.md)：借鉴圆角分组、标题/辅助信息/状态分层、整行点击。采用首图、头像、对方和状态，避免多行规则占据卡片。
- [Vant Weapp Dialog](https://raw.githubusercontent.com/youzan/vant-weapp/dev/packages/dialog/README.md)：借鉴明确动作与取消的消息确认。拒绝、撤回及撤销在确认前说明24小时影响；不增加PRD未定的必填理由或申请说明字段。

## 页面与交互

单个手机画板，与服务页一致的绿色、米白色和44px触控区域。顶部三个分栏“我发起的 / 我收到的 / 授权与历史”，下方按状态筛选；标题与胶囊留位不重叠。图文申请卡一键进入完整详情，返回保留分栏、筛选及滚动位置。

详情依次展示状态与下一步、闲置首图/标题/金额、对方头像昵称、申请时间、逐行打码联系方式、同页时间记录。底部固定当前允许的主要动作：待处理申请发起人可撤回；物主可拒绝/同意；获准的物主可在无当前交易/争议限制时撤销。冷却后由请求人点击重新申请；过期对象和旧服务资料不可重申。

获准闲置关系可进入已有V07买家提时间/卖家发起确认预览；进行中/争议关系跳到对应订单，不重复实现交易规则。V08始终只提供打码资料，完整联系按V07当前交易权限显示。所有跨页仍是独立合成预览，不声称共享真实记录或持久化。

状态演示包含：正常、未登录、空态、读取失败保留内容、加载中、提交结果待核对、对象已关闭、24小时后。未知结果只提供查询，不重复执行；状态已变化时保留当前记录、展示最新状态。取消确认不改变记录；双击/同请求重复不重复改状态或写历史。

## 验证方案

1. 模型：本人过滤、同身份自申请禁止、每对象单一待处理、所有者和申请者动作权限、24小时边界及无自动申请、交易/争议不可撤销、已失效历史只读、状态并发校验、幂等和未知结果查询。
2. 浏览器：三分栏与筛选、首图头像、整卡进入详情、同意/拒绝/撤回/撤销的确认及取消、冷却与明确重申、打码、空/错/游客/未知、V05及公开闲置入口、V07角色及返回。
3. 320/375/414px无横向溢出、固定底部不遮挡、弹窗键盘关闭/焦点恢复/焦点循环、减少动画、无浏览器错误；全量Node与相关文档检查后提交Git。

不接入真实联系人、消息、身份核验、交易或数据库；不提供聊天、陌生人搜索、批量同意、自动申请或真实授权修改。
