# V06 商家主页与订阅内容流设计

日期：2026-10-20  
状态：用户已确认设计，等待书面规格审阅  
适用范围：V06 / V23 离线预览中的发现页、订阅内容流和商家公开主页

## 1. 目标

将商家公开资料页调整为用户手绘稿确认的内容型商家主页，并在发现页顶部增加订阅内容流。页面继续使用项目已有的绿色、米白色视觉体系和双列帖子卡片，不复制其它应用的品牌色或图标。

本规格覆盖 2026-10-19《V06 内容流、发帖、详情与商家资料布局细化设计》中“不增加关注”和“不显示社交统计”的冲突条款。原规格的审核门禁、公开字段授权、合规帖子筛选、帖子详情、收藏失败回滚、分享限制、通知入口和底栏顺序继续有效。

本轮只修改 V06 离线预览、设计记录和验证，不修改小程序源码，不连接真实账号、发布、订阅、收藏或通知服务，不创建生产接口或数据库字段。

## 2. 发现页顶部结构

发现页顶部使用 `订阅 / 发现` 两个主入口：

- 每次点击底部“发现”，默认进入“发现”，不保存上一次主入口作为下次默认值。
- 从帖子详情或商家主页返回时，恢复进入前的“订阅”或“发现”位置；只有重新点击底部“发现”才重置为“发现”。
- “发现”继续展示原有 `最新 / 优惠 / 上新 / 活动` 主题栏和合规公开帖子。
- “订阅”只展示当前用户已订阅商家的审核通过且当前可展示帖子，并按审核通过后的发布时间倒序。
- 订阅不发送站内通知或微信提醒，也不改变帖子在发现页中的正常展示资格。

未登录用户仍能看到“订阅”入口；进入后显示“登录后查看订阅内容”和登录按钮，不使用空白内容冒充订阅结果。登录完成后可进入订阅流。

## 3. 商家主页结构

商家主页从上到下为：

1. 线条式 SVG `<` 返回按钮；
2. 商家头像与名称；
3. `帖子 / 订阅 / 收藏` 三项公开统计；
4. 一句话简介；
5. “查看详细信息”折叠入口；
6. 全宽“订阅 / 已订阅”按钮；
7. “作品”标题、单选筛选入口和双列作品流。

主页不显示公开审核标签。所有触控目标至少为 44×44 像素；按钮按下时保留轻微缩放反馈。内容为空、加载失败和减少动画设置继续沿用 V06 的现有处理原则。

## 4. 公开统计口径

- “帖子”只统计该商家当前审核通过且可公开展示的帖子；删除、下架或变为不可展示的帖子立即退出统计。
- “订阅”统计当前有效订阅关系；订阅成功加一，取消订阅成功减一，失败时不改变。
- “收藏”汇总该商家当前审核通过且可公开展示帖子的有效收藏。帖子退出公开范围或用户取消收藏后，相应数量同步减少。
- 三项数字都来自同一时点的有效记录，不使用虚构热度，也不把历史下架内容继续累计在公开数字中。

## 5. 详细信息折叠区

主页默认只显示一句话简介，不重复展示长篇商家介绍。点击“查看详细信息”后在原位置展开，不跳转页面、不打开底部弹层；入口改为“收起详细信息”，箭头旋转，作品区自然下移。

展开区按已填写且获准公开的数据依次显示：

- 服务项目；
- 服务方式，候选值为 `上门 / 到店 / 远程 / 配送`，只展示商家实际选择的一个或多个方式；
- 服务区域；
- 营业时间；
- 联系方式，包括电话和微信。

未填写的字段直接隐藏。电话和微信不需要再次点击，已登录与未登录用户也直接看到完整电话和微信，不打码；但只有商家明确授权公开的联系方式才可进入页面数据和界面。

## 6. 作品流与筛选

“作品”区继续使用与发现页一致的双列卡片。右侧筛选入口默认显示“最新”，下拉选项为 `最新 / 优惠 / 上新 / 活动`，使用单选：

- “最新”展示该商家全部当前合规公开帖子；
- “优惠”“上新”“活动”各自只展示明确选择对应主题的帖子；
- 选择后立即关闭菜单，入口文字同步为当前选项；
- 所有结果均按审核通过后的发布时间倒序；
- 筛选结果为空时显示真实空状态，不用其它商家帖子填充。

## 7. 订阅与取消订阅

未登录用户点击“订阅”时先进入登录引导；登录完成后才创建订阅关系。订阅成功后按钮变为“已订阅”，订阅数加一，该商家当前合规公开帖子进入用户的订阅流。订阅失败时恢复原状态并提示重试。

点击“已订阅”时弹出确认框，文案固定为：

```text
不再继续订阅？

[继续订阅]  [取消订阅]
```

- 点击“继续订阅”或关闭弹窗时，保留订阅关系和页面状态。
- 点击“取消订阅”后才执行取消；成功时按钮恢复“订阅”，订阅数减一，该商家帖子退出订阅流，并显示“已取消订阅”。
- 取消失败时继续显示“已订阅”，订阅数和订阅流不变，并提示“取消失败，请重试”。
- 取消订阅不删除用户此前收藏的帖子。

## 8. 状态与边界

- 已登录但没有订阅任何商家时，订阅页显示真实空状态和“去发现看看”入口。
- 已订阅商家暂时没有合规公开帖子时，不用其它商家内容填充。
- 帖子被删除、下架或变为不可展示后，从发现页、订阅页、商家主页和公开统计中同步移除。
- 加载失败时保留上一次成功内容并提供重试；失败不清空已有列表。
- 第一版不增加评论、点赞、私信、热榜、个性化推荐或订阅通知。
- 完整联系方式公开仅适用于商家明确授权的公开字段，不扩大其它私密资料权限。

## 9. 验证方案

1. 静态规格测试确认覆盖关系、订阅入口、主页结构、统计口径、详细信息字段、单选筛选和取消订阅确认文案完整。
2. 模型测试确认发现、订阅与商家作品流只返回审核通过且当前可展示的帖子，并验证统计随帖子、收藏和订阅状态变化。
3. 浏览器测试确认底部“发现”每次默认进入顶部“发现”，内部返回能恢复来源入口，未登录订阅页显示登录引导。
4. 浏览器测试确认详细信息展开和收起、完整授权联系方式、服务方式标签、筛选单选与真实空状态。
5. 浏览器测试确认订阅成功、取消确认框、继续订阅、取消成功和失败回滚。
6. 在 320、375、414 像素宽度检查无横向溢出，触控区域足够，展开内容、下拉菜单和确认框不被遮挡。
7. 运行完整 Node 测试、结构化文档验证、生成物一致性检查与 `git diff --check`。

## 10. 回退方式

规格、实施计划和 V06 实现分别使用独立 Git commit。若新商家主页或订阅内容流不适合，可按提交粒度回退到 2026-10-19 的商家公开资料页，同时不影响此前导航、审核、帖子详情和通知层级。
