# 商家主页统计 SVG 图标设计

日期：2026-10-20

## 目标

补齐商家主页统计信息所需的 SVG 图标资源，使“帖子、订阅、收藏”具备统一、可复用的线性图标。此次只更新 SVG 资源库，不修改 V06 或任何 HTML 页面，也不改变产品交互和业务逻辑。

## 已确认图标

- 帖子：新增内容卡片图标，使用圆角矩形和三行正文表达图文帖子。
- 订阅：新增铃铛图标，表达订阅商家内容更新。
- 收藏：复用现有星形 `icon-star`，不继续使用心形，也不重复新增同义资源。

## 资源范围

在 `assets/ui/development-handoff-20261009/icons/` 中新增：

- `icon-post.svg`
- `icon-post-green.svg`
- `icon-subscribe.svg`
- `icon-subscribe-green.svg`

同步更新 `assets/ui/development-handoff-20261009/icons.svg` 总览精灵图，加入 `icon-post` 和 `icon-subscribe`。已有 `icon-star` 保持不变，作为收藏图标使用。

## 视觉规范

- `viewBox="0 0 24 24"`
- 无填充的线性图标
- 线宽 `1.75`
- 圆角线帽与圆角连接
- 普通版使用现有深色资源规范
- 绿色版使用现有绿色资源规范
- 图标形状在 24×24 视口内保持清晰，不依赖文字标签才能区分

## 不在本次范围

- 不修改 `previews/v06.html` 或其他页面。
- 不把图标接入任何按钮、统计项或导航。
- 不修改收藏、订阅或帖子相关业务逻辑。
- 不新增心形收藏图标。
- 不改动已有 `icon-star` 的图形。

## 验证方案

1. 先更新测试，要求四个新增独立文件存在且满足统一 SVG 属性。
2. 验证总览精灵图包含唯一的 `icon-post` 和 `icon-subscribe` 符号及预览实例。
3. 验证新增独立文件与精灵图中的路径定义一致。
4. 验证现有 `icon-star.svg` 和 `icon-star-green.svg` 仍然存在且未被修改。
5. 运行图标资源相关测试和仓库现有相关验证，全部通过后再提交实现。

## 回退方式

实现将使用独立 Git commit。若需要回退，可整体撤销该实现提交，不影响既有星形图标或 HTML 页面。
