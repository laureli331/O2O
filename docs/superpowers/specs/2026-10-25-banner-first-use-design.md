# 广告首次进入与价格查看

用户已确认2026-10-25方案。范围仅V11—V13第二版合成预览，保留既有审核、原稿继续展示、独立下期、未知先查询和按秒退款保护。

## 实施顺序与验证方案

1. 模型增加empty状态、空白创作表单、订单准入判断；测试保存/提交前后状态，未完成不能付款。
2. 首次进入默认empty；无广告的居中空态与底部创建；常驻价格入口进入独立只读视图，返回恢复位置/焦点。
3. 仅保存或有效提交创建草稿/审核记录；新建和下期未保存内容独立于原记录。新建表单不预填合成广告，经营名称和区域可复用合成档案。草稿缺图时不冒充广告首图。
4. V12无订单显示空态，无金额、付款和退款；V13无广告显示空态，无统计。已有广告未开始保持原未开始状态，存在订单才提供查看入口。
5. 更新ASCII/PRD/交付说明，刷新资产内容版本，回归新用户浏览器链路、原三页已通过流程及窄屏/按压/固定栏布局，运行测试与文档检查后提交Git。

## 只读价格页

## 依据

[Ant Design空状态规范](https://ant.design/docs/spec/research-empty/)要求说明空状态并提供下一步；此次用已有视觉和移动端44px操作区域进行适配。关键布局和范围已由用户“可以”确认，不引入真实广告售卖或正式定价。
