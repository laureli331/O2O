# 发现页商家工具与通知入口

用户已确认：抽屉入口用三横线SVG，与铃铛同在左侧；两图标分别在44px点击区域居中，订阅/发现另起一行整组居中。顶部独立胶囊区域，入口不占胶囊位置。

## 本轮范围

- V23-A：已开通商家可用三横线打开左抽屉、铃铛进入商家通知；普通居民、未登录和待审商家不显示商家工具。沿用合成身份，不将审核通过等同真实开通。
- 抽屉：头像名称整体查看主页；订阅/收藏轻量同行；帖子管理、审核记录优先；经营推广为较小绿色入口，指向已有V11第二版预览，不启用真实售卖。底部固定客服、草稿、设置。内容独立滚动。设置直接打开已有V05设置页，不再增加中间说明页。
- V23-B：头像、单行商家名称、主页同行；删除细小重复说明。长名称省略，顶部预留胶囊区域。
- 服务页：用标题下的通知行替代绿色悬浮球；保留原通知ID、未读数、订单来源及返程逻辑，不新增商家抽屉。
- 抽屉关闭不重绘底层瀑布流；焦点归还来源按钮。遮罩、关闭按钮、Escape均可关闭，键盘焦点留在抽屉，背景不可操作。通知回到发现保留主题、订阅分栏、滚动；通知详情可返回原通知。
- 当前均为本地合成预览，沿用已有客服、资料设置和编辑示例；不接真实账号、支付、审核或消息服务。
