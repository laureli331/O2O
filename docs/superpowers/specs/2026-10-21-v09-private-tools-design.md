# V09 私人工具 HTML

日期：2026-10-21。按用户“给我v09”和既有 V09-A—D 制作，沿用已确认移动端风格，不引入新的人员目录。

## 范围与设计

四页使用一个手机画板，外部演示导航切换收藏、草稿、地址列表和编辑。收藏仅“需求／作品”两个标签栏，作品为商家发布。失效需求和作品保留原公开卡片图片与摘要，原列表项以蒙层和置灰禁用查看，不独立分类，仍可取消收藏；不读旧私密字段。取消收藏有确认。草稿与常用需求分栏，支持继续填写、删除确认、复制模板或本人旧帖到新表单；允许字段不全，只在明确保存时记录。

地址卡按联系人/电话、社区/详细地址、备注/默认标记分层；编辑 SVG 保留44px触控区，新增与保存固定在底部。编辑校验联系人1—20、11位数字电话、配置中的村社区、详细地址1—200、备注0—100，最多一个默认地址，不把号码格式当控制权验证。离开未保存编辑时确认。普通管理无选用操作；顶部演示开关进入任务选址模式，明确选用才生成独立任务快照，可通过随后修改/删除验证快照不变。

V05 当前收藏和地址入口直达对应 V09 页，保留最新个人页排布；草稿可从 V09 演示导航查看。有效收藏进入已有公开详情。草稿继续填写、模板/再次发布通过同源会话临时交接进入 V04，私密数据不放URL，不自动调用AI或发布；复制只允许公开内容，新对象不继承授权、旧费用/未来时间或私密字段。没有真实云保存、授权或持久化，刷新恢复合成数据，跨页临时交接仅用于本次明确操作。

参考 Vant 官方 [AddressList](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/address-list/README.zh-CN.md) 和 [AddressEdit](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/address-edit/README.zh-CN.md)，借鉴默认标记、独立编辑及底部保存，使用本项目真实规则而非省市区或定位默认方案。依据公开文档，不声称已体验最新版应用。

## 验证方案

模型覆盖本人权限、地址字段边界、唯一默认、显式保存、删除、快照独立、失效收藏只返回有限摘要、草稿允许不完整、复制去除私密及旧授权。浏览器覆盖四页与各入口、删除取消/确认、编辑错误定位与修正、未保存离开、选址模式与快照、空/错/加载/游客、V04交接及公开详情、320/375/414px、44px操作区、底部遮挡、弹窗键盘/焦点和减少动画。回归相关既有页面、全量Node及文档校验后提交Git。
