# V06 内容优先布局实施计划

日期：2026-10-19  
依据：[已确认规格](../specs/2026-10-19-discovery-feed-layout-refinement-design.md)，规格提交 `1177f8a`，主题归属澄清提交 `c6ebfbb`。

## 1. 交付目标

仅调整 V06 / V23 离线原型，使发现页、商家发帖页、帖子详情页和商家公开资料页统一采用图片与内容优先的布局：

- 发现页删除引导卡和固定“最新发布 / 演示加载失败”行。
- 增加 `最新 / 优惠 / 上新 / 活动` 主题栏并执行真实的本地筛选。
- 商家发帖页采用图片置顶、精简字段和固定操作区。
- 帖子详情页采用 A 版顶部商家栏、图片轮播和固定收藏/分享操作区。
- 商家公开资料页增加该商家的合规公开主帖双列列表。
- 所有面向普通用户的审核标签移除；商家自己的审核状态流程继续保留。

## 2. 边界与回退

- 不修改 V01—V05，不修改小程序源码，不创建生产接口或数据库字段。
- 不新增评论、点赞、关注、粉丝数、获赞数或推荐算法。
- 不新增优惠有效期、活动截止时间或自动失效业务规则。
- 不暂存或提交 `redbook` 中用户已有的删除记录。
- 所有文件使用 `apply_patch` 修改；先写失败测试，再实现并验证通过。
- 每个逻辑阶段独立提交；回退使用对应提交的反向提交，不执行破坏性重置。

## 3. 阶段一：主题模型与发现页

### 3.1 先写失败测试

修改：

- `tests/v06-preview.test.cjs`
- `scripts/verify-v06-preview.cjs`

测试合同：

- 三个当前公开合成帖子分别带 `优惠`、`上新`、`活动` 主题。
- `feed(posts, '最新')` 返回全部审核通过且当前可展示的商家帖子，并保持原排序。
- `feed(posts, topic)` 只返回明确选择该主题的合规帖子；未选择主题的测试对象只进入“最新”。
- 正常发现页不存在 `.hero`、`.feed-tools`、固定“最新发布”或公开 `.verified` 标签。
- 主题栏顺序严格为 `最新 / 优惠 / 上新 / 活动`，默认“最新”。
- 点击各主题后列表正确；主题空状态提供“查看最新”。

运行并确认旧实现因缺少主题模型和新布局而失败：

```powershell
node --test tests/v06-preview.test.cjs
```

### 3.2 实现模型与发现布局

修改：

- `previews/v06.html`

实现：

- 为合成帖子增加可选 `topic`，扩展 `feed` 的主题参数。
- 删除发现页引导卡与固定工具行。
- 新增 44 像素触控高度的主题栏、选中下划线、轻微按压缩放和减少动画兼容。
- 保留加载失败状态入口；正常发现页不显示演示按钮。
- 卡片只显示封面、标题、商家头像和名称。

验证并提交：

```powershell

git diff --check
```

提交信息：

```text

```

## 4. 阶段二：发帖、详情与商家资料

### 4.1 先写失败测试

继续修改：

- `tests/v06-preview.test.cjs`
- `scripts/verify-v06-preview.cjs`

测试合同：

- 发帖页图片选择与排序位于标题、正文之前；内容主题为可不选且最多一个的单选控件。
- 发帖页固定“保存草稿 / 预览”操作区不遮挡最后一个字段。
- 详情公开内容没有“已审核 / 资料已审核”，仍显示发布时间、正文、服务区域与商家入口。
- 详情底部固定“收藏 / 分享”操作区，原收藏失败回滚和公开字段分享合同不变。
- 商家公开资料页只列出与当前商家名称相同、审核通过且当前可展示的帖子。
- 商家资料卡片可进入帖子详情；无合规帖子时不填充其它商家内容。

### 4.2 实现四页统一结构

修改：

- `previews/v06.html`
- `docs/v06-html-preview.md`

实现：

- 商家编辑表单增加合成主题单选并在预览中保留选择结果。
- 将发帖主要操作移动到固定操作区，保留草稿、预览、校验和图片换封面能力。
- 重排详情页内容并固定收藏/分享操作区，删除公开审核标签。
- 重排商家资料头部，保留服务区域和授权公开边界；下方复用卡片组件展示同商家公开帖子。
- 不在商家自己的审核状态页面删除必要审核状态文字。

验证并提交：

```powershell

```

### 4.3 已确认的 A 版详情补充

继续按测试先行修改 `tests/v06-preview.test.cjs` 与 `scripts/verify-v06-preview.cjs`，确认旧实现因结构、文案和测试控件不符合新决定而失败，再修改 `previews/v06.html` 与 `docs/v06-html-preview.md`：

- 详情从上到下调整为 A 版顶部商家栏、图片轮播、标题、正文、发布时间与服务区域、商家公开资料入口。
- 顶部返回按钮使用线条式 SVG `<`，视口为 24×24，点击区域至少 44×44。
- 底部使用固定“收藏 / 分享”操作区，分享载荷仍只含获准公开字段。
- 删除空状态内部说明、详情隐私说明卡和收藏失败测试控件；收藏失败回滚继续由验证脚本在页面内部状态上覆盖。
- 不增加关注、评论、点赞、更多菜单或新的业务能力。

验证并以独立提交交付，确保可以单独回退本次详情补充。

## 5. 阶段三：真实浏览器验证

更新 `scripts/verify-v06-preview.cjs`，覆盖：

- 四个主题的切换、计数、默认态和空状态恢复。
