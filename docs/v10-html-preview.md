# V10 我的接单资料 HTML

[打开 V10](http://127.0.0.1:8765/v10.html)，或从 V05“我的收藏”下方点击“我的接单资料”。[范围确认](provider-profile-confirmed-20261021.md)覆盖原服务管理取消范围，服务页仍为订单中心，人员目录不恢复。

| 页面 | 内容 |
| --- | --- |
| V10-A | 本人资料概览、复用的资格入口、维修／跑腿资料、时段与忙碌管理。 |
| V10-B | 申请人只读资料，V03候选卡可进入；无资料时显示空态，不伪造技能。 |
| V10-C | 名称、技能介绍、配置区域、选填微信、展示图片0—9、选填营业执照1张。联系方式管理复用V05。 |
| V10-D | 每周时段、添加／移除、同日重叠合并、结束晚于开始、选填忙碌。 |

展示名称1—30字、服务介绍1—500字、至少一个已配置村社区，微信号最多50字。当前使用既有“演示社区”配置；图片只在浏览器本页选择和预览，JPEG/PNG每张不超过5MB，不上传、不存入跨页会话。执照原图只在本人编辑页预览，公开投影只提供提交状态，不因上传宣称已核查。时段/忙碌只是提示，不自动拒单、取消或限制并发；填写资料不是额外的接单准入审批。

认证仍使用V05现有独立授权流程。新申请缺少必要资格时，保留本次业务与申请输入，完成后明确继续回原需求，再由用户提交。有效资格复用，待核对不放行。临时交接仅使用30分钟合成资格状态和一次性申请表单，不保存原始姓名、身份证、执照图片；不能代替服务端鉴权、真实核验或交易资格校验。

顶部可体验待完善、已填写、游客、资格失效。资料刷新重置，候选人与资料为独立合成记录，真实发布者与申请关系、数据同步、云存储、核验调用、图片安全均未接入。没有人员目录、新目录联系、陌生人搜索或新的目录评价入口。

参考 Vant 官方[分组列表](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/cell/README.zh-CN.md)和[图片选择预览](https://raw.githubusercontent.com/youzan/vant/main/packages/vant/src/uploader/README.zh-CN.md)，适配现有绿色卡片、44px热区、固定主要操作与键盘确认；依据公开文档，不声称已体验最新版应用。

验证：`node --test tests/v10-preview.test.cjs`；浏览器 `scripts/verify-v10-preview.cjs` 依次传入URL、产物目录、Edge路径，并指定 `PREVIEW_PLAYWRIGHT_PATH`。覆盖资料字段、图片限制、执照隔离、时段合并、忙碌、未保存离开、申请查看、认证保留返回不自动提交、资格复用、年龄/未知限制、游客、320/375/414px、触控/遮挡/键盘/减少动画。证据位于 `.local/v10-verification/`，不提交合成截图。
