# 个人资料：核对与验证后接着编辑

2026-10-25。修复V05个人资料进入联系方式核对/手机号验证后的返回断点。保留既有资料保存、手机号单独授权、微信号变更另行确认及头像本页更新方式。

## 实际问题与处理

- 原联系方式变更核对页只有底部“返回修改”恢复输入，左上角返回却进入资格页。现在两者复用恢复逻辑，保留昵称、微信号、原阅读位置和合理焦点；返回不等于确认保存。
- 原从资料编辑去验证手机号后，取消或成功都回资格页，未保存文字随表单重绘丢失。现在记录当前子流程来源，提供“返回个人资料”；顶部返回、取消、缺少授权或失败后返回均恢复原填写，成功验证后直接接回原资料编辑。
- 手机号验证只更新本人手机号验证状态，不保存资料文字，不自动确认微信号变更。最终仍须点击保存资料；微信号改变继续经过原明确确认。正常资格入口与来自发布/接单的引导核验仍沿用原流程，不强制回个人资料。
- 来源与填写仅在当前子流程内临时保留，明确保存、离开子流程到其它页面或切换演示状态会清理，不新增云端草稿或刷新恢复。本轮仅修复这两条返回路径，不声明已实现整个V05的通用离开保护。
