# 接单资料：取消切换与刷新保护

2026-10-25。沿用已确认的资料编辑、类别独立及批量时段设计，补齐V10既有未保存离开保护，不新建中转页或保存机制。

## 问题与处理

- 编辑中切换演示状态后，原下拉框已先改值；取消时资料保留，但显示的状态与实际状态不一致。现在先恢复原选项，明确放弃修改后才应用所选演示状态。继续编辑、Esc或点遮罩不切换。
- 页内返回已有保护，但刷新和外部跳转未接入。现在复用当前编辑基线判断：资料或时段有实际改动时请求浏览器原生离开提醒，未改或改回原值不打断；不承诺浏览器一定拦截所有移动端关闭行为，不将提示等同保存或跨刷新恢复。
- 已在页内明确放弃后，更新离开基线再执行跳转或重置，避免紧接着再弹一次浏览器提醒。
- 保留现有确认层、默认“继续编辑”、Tab循环及关闭后焦点返回；类别切换、保存时段的一次核对和服务端核验边界不变。演示状态选择器是评审设施，不作为产品业务功能宣传。

## 参考与适配

[GOV.UK表单校验](https://design-system.service.gov.uk/patterns/validation/)建议保留填写，减少重复输入；[W3C模态对话框规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)说明初始焦点、Tab循环、Esc关闭及合理焦点返回。本项目沿用已有轻量确认层和44px按钮，不增加常驻警告或新业务步骤。参考为公开规范，不声称体验其它平台最新版。
