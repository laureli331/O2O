# 交易表单：离开前保护未提交内容

2026-10-25。延续已确认的输入保护方式，修复V07交易表单返回、切换角色/业务/演示状态及重置时丢失输入的问题。复用订单页现有底部弹层，不增加交易步骤。

## 行为与边界

- 对时间、闲置确认、费用、变更、延期、取消、异议、解除及恢复电话等现有表单记录初始值。有实际未提交改动时，离开前显示“继续填写／放弃填写”。初始默认值及改回原值不提醒。
- 原生文件选择、文字、金额、选项和复选框都纳入比较。继续填写、Esc或点遮罩保留当前DOM和本地图片，焦点返回触发入口；明确放弃才执行目标跳转或切换。切换控件在确认前仍显示原值。
- 成功提交按原流程进入结果/待回复，更新输入基线，不再弹离开提醒；买家时间明确提交后同样更新。校验失败保留输入和保护，放弃填写不等于提交、取消交易或新增异议。
- 外部离开/刷新请求浏览器原生提醒；明确放弃后不重复提醒。不增加自动草稿或刷新恢复，不承诺移动端关闭一定可拦截。权限、双方确认、交易到期、费用与异议规则不变。

## 参考与适配

[W3C模态对话框规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)要求合理初始焦点、Tab循环、Esc和关闭后的焦点返回。本项目复用已有底部操作面板，默认“继续填写”，仅在有实际改动时出现。依据公开规范适配，不照搬其它平台视觉，也不新增常驻提示。
