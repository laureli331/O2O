- [V12 订单与退款](http://127.0.0.1:8765/v12.html)：订单与付款结果、退款影响及预计金额、二次确认、终止后的退款进度。付款和退款待核实均提供查询，不把未知当失败或完成。

三页顶部有预览导航；不向居民个人中心添加商家广告入口，也不把第二版功能接入真实商家后台。演示状态、审核通过及结果控制均置于手机画板外，明确为演示操作，不伪装成商家可自行审批。

## 已确认规则的体现

- 首页三位置共用轮播，首图默认；首/次/末图299/249/199元每连续30天为候选价。非会员可单独购买；不自动续费、不保底曝光或成交。
- 先审核资格/素材并确认排期，再建立待付款订单与实际保留；演示保留24小时。付款结果未知不能再次付款，核实未付款后才允许重试；付款成功显示待开始，不冒充已经投放。
- 同主体重叠期最多一位；新期准备与当前期分开，下一期素材可以先准备，但是否有位、具体排期均需再确认，不承诺续购优先权。演示支持当前期与下期两个独立上下文，不模拟真实容量锁或并发交易。
- 修改先审后换，同期一份待审新稿，原合规版继续展示；新稿通过后才替换。撤回修改不影响原版，普通修改不加价、不重算周期。
- 未开始自愿退订退全部实付；已开始按实付×剩余秒数÷购买期总秒数，最终一次四舍五入到分。二次确认并完整有效提交后立即终止，不在审核等待中继续耗时、不连带终止其它期。
- 收到退款申请后24小时内首次回应，完整有效提交后72小时内审核并对符合条件者发起退款，为处理目标而非到账保证；失败/未知保持终止，查询核实后再确认结果，不自行恢复投放。无自行撤回生效退订入口。
- 未经独立授权不展示经营电话与详细地址，不复用实名资料；不展示访客身份、转化或收益承诺。

## 历史：2026-10-26按张AI定制方案（已由99元标准制作替代）

用户确认AI自助制作且Banner定制独立计费，不扣现有商家AI图片额度；询问基础报价来源（阿里云/火山方舟，不是OpenAI）后回复“可以”，本轮按推荐2.90元/成功生成一张作为候选售价制作合成预览。供应商、正式价格启用、真实收费/退款通道均未接入。生成成功即计费，选不选用均计费；选用和纯文字/排版调整不重复收费，主动重新生成另计；技术失败不计费，未知只查询、成功去重计一次。与广告投放费分开，原普通素材审核/自备素材替换不另收费规则不变。

V11-B首图入口改“定制/上传”，隐藏原生文件框；删除在首图右上关闭按钮，44px点击区，保留标题、日期等其他内容。移除“使用示例首图”和画板内格式/本地演示技术说明，V11价格页移除“示例价格，暂未正式启用。”；合成与候选价边界统一保留画板外及文档。上传取消/格式失败保留旧图；本地图片仅当前页面，重开时显示待重新上传，不能用示例图冒充。定制成图为可编辑合成SVG，保留当前标签页临时会话，不是已调用AI。

新增期望开始日期时间（北京时间），预计结束=开始+连续30天。新建自行选择，草稿可不填完；预览/提交必须未来，下期不得早于当前期结束。实际排期需审核，若建议日期不同，先展示原期望、建议开始/结束，商家明确接受后才建立待付款订单与位置保留，不静默改期。修改投放中素材不改变原购买期。期望/确认日期贯穿草稿、预览、审核及订单。

AI定制流程：填写标题/短句/宣传重点/风格、可选参考图→生成→预览→免费编辑文字/排版→用作首图。返回原表单保留文字、日期、授权和阅读位置；未选用不替换首图。生成记录独立于广告草稿，成功成图可在本次临时会话重新选用，不重复计费；刷新中断的请求转未知，先查询而非自动重发。生成前主操作标出2.90元，旁边固定提示成功生成即计费；二次生成再次显示金额。

方案、来源、边界及验证顺序见[本轮设计](superpowers/specs/2026-10-26-banner-ai-custom-and-schedule-design.md)。官方价格是基础模型调用价，不是本项目实测总成本；0.60元预算是假设，不是供应商报价。

本轮验证：新增5项模型用例，当前全量1255项Node测试通过；`verify-banner-custom-schedule`覆盖320/375/414/1280px、真实文件选择、取消/错误保图、删除保留日期、免费调整、失败不计费、未知只查询、刷新中断查询并只计一次、期望日期和改期接受到订单；原`verify-banner-preview`、`verify-v11-review`、`verify-banner-task-refinement`、`verify-banner-first-use`回归通过。结果与截图在`.superpowers/banner-custom-20261026/`。并发回归时首轮首次进入套件曾遇本地服务连接拒绝，单独重跑通过，未跳过资源错误检查。
