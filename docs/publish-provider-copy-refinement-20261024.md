# 发布与接单资料：操作文案整理

2026-10-24。承接用户继续优化前序页面的要求，本轮只处理审查表中V04用语一致性与V10重复解释，沿用已确认的字段、资格、三类独立资料和批量时段规则，不新增业务决定。

## 页面任务与改动

V04的任务是把本次文字整理后明确填入发布表单，再单独核对发布。按钮统一为“核对整理结果”“填入表单”“暂不使用”，步骤统一为写需求、核对结果、填入表单；原手填内容旁直接写“勾选后替换为下方内容”，未勾选保持原值。无选择、格式错误、填入成功及暂不使用的反馈与按钮使用同一套用词。已齐全与待补充由同一状态区显示，不在信息已齐全时再次提示补全。内部采用归因、结果过时保护、隐私提示、付费条件和发布确认不变。

V10的任务是编辑某类接单资料或设置可服务时段。资格状态和入口合为“发布与接单资格｜去完善/已核验 >”一行，取消上方重复准备接单介绍。三类资料和三类时段入口完整保留；概览只提示“时段和忙碌仅供沟通参考”，不自动拒单、取消交易或限制数量的具体说明放在忙碌开关旁。保存前仍明确核对批量替换范围，不增加资料门禁。

## 参考与适配

查阅[W3C表单说明](https://www.w3.org/WAI/tutorials/forms/instructions/)，借鉴字段说明就近、明确必填与格式的做法；查阅[GOV.UK按需展开](https://design-system.service.gov.uk/components/details/)，其明确不能隐藏大多数用户都需要的信息。本轮据此将忙碌影响留在开关旁直接显示，未机械增加折叠层或删除必要限制。参考是公开规范，未声称体验最新版平台应用。
