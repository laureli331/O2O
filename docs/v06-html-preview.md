# V06 / V23 发现与商家主帖 HTML 预览

这是第一版“发现”与商家图文主帖的单文件离线合成预览，不是小程序源码，也不会连接真实账号、发布、审核、收藏、分享或通知服务。

## 已确认范围

- 底栏固定为“首页 / 发现 / 发布 / 服务 / 我的”；发现使用 A 版线性指南针，底栏不再有“消息”。
- 发现页参考小红书 App 的内容优先层级：顶部使用“订阅 / 发现”主入口；“发现”内部显示“最新 / 优惠 / 上新 / 活动”和双列内容流，不复制其品牌色或图标。
- 每次点击底部“发现”都回到顶部“发现”和内部“最新”；从帖子详情或商家主页返回时保留原来的主入口与筛选状态。
- “订阅”只显示当前用户已订阅商家的合规公开帖子。未登录时显示“登录后查看订阅内容”；没有订阅或没有合规帖子时使用真实空状态，不填充其它商家内容，也不发送站内或微信提醒。
- 发现只展示审核通过且当前可展示的商家图文主帖，按审核通过后的发布时间倒序；主题帖同时进入“最新”和对应主题，未选主题的普通内容只进入“最新”。居民维修、跑腿、闲置和其它信息仍留在首页。
- 商家基础主帖免费，不依赖会员或内容加热。仅审核通过商家可提交；普通居民没有入口，资料待审商家只能看状态。
- 主帖支持 1—9 张图、首图封面和调整顺序；标题最多 20 个可见字符，正文最多 1,000 个可见字符；计数按 Unicode 字素簇处理，组合字符和家庭表情不会被拆开。
- 商家发帖页将图片选择与排序置顶，主题最多单选一个且可以不选；“保存草稿 / 预览”使用固定操作区。
- 详情采用 A 版顶部商家栏、SVG `<` 返回按钮、图片轮播、标题正文，发布时间与服务区域分两行且间距为 4 像素，并使用固定“收藏 / 分享”操作区。
- 商家主页采用头像、名称、`帖子 / 订阅 / 收藏`、一句话简介、“查看详细信息”、全宽订阅按钮和双列作品流。详细信息原位展开，只显示已填写的服务项目、服务方式、服务区域、营业时间和获准公开的联系方式；电话与微信直接完整展示，不打码。
- 商家作品筛选使用“最新 / 优惠 / 上新 / 活动”单选下拉，选中后立即收起并按审核通过后的发布时间倒序显示。
- “订阅 / 已订阅”支持登录引导、失败回滚与取消确认；取消确认文案为“不再继续订阅？”，操作为“继续订阅 / 取消订阅”，取消订阅不删除此前收藏。
- 公开页面不显示“已审核”或“资料已审核”；审核状态只保留在商家自己的发布与管理流程。
- 首版详情仅提供收藏与分享，不展示隐私说明卡或收藏失败测试控件，也不含评论、点赞、私信、视频、热榜或推荐算法；订阅只用于内容流聚合。
- 已发布主帖修改后，旧合规公开版在新版审核期间继续展示；通过时原子替换，驳回保留旧版；明显风险内容可先行下架并留记录。
- 通知中心位于服务页右上角二级入口，未读时显示角标，未读数为 0 时隐藏角标。
- 发现流覆盖加载、空状态、失败保留与重试、游客浏览；订阅流覆盖游客登录引导和无内容状态；详情显示发布时间和商家公开资料入口。

## 打开与验证

预览文件：[v06.html](../previews/v06.html)。项目本地预览地址为 `http://127.0.0.1:8765/v06.html`。

顶部状态按钮可直接切换发现流、详情、编辑、预览、待审核、驳回、替换成功、风险下架、通知中心和服务入口；右侧身份下拉可验证普通居民、待审核商家及审核通过商家的入口差异。发现主题可直接点击筛选；商家主页可展开详细信息、切换作品筛选、订阅或取消订阅，作品卡片可返回同一套详情。

自动验证覆盖模型边界、离线约束、真实 Edge 交互、订阅与取消失败回滚、授权联系方式、加载失败保留旧内容、收藏失败回滚、服务通知层级、减少动画，以及 320、375、414 像素下的横向溢出与底栏遮挡。
