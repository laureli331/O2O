# V21指标到订单与资金明细

2026-10-24。用户明确要求点击概览卡片查看具体订单，例如取消订单与多收待退。采用当前V21-A内的同页只读侧栏，不新增产品页面合同或写操作。

## 参考与适配

[Power BI官方明细导航说明](https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-drillthrough)介绍从汇总进入继承筛选的详细视图并返回原页面。本项目采用显式可点击卡片和“查看明细”提示，免去移动端右键操作；列表与对象详情在同一侧栏切换，关闭回原卡片。仅借鉴公开文档，不声称体验其最新版应用。

## 界面

11张卡片：发布、承接/成交、自动结束、取消、有效异议、应缴、收款、抵付、多收待退、退款及核准抵扣。前五项按业务事件筛选，后六项按对应账单/资金记录呈现金额。

列表继承当前成功查询的日期、业务及截止；显示首图、标题、当前状态和本项金额。支持标题/订单号/付款号查找，每页10条。点击记录显示订单摘要、事件状态/日期、资金依据；原编号与合成来源折叠。返回保留查找、页码和列表位置，关闭或Escape恢复卡片焦点和原页面位置。

0值可查看空清单；来源未知/未采集时禁用入口，不拼造完整明细。普通和未登录身份不渲染卡片或残留明细。刷新失败沿用最近成功查询的数据范围；重新筛选关闭旧侧栏，防止混用来源。

## 合成记录与资金边界

此前仅有日汇总示例，本轮补齐对应的确定性合成订单/资金记录；不把这些样本声称为真实订单。各筛选下记录数量或逐笔分金额等于原卡片数值，原业务/费用指标值未改。相同业务订单在发布、承接、结束、取消或异议入口中使用相同编号、标题、图片和当前状态。

本期收款、有效抵付与待退的记录引用相同付款。已退回示例来自10月16日的较早付款，于所选期间退回，不再计入本期收款。应缴与核准抵扣各有独立来源，不假造已收款；抵扣与多收退款不混用，不展示客户线下实付总额。取消不等于费用结清，自动结束不等于客户付款。

没有地址、电话或私密凭据，没有退款/处罚/支付按钮，不跳转不相关的V22本人合成账单。生产仍须DG01等准入及原订单必要管理权限，不新增已获授权的真实分析采集范围。
