## 3. 官方核查（2026-10-06）

### 3.1 微信类目

已直接读取[微信小程序服务类目](https://developers.weixin.qq.com/miniprogram/product/material.html)，HTTP 200，Last-Modified为2026-09-24。

### 3.2 评论管理

[现行《互联网跟帖评论服务管理规定》](https://www.cac.gov.cn/2022-11/16/c_1670253725725039.htm)涉及评论、回复等信息发布方式，要求真实身份、个人信息保护、审核巡查、举报/申诉等管理；本项目是否适用以及新增功能是否触发安全评估，需按真实业务核实。不能使用已废止的2017版本或2022征求意见稿作现行依据。

其中明确的先审后发条款针对新闻信息评论；本文建议业务评价文字先审后发是本项目运营选择，不声称法规要求所有业务评价都人工预审。

### 3.3 评价公平

[《电子商务法》第39条](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_d337c3291e8b40459ca03dea54395856.html)对电子商务平台信用评价及消费者评价途径作出要求，并限制平台删除消费者评价。是否属于该法律所指平台需按实际模式确认。

设计建议：合法低分不能仅因为不好看、服务人员要求、购买推广而拒绝展示/删除；虚假评分、违法内容、隐私泄露的处理必须有依据和申诉记录，不能把差评自动认定虚假。个人信息删除/保存、证据留存和合法评价保护的具体适用按E03与新增资格核验落实，不擅定永久保存或一概不能申请删除。

- 评价原稿、版本、审核/申诉证据限当事人及必要运营，不能在公开评价区曝光完整订单或他人私密资料；保存期限纳入E03核实。
- 每条评分保留唯一关联订单、方向、资格依据、星级、作者/对象受保护标识、首次/修改时间、文本审核状态。未通过文字不计为无评分；有效数值、文本公开和回应公开是分开的状态。

- 公共评价列表按首次评分时间倒序，每次20条；作者修改不自动置顶。均分计算不含未评分/无资格/被依法依规核实为虚假的记录；不能仅因低分或同一住址/IP把正常记录判无效。
- 评分统计只用本平台有效记录，不导入服务人员自报“线下五星”，不把数值均分作为安全担保、已付款证明或实际操作者身份证明。
- 评分/评价不恢复双方已撤销联系权限，不公开结束订单详细地址，不改变已完成/已取消状态，不暂停或延长推广权益。
