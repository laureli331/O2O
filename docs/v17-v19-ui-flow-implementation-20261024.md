## 实现说明

最终资格结果统一提供代码、结论、辅助说明、截止或已评时间。显示与按钮复用这一结果，V17 不另算资格。既有合法评分在出现后续争议时仍是已评，不被移回待评或自动删除。首评允许条件仍沿用原有来源及窗口，没有扩大已确认业务的准入。

等待结果的来源使用普通信息卡，不使用禁用按钮阻止理解原因，也不出现可点击箭头。已取消、超期等记录仍留在原订单/来源历史；本次没有新增终态汇总页或删除数据。

公开投影只向被评对象提供未公开回应的状态，不泄露待审/拒绝的文字、原因或原稿给公众。回应原有权限、拒绝可重提、公开后不能自主修改等规则不变。评分公式、舍入、分页和排序依据均不变；分页追加保留滚动并聚焦首条新增记录。

参考复核了 [GOV.UK 错误汇总](https://design-system.service.gov.uk/components/error-summary/)、[主次按钮](https://design-system.service.gov.uk/components/button/)和 [W3C 星级单选示例](https://www.w3.org/WAI/ARIA/apg/patterns/radio/examples/radio-rating/)。仅借鉴错误定位、操作层级、键盘和焦点原则，结合项目视觉实施，不复制示例或外部业务规则。
