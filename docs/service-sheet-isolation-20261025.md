# 服务弹层背景隔离

2026-10-25。沿用已确认的弹层隔离与原入口恢复原则，修复服务页底部弹层。

## 问题与修复

原版浏览器验证确认：更多操作打开时，预览外的状态切换、重置等工具栏并未禁用，程序焦点也可离开弹层；它们会改写当前演示内容。未保存修改确认复用同一底部层，也存在该边界缺口。

复用项目评价弹层的祖先同级元素隔离方式：仅保留弹层所在分支可操作，其它HTML背景分支记录原inert值后暂停操作；脚本、样式及图标定义不参与。弹层取消、Esc及点击遮罩后恢复原值并回到原触发按钮；不把既有禁用元素误启用。确认放弃仍沿原处理，仅明确确认后离开。进入历史或关闭需求等视图前解除隔离，不把下一页留在不可操作状态。

继续使用原底部菜单、按钮和安全默认焦点。表单未保存确认关联原说明文字以便读屏读取，预览工具栏暂停时同步降低透明度。没有新增页面、业务规则、确认步骤或外部操作。

## 参考

[W3C模态弹层规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)说明背景不可交互、焦点在弹层内循环、关闭后回到原入口。结合本项目内嵌手机预览，隔离范围同时覆盖手机内内容与外部演示工具栏；并沿用原取消/放弃语义。
