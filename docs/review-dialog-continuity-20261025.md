# 评价确认层：背景隔离与继续填写

2026-10-25。沿用V18/V19现有确认和图片预览，补齐弹层边界，不新增步骤。

## 实际问题与处理

- 已复现V18未提交保护弹层打开时，预览手机之外的演示状态、页面导航仍可操作。原视觉遮罩不等于真正禁用背景。
- 共享评价弹层现在沿父级保存并暂时禁用其它分支，覆盖手机内的标题/滚动区/页脚及外部工具栏、导航。背景工具栏和导航弱化显示；弹层本身保持可操作，Tab与Shift+Tab沿用现有循环，Esc与遮罩取消仍有效。
- 关闭时逐项恢复原禁用状态，原本禁用的元素不会被顺带启用；焦点回到仍存在的原触发按钮，避免额外滚动。弹层关联现有简短说明，辅助技术能识别本次确认内容。
- V18清空图文后重绘会令触发按钮断开，现明确聚焦文字框，继续填写；评分不变，取消清空不改内容，提交成功才消耗修改机会的原规则不变。
- V19图片预览仍只有一个关闭操作，隐藏的确认按钮不进入焦点循环；关闭后移除临时图片，回到原预览按钮。不改变举报入口、公开范围或评价模型。
- V17仅更新归档HTML里的共享资源版本，归档标记与历史渲染器保留，不恢复产品入口。共享样式仅增加禁用背景的弱化显示，不新增业务功能。

## 参考与适配

[W3C弹窗规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)要求背景不可操作、焦点留在弹窗内、关闭后回到合理位置；[MDN inert说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/inert)说明原生背景禁用同时限制点击、焦点和辅助技术访问。本项目继续使用原确认层与配色，保存/恢复原状态，防止手机预览之外的控件绕开确认；没有增加新的模态流程。
